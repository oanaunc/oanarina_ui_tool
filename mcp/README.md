# Oanarina UI Tool MCP

A free local MCP server for the saved `.oui` document you select explicitly. It uses stdio, runs without an account/API key, and opens no network listener. There is no usage charge or subscription in this server. AI hosts and models are separate products with their own terms.

Auto-layout operations accept validated `layoutStacking`, `layoutIncludeStroke`, `wrapDirection`, `wrapAlign` and optional preserved `layoutAspectRatio` metadata. Layout uses the same aspect/fill, padding, stroke and wrap solver as the editor. Malformed values reject the entire transaction before the selected project is written. This does not change the server's project/file authorization boundary.

Source `apply_operations` also accepts `reorder_grid_tracks` with `pageId`, `nodeId`, `axis` (`column` / `row`), zero-based `from`, final zero-based `to`, and optional `count` (default 1). It moves a contiguous track block with its occupied cells, pins active automatic placements, preserves spans and refuses split spans or locked/managed grid edits atomically. Definitions support 4096 tracks; automatic row overflow beyond that ordering range must be reduced first. Rows remain a minimum. See [grid track ordering](../docs/GRID-TRACK-ORDERING.md) for limits. Download archives are not regenerated by this source-only change.

## Standalone download

Current development Mac app users can download `oanarina-mcp.zip` from the app’s MCP help, unzip it, and launch `node /absolute/path/server.mjs --project /absolute/path/Design.oui` with Node.js 22 or newer. All runtime code and licenses are included; no npm installation is needed for that download. No live editor synchronization is claimed.

## Install and connect

Use Node.js 22 or newer and a checkout of this repository:

```sh
npm ci
npm --prefix mcp ci
```

Add this server to any MCP host supporting local stdio servers. Replace the example project path with your `.oui` file. Use absolute paths for both script arguments. Directly launch Node/tsx, as below, so npm's normal progress output cannot enter the protocol stream.

```json
{
  "mcpServers": {
    "oanarina-ui": {
      "command": "node",
      "args": [
        "/Users/oanarinaldi/Desktop/oanarina_ui_tool/mcp/node_modules/tsx/dist/cli.mjs",
        "--tsconfig",
        "/Users/oanarinaldi/Desktop/oanarina_ui_tool/mcp/tsconfig.json",
        "/Users/oanarinaldi/Desktop/oanarina_ui_tool/mcp/server.ts",
        "--project",
        "/absolute/path/My Design.oui"
      ]
    }
  }
}
```

Append `--create` to create an empty document if that exact path does not exist. Without it, an existing valid `.oui` file is required. The directory must already exist. Save changes in the Mac editor before using the server. A Forma window with no unsaved changes reloads MCP edits within seconds; see [the open editor](../docs/MCP-LIVE-CONTEXT.md) for what happens otherwise.

Version-one `.oui` projects can be read and migrate to version two when written. Use the current development editor to reopen MCP-edited files; compatibility with the older public v0.1.0 installer is not claimed.

## Tools

| Tool | Behavior |
| --- | --- |
| `inspect_project` | Document/page metadata, layer counts and current SHA-256 revision |
| `read_spec` | List spec layers, or read one as Markdown with `forma://` references to its frames and images |
| `read_nodes` | Search, filter IDs and paginate layers; asset bytes omitted by default |
| `read_document` | Complete JSON, optionally including assets; maximum response 5 MB |
| `read_design_system` | Typed variables, collections/modes, local styles and component sets |
| `read_library_context` | Source-only metadata index of local reusable definitions, installed libraries/publication, versions/status and bounded dependency IDs; revision-bound pagination |
| `apply_operations` | Atomic batches of up to 500 node/page/design-system edits |
| `replace_document` | Validated complete document replacement for advanced model features |
| `undo_transaction` | Restore the previous successful MCP transaction; last 20 survive restarts |
| `read_undo_history` | Source-only: retained Undo count, size and availability, never content |
| `clear_undo_history` | Source-only: delete retained prior project copies; the project is unchanged |
| `list_installed_fonts` | Source-only: installed family names and styles, optionally compared with the document |
| `read_live_editor` | Source-only: page, selection and viewport of an opted-in open Forma window |
| `read_live_screenshot` | Source-only: latest window screenshot from an opted-in open Forma window |
| `export_live_artwork_png` | Source-only: selection or page PNG rendered by an opted-in open Forma window |
| `import_image_asset` | Source-only: validate embedded static 8-bit RGB/RGBA PNG, create an editable page-root image in one transaction |
| `validate_project` | Run the editor's shared document validators. Brand projects also report out-of-brand values and assets whose locked styling no longer matches their recorded lock |
| `export_svg` | Return SVG for vector/text pages; reject images and browser-raster fills |

Durable Undo, font listing and the command-line `mcp/automation.ts` are described in [MCP undo, fonts and automation](../docs/MCP-LOCAL-AUTOMATION.md). Live tools are described in [the open editor](../docs/MCP-LIVE-CONTEXT.md). The server has no renderer of its own: raster output needs an open editor window that opted in. The frozen standalone download does not include these source tools yet.

The resource `oanarina://project/summary` provides current metadata. Tool schemas are discoverable through MCP. Every write requires a `revision` returned by a read. Stale revisions fail without changing the file.

Source `read_library_context` omits node bodies, library baselines, scalar variable/style values, images/fonts, comments/annotations, author/profile payloads and unknown optional metadata. It returns explicit limits/notices and requires `expectedRevision` for nonzero pagination offsets. It is scoped to the selected saved file; it does not search remote libraries or the browser's snapshot cache. See [agent library context](../docs/MCP-LIBRARY-CONTEXT.md). The frozen standalone download does not include this source tool yet.

Default asset-omitted document reads also omit opaque local-library edit-baseline strings: those can contain copies of embedded image/font data. Request `includeAssets: true` for a complete saved document, subject to the response limit. Asset-omitted views are for inspection and must not be submitted to `replace_document`.

Source `import_image_asset` takes `revision`, `pageId`, `dataUrl` (`data:image/png;base64,…`) and optional `name`, `x`, `y`, `displayWidth`. It preserves aspect ratio and returns natural/display dimensions, bytes, node ID and new revision without echoing the asset. Supports bounded noninterlaced 8-bit RGB/RGBA static PNG; other raster formats, indexed/grayscale/16-bit/interlaced PNG, animation and compressed metadata are refused. No asset paths or network URLs are accepted. See [PNG import](../docs/MCP-PNG-IMPORT.md) for validation and limits. The frozen standalone download does not include this new source tool yet.

`apply_operations` supports `rename_document`, `create_page`, `rename_page`, `duplicate_page`, `reorder_page`, `delete_page`, `create_node`, `update_node`, `update_spec`, `delete_node` and `set_design_system`. `update_spec` replaces a spec's blocks from Markdown and keeps the frames and images its `forma://` references name. Nodes can specify an optional unique `id` when created, so children can reference parents created earlier in the same atomic batch. Node `properties` use the shared `.oui` node fields; changing `id` or `type` through an update is rejected. Deleting a frame also deletes its descendants; deleting an owned instance child records a visibility override. Moving a container moves its descendants.

A minimal operation batch, after obtaining the revision and page ID:

```json
{
  "revision": "SHA256_FROM_INSPECT_PROJECT",
  "operations": [
    {"op":"create_node","pageId":"PAGE_ID","id":"card","type":"frame","properties":{"name":"Card","x":100,"y":100,"width":320,"height":200}},
    {"op":"create_node","pageId":"PAGE_ID","type":"text","properties":{"parentId":"card","name":"Heading","x":124,"y":124,"text":"Created locally."}}
  ]
}
```

### Page organization

- `duplicate_page` takes `pageId` and returns `{pageId, index}` for the new page. It inserts the copy immediately after its source and chooses a unique copy name. Page and owned layer IDs are fresh; typed internal component/prototype/flow/motion/guide references follow the copied artwork. External references and shared style/variable/font identities remain in this document. Ordinary text, URLs and expressions are not rewritten just because they equal an ID. Supported whiteboard logical records and wholly owned component sets are copied; the global timer and existing votes are retained rather than duplicated.
- `reorder_page` takes `pageId` and an integer `index` from `0` through the current page count minus one. This is the page’s **final zero-based position**, not an insertion gap or a relative offset. It returns `{pageId, index}`. Page identities and references do not change. A transaction containing only reorders with no net change preserves the exact saved bytes/revision and consumes no undo entry; its supplied revision must still be current. A mixed no-op reorder plus real edit remains one normal transaction.
- `delete_page` uses the editor’s shared reference checks. It refuses deletion of the last page, an active presentation deck page, a page with incoming surviving component/prototype/flow/motion references, or a page splitting a component set or mind map. It cleans owned component-set and whiteboard records only after validation. Explicitly remove or move incoming references first; earlier valid operations in the same atomic batch can do this. There is no implicit detach or silent reassignment.

An active Slides deck page cannot be duplicated/deleted through these page operations. Use the presentation workspace’s individual-slide commands instead. Other pages can still be ordered. Duplicate refuses the shared 1,000-page limit; the 50 MB document limit and 500-operation transaction limit still apply. A page helper validates the draft after preceding edits have passed the same rich-text/component/layout/whiteboard derivation pipeline used at save. The complete batch still performs a single atomic file save and records one undo entry; any failure rolls back every operation and leaves history intact.

Example: first duplicate a known page, then use its returned ID and revision in the next request:

```json
{"revision":"<current SHA-256>","operations":[{"op":"duplicate_page","pageId":"<source page ID>"}]}
```

```json
{"revision":"<returned SHA-256>","operations":[{"op":"reorder_page","pageId":"<returned copy page ID>","index":0}]}
```

## File handling and limits

All tools are scoped to the one launch-time project. Tools accept no filesystem paths, shell commands, scripts or eval code. Individual file symlinks are refused, parent directory symlinks are canonicalized at launch, and `.oui` files are limited to 50 MB. Inputs are validated before writes using the same component, variable, prototype, grid and motion validators as the editor. Project reads use bounded chunks and reject symlinks, non-regular files, named pipes and malformed UTF-8. Lock cleanup removes only the lock identity it opened. Components and design-system values propagate before saving. Headless text measurements are approximate; review automatic wrapping and size in the Mac app.

Writes use a per-project exclusive lock, a temporary sibling file, fsync and atomic rename. Hashes are checked immediately before committing. The lock coordinates MCP processes and the Forma native editor. Native project saves also compare the last opened/saved SHA-256 and offer Cancel, Save As or an explicit overwrite when the disk copy changed. A clean editor window reloads the saved file automatically; a window with unsaved changes keeps them and asks before Save replaces the file. Other applications ignoring the shared lock are not coordinated. An external write in the final check-to-rename interval cannot be excluded by the filesystem API. A crash before rename retains the old file; a crash after rename retains the validated new file. Undo history persists beside the project in a private hidden folder and stops at any external change. A crash can leave `<project>.oanarina-mcp.lock`; verify neither Forma nor an MCP process is using the project before manually removing that lock.

SVG output uses the editor's actual vector renderer and escapes text. It never writes a path, fetches URLs or evaluates document content. Image layers, image paints, angular/diamond raster paints are refused so output cannot depend on browser decoding or external assets. Text wrapping uses approximate headless metrics; installed font files are not copied. Project-embedded fonts are included only where embedding is permitted. Responses are capped at 5 MB. Binary `.fig` support is outside this server.

## Validation and dependencies

```sh
npm run mcp:test
```

Tests cover atomic rollback, stale revisions, concurrent writers, scope/symlink rejection, locks, undo, invalid geometry, design-system cycles, hierarchy edits, deterministic/escaped SVG, and an actual SDK client communicating with the spawned server over stdio.

Uses the current stable official MCP SDK v2 packages (`@modelcontextprotocol/server` and test client `@modelcontextprotocol/client`, pinned to 2.4.0), verified October 29, 2026.
