# Primitive vector brush drawing

This unreleased source workflow adds Brush to the Pen/Pencil toolbar menu and the searchable Tools commands. Its floating controls provide five stock presets and a reusable local library, with shape, size, aspect ratio, spacing, fixed/follow-stroke direction, angle, six-digit color, opacity and size/opacity pressure response. The actual preview uses the same SVG Artwork renderer as saved strokes.

Draw on the Design canvas. The frame/section under the starting pointer owns the entire stroke; outside containers it becomes a page-level group. Brush does not automatically nest later strokes into a previous stroke group. Nested rotations, reflections and nonuniform scales map the pointer through one captured parent inverse, with size/spacing expressed in that parent's local units. Existing frame clips and preceding sibling masks keep their normal shared rendering semantics. Source layers/masks/frames are preserved. Hit locked, main-component/instance, live-boolean, mask-source-container or Auto-layout ownership is refused, rather than silently switching to another owner. Whiteboard, Slides, Motion, outline view and point editing are outside this pass. A destination can have at most 62 hierarchy levels, leaving two for the group and stamps; the bounded page index supports 64 source levels.

Each finished stroke is one ordinary group containing independently editable ellipse, rectangle or closed diamond/triangle contour nodes. Separate stamp opacity preserves overlap compositing: two overlapping 50% stamps produce 75% alpha. There is no merged compound path that accidentally removes these overlaps. Existing .oui versions 1/2 need no new metadata; preset changes never change already materialized strokes. Shared Canvas, SVG/raster export, alpha/luminance/vector masks, clipboard and source-MCP editing work through these existing validated node types. Presets do not add a new source-MCP drawing endpoint or native brush format. Exact Figma/native reference acceptance is unverified.

The centerline is a piecewise-linear sequence sampled at `nominal size × spacing` arc-length intervals, including an initial stamp. Fractional distance carries across segment/coalesced-event boundaries, rather than restarting at each event. There is no forced final stamp that alters spacing. Follow-stroke direction uses the tangent of the interval containing the stamp; at an exact joint it uses the arriving interval. Source samples use the actual supplied pen/touch pressure, linearly interpolated at stamp positions. Each enabled response uses `minimum + (1 − minimum) × pressure`; it affects actual stamp geometry/alpha. Mouse input uses full pressure. A lift event's zero pressure does not shrink the last committed interval. Browser tests inject genuine Chromium pen pointer input through CDP and inspect materialized sizes/alpha; physical tablet, AppKit/WKWebView pressure delivery and native hardware acceptance remain unverified. No automatic pressure capability/quality guarantee is made.

The local preset picker/library supports save-new, update/delete custom, restore the selected saved settings, and JSON import/export of one brush or the library. Five built-ins are read-only; customization creates an independent preset. Current settings and custom presets persist locally on this device/browser origin, separately from .oui. Preset changes use local preferences rather than document Undo. JSON imports validate the entire file before installation and receive fresh local IDs; a delayed read cannot apply after its document/mode context was invalidated. Only the four primitive families and literal scalar/color fields are accepted: SVG markup, remote assets, scripts and unknown fields are refused. Import/export supports Forma primitive JSON, not third-party brush formats. Arbitrary vector/art brushes, scatter/stretch/calligraphic libraries and sampling an existing layer are not implemented here.

Limits are 32 presets including built-ins, 64 KB per preset file, size 1–512, aspect .1–4, spacing 5–400%, opacity 0–100%, angle ±3600°, and minimum pressure response 5–100%. A stroke supports 1,024 distinct samples, at most 128 coalesced events in a dispatch, 512 stamps and 20,000 total page nodes. Scene indexing visits each page node once, caches inherited matrices/visibility/ownership, and rejects cyclic/missing/deep hierarchies before hit geometry. Each sample then uses the cached parent inverse in constant work; ID collision checks use a cached Set. Existing source/model/effect budgets can refuse a smaller stroke in a constrained context. Exceeding any limit cancels the entire current draft with an explanation, preserving source/history; it does not commit a hidden prefix.

Pointer drafts are ephemeral full-scene previews. Release validates a complete candidate, then commits one Undo with post-derivation checks that the source nodes and materialized additions remain exact. Escape, blur, visibility/resize, lost capture, pointer cancellation, source/camera/selection/mode/settings changes cancel the draft. Foreign pointers cannot finish it. Space cancels and permits Canvas panning. Retained handlers cannot restart a canceled context after an away-and-back change. No release package or website/download update is part of this source work.

Validation includes pure arc-length/pressure/shape/budget tests, 20k-page/64-level/128-sample work-count checks, .oui/Undo/source-MCP persistence, real browser pressure/coalesced input, scaled control reachability, genuine save/reopen, malformed/delayed import, cancellation/stale handlers, transformed clip pixels, alpha-overlap pixels, and shared Canvas/editor/headless SVG mask pixels. Reference verification remains separate.

Destination hit-testing follows actual hierarchical sibling/mask-run paint order, rather than taking the last matching entry in the flat document array. Interleaved descendants therefore cannot steal ownership from a front sibling frame. Cached inherited affine clip chains exclude candidates outside square or ordinary circular-corner rectangular clips (including signed/nonuniform transforms). Nonrectangular/smoothed clip coverage and containers affected by sibling masks are conservatively refused when coverage cannot be proved; the tool does not silently choose an invisible container or another owner. Page-level drawing under an existing sibling mask remains supported through normal shared rendering. Unknown coverage behind an already chosen front unmasked frame does not block that frame. Mask-source-container ownership stays refused.

Known clip boxes are explicitly limited to rectangle, image, frame, group, section, component and instance geometry. Text clips use glyph/outline coverage in shared Artwork and are therefore unknown and refused, just like arbitrary vector clips. Falsy imported parent IDs follow the renderer's root semantics; an empty-ID destination is refused before mutation because that renderer cannot represent children under such an ID reliably.
