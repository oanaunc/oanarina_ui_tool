# Editable text on a self-contained path

This pass implements a bounded text-on-path workflow, not complete Figma text-path parity. Select an ordinary contour path, open **Text on path** in the inspector, and choose **Convert path to editable text**. The same layer owns its original contour, basis, pose, name, text and paints. Its fills and supported strokes paint the glyphs. Double-click painted text to edit its source; use **Text path start offset (%)** to move it along the curve. **Return to baseline path** restores vector editing without another layer or external reference. Focused Convert/Return buttons retain native Space/Enter activation without starting canvas panning. Conversion, text changes, offset and return use normal Undo and `.oui` persistence.

Ellipses, rectangles, polygons, stars and closed paths also convert, so text can run around a circle. A saved baseline stays one open contour, because every build requires that: a closed shape opens at its first anchor, with the end repeating the start, and shapes bake their own pose first. **Return to baseline path** closes a contour whose ends meet, which also applies to a path that was authored open with coincident ends. **Flip text direction** reverses the contour in one Undo step, which moves the text to the other side of the path, and mirrors the offset so it starts from the same place. A round handle on the canvas drags the start offset along the real baseline: glyphs follow in preview, Escape cancels, and release commits one Undo step at 0.1% precision.

The baseline is one open straight/cubic contour with 2–64 anchors. Text is plain single-line LTR, at most 2,048 UTF-16 units, font size 1–256, and tracking within ±4 em. Local dimensions/basis and rendered control coordinates are bounded at 100,000 units. A page containing this feature supports 20,000 layers, 64 text paths and 8,192 combined text units; ancestry is capped at 256. Existing documents without the optional `textPath` field keep ordinary text behavior. Versions 1 and 2 remain readable.

The browser's SVG `<textPath>` shapes the original string on the actual cubic baseline. The offset is a percentage of path length; left/center/right alignment uses SVG start/middle/end anchors. Characters outside the open path are clipped by SVG text layout. The baseline is self-owned geometry, so clipboard copies and deletions cannot leave a dangling reference. Separate canvas/prototype/export surfaces use isolated SVG resource IDs even when the same authored layer has different variable-derived dimensions.

## Bounds and supported contexts

Browser bounds are native SVG **glyph-cell bounds**, padded by available Canvas font metrics and a conservative 2 em minimum. They are not a guarantee of paint-tight ink for arbitrary fonts. The inspector states this. Native font loading and `refreshFonts` remeasure the same source without caching old glyph bounds. A detached measurement probe is rebuilt. When native measurement is unavailable, headless/model use an explicitly **estimated** control-hull/text-size envelope; the inspector and exported SVG description disclose that fallback. An authored ancestor clip/frame viewport or explicit export viewport remains an intentional crop. Very large estimated envelopes can exceed normal export pixel limits and require native browser measurement or an explicit crop.

Supported glyph strokes are up to four solid centered round/bevel strokes of width 0–256, without dashes. Rich ranges, paragraph/list/wrap/trim settings, OpenType overrides, RTL, multiple baselines, components/instances, automatic layout, effects, own text clipping, live Booleans and animated ancestry are refused atomically. Pages containing masks are refused. Ordinary clipped ancestor frames and affine/reflected poses are supported. Existing inherited locks and source-context guards apply. Text-only metadata that cannot survive conversion back to a path causes an explicit refusal rather than silent deletion.

Saved baselines and their authored text are validated before document publication, including source MCP operations. Transient prototype variable results receive the same validation; unsupported multiline or geometry changes refuse the whole action batch. Instant/dissolve presentation can display supported states. Smart animate of affected text-path subtrees explicitly refuses.

Inspector and canvas text drafts permanently invalidate across source, selection, page, mode, modal, Motion or inspection interruptions. UI-scale/tool interruptions also discard a canvas draft. Rejected multiline drafts stay reviewable with an error and can be corrected or discarded with Escape. No document changes publish before validation; equal values add no history.

## Interchange limits

SVG and derived PNG appearance exports use the shared renderer and bounds. Editable SVG import currently refuses `<textPath>` explicitly; it does not silently flatten or omit the text. Figma Bridge transfer explicitly refuses this node before creating content. Direct binary `.fig` text-path interchange is not implemented. CSS/native inspection reports that the curved baseline and start offset require SVG. Reusable text styles do not store baseline geometry. This pass does not provide a linked external baseline lifecycle, rich multilingual typography or arbitrary font-ink equivalence.

## References and validation

Figma's primary [Create text path API](https://developers.figma.com/docs/plugins/api/properties/figma-createtextpath/) and [TextPathNode reference](https://developers.figma.com/docs/plugins/api/TextPathNode/) establish text-path conversion as a separate geometry-bearing node. The [Figma text guide](https://help.figma.com/hc/en-us/articles/360039956434-Guide-to-text-in-Figma-Design) describes its editing controls. Forma's narrower implementation uses the [SVG text-on-path model](https://www.w3.org/TR/SVG/text.html), with explicit limits above; it does not claim Figma's full implementation.

Coverage includes exact cubic/basis serialization; signed affine pose; atomic invalid imports/edits and missing ancestry; Undo, save/reopen, clipboard and deletion; bounded 20,000-layer ancestry work; Bridge/SVG-import refusal; prototype variable validation; actual curved glyph positions/rotation and raster overhang margins; late open-license font loading, detached probes and fallback warnings; context interruption/recovery; 125% UI scale; and distinct canvas/prototype baseline resources.
