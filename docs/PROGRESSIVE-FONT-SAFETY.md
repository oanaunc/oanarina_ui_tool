# Progressive blur after font loading

Font loading can change measured glyph widths without changing saved text or font settings. An auto-sized layer may grow beyond progressive blur's bounded filter region; fixed-box text can also acquire enough wrapped lines or overhang to exceed that region while its saved dimensions remain unchanged.

`refreshFonts` now validates the complete derived document before publishing reflow. If validation fails, it preserves the exact source document, selection and Undo/Redo arrays. It still advances the font revision so the interface reflects the loaded font and reports why reflow was not applied. Font loads are neither disabled nor rounded into an undeclared approximation.

Live Artwork explicitly opts into a recoverable refusal with `live`. A typed progressive region/pixel-budget failure pauses that Artwork instance atomically and displays **Artwork paused** with recovery guidance. The rest of the editor remains usable. No source artwork or unfiltered substitute is painted: refusing an entire instance avoids changing the meaning of mask sources, sibling targets, clips and nested effect stacks. The diagnostic is an editor-only SVG overlay, anchored in CSS pixels to its owner SVG viewport outside source clips/masks; static rendering has an inline accessible fallback. Small thumbnails use a compact title and an accessible explanation. Media playback is a separate option and is not enabled by live diagnostics.

Reduce text, font size or blur padding, or remove the progressive effect, to return to supported bounds. A valid correction is an ordinary persisted Undo step. Undoing a correction may return to the explicit refusal; it never reloads or discards the project. Normal safe artwork continues through the existing renderer. Malformed metadata and unrelated source-work/depth errors still reject rather than being mislabeled as a font-budget refusal.

The main canvas (including Whiteboard's shared canvas), Home, page/component thumbnails, slide canvases, SVG import preview and standard prototype Artwork opt into live refusal. Existing preview helpers that use strict SVG export report their failures locally. Page-thumbnail viewport calculation may use nominal boxes only to place a diagnostic when progressive region measurement is refused. This fallback does not alter model or export bounds. Canvas sampling reports an export refusal locally and keeps its close control available.

Graphic exports use strict Artwork without `live`: editor SVG, raster/PDF source exports, slides and headless MCP SVG continue to reject unsafe geometry. They do not export the diagnostic as valid artwork or silently remove the filter. `.oui` source persistence and the font catalog remain unchanged. There is no new schema field or format migration.

Verification uses isolated headless metric changes plus actual Chromium FontFace loading from an existing bundled, open-license JetBrains Mono asset under a synthetic test family. Auto-width and fixed-box cases check exact document/history preservation, visible refusal, strict export rejection, correction/Undo/Redo, 125% UI scale, extreme pan/zoom and page thumbnail behavior. No fonts are uploaded or newly bundled. Native WKWebView diagnostic acceptance remains unverified; no app, archive, installer or website build is part of this change.
