# Embedded image editing

Source implementation following dev.12; no new release package or version is created by this work.

Image fills and image strokes expose Fill, Fit, Crop, Tile and Stretch in the existing paint inspector. Numeric scale, angle and offsets retain the previous renderer’s coordinate semantics. Tile uses embedded intrinsic dimensions when available and the layer dimensions for legacy assets. Reset image transform restores Fill, 100% scale, zero rotation and zero offsets, preserving the source asset, opacity and adjustments.

Interactive crop is an inspector preview. Drag the image to pan or its lower corner to scale. A completed gesture commits one shared Undo step; drafts do not change the document. Escape, pointer cancellation, lost capture, window blur/resize, a document/page/selection change and opening another workspace/modal cancel an active draft. The preview supports arrow-key panning, with Shift for 10 pixels, and accounts for source rotation. This is not a canvas crop-overlay reproduction or perspective crop.

Seven independent adjustments—exposure, contrast, saturation, temperature, tint, highlights and shadows—are optional paint metadata. Each accepts −100…100%. The canvas, crop preview, masks, SVG exports, raster exports and selected-artwork PNG-copy renderer use the same SVG image definition. Exposure spans ±2 stops. Contrast is centered at 0.5; saturation uses an SVG saturation matrix; temperature/tint adjust channels; shadow/highlight transfer curves taper toward midtones. Tone transfer remains monotonic at the supported extremes. These are Forma’s own sRGB curves, not a verified match to Figma’s image filters. Adjustments preserve alpha; image paint opacity is separate from layer opacity. Reset adjustments leaves placement, source bytes and opacity intact.

Replace image accepts embedded PNG/JPEG/WebP/GIF files up to 20 MB. It validates the file and decoded dimensions (16,384 per side, 80 million pixels), and refuses a late result after the project or selection changes. Replacement preserves placement and adjustment choices. Image fills on legacy image layers also update their fallback source field, avoiding storage of a replaced asset solely as unused fallback data. Inherited locks and an open motion editor disable these editing controls.

Export original image downloads decoded embedded bytes with their embedded MIME extension, preserving the source file rather than resampling the edited appearance. The file-size label reports decoded embedded bytes, with known intrinsic dimensions. It does not estimate decoded memory or the compressed `.oui` document size.

Copy image as PNG invokes the existing trusted Mac clipboard action. It copies selected artwork, including fills, other paints, masks, adjustments and opacity, at the existing 2× bounded raster size. It is not an isolated source-file copy. The browser explains that this action requires the Mac app; original export and PNG file export remain available. Its native clipboard implementation and permissions are unchanged. This batch has browser API-contract coverage for the new button, not a new real native clipboard acceptance run.

The additive `Paint.adjustments` object is validated on `.oui` import, ordinary store edits and editable Figma Bridge import. Version-one and version-two projects remain readable. Unsupported editable Bridge transfers explicitly report nonzero Forma image adjustments, and section ready-for-development metadata, as omitted. Use appearance-preserving SVG/PNG export for adjusted assets. No binary `.fig` export or exact image-filter round trip is claimed.

Validation: 13 image core tests plus two Bridge omission/preflight checks; 722 total core tests passed. Production Chromium checks passed 13 image cases and 13 existing paint/mask cases, including actual exported pixels, independent adjustments and resets, Undo/Redo, save/reopen, crop cancellation, replacement races, byte-for-byte original export and the trusted PNG clipboard API contract. TypeScript and production web compilation passed. No Mac package, signing/notarization task, website change or release is part of this batch.
