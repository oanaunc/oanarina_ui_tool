# Local keyboard layout and additional shortcuts

Preferences → **Keyboard shortcuts** supplies real local keyboard workflows for UI-42-015/016/017: a key layout choice, additional bindings, replaced defaults and conflict refusal. Reference verification is pending, and the Mac menu's own accelerators stay fixed.

**Physical US key positions** is the default. Registered commands, tools and the Command-/ Actions alias use `KeyboardEvent.code` where available. **Logical typed keys** follows the reported `key`, so a reported `r` at `KeyQ` selects Rectangle rather than the physical Q position. Non-ASCII Option-modified symbols fall back to the physical key because browser events do not reliably provide that key's unmodified character; the controls and help explain this exception. Dead input does not trigger logical shortcuts, and composing events do not dispatch commands. Contextual arrows, temporary Space pan, text entry, number opacity, native menus and specialized workspace controls retain their own policies. No system keyboard map, layout permission or remote service is used.

## Named layouts

**QWERTZ**, **AZERTY**, **Dvorak** and **Colemak** map each physical key to the letter printed on it, so Command-Z undoes on the key labelled Z, including with Option held, where a reported `key` is a symbol. Keys a table leaves out keep their US position: on QWERTZ and AZERTY, `[`, `]`, `/` and similar shortcuts stay at the US physical key, which keeps them reachable where the layout hides the symbol behind Option. Help and menus still print the US glyph for those punctuation shortcuts. The layout is a declared choice; Forma does not read the system keyboard.

## Replacing a default

**Turn default shortcut off** stops a command's default key; pair it with an additional shortcut to replace it. That key is then free for another command. Help, menus and Actions stop listing the old key. Turning a default back on while another command holds its key refuses and names the conflict. Open, Save, Save As, Undo, Redo, clipboard commands, Select All, Preferences, Find, Actions and canvas navigation stay on, because the Mac menu or navigation relies on them. Additional shortcuts can also be one bare letter or Shift plus a letter.

## Additional shortcuts

The command chooser searches the actual named editor command catalog. **Record additional shortcut** captures one A–Z letter, alone or with Shift, or Command plus one letter (Control on non-Mac platforms), optionally with Shift/Option. Apply persists one additional binding per command; Remove restores that command to its original defaults. Reset additional shortcuts preserves the layout choice; Reset keyboard preferences removes this preference record entirely. The general Reset preferences action includes this record too. Recording Escape cancels capture rather than closing Preferences, and Tab remains available once capture ends.

An additional binding never replaces an original shortcut. Its eligible dispatch context is Design, Prototype or Inspect with Move/Scale selected, where the command's own checks still apply, outside editable fields, modal dialogs, vector editing, Motion, hidden UI, the file browser and Slides. A file action in the document title menu uses the same eligibility rule and current live settings. Existing defaults, early file shortcuts and the native command adapter stay available through their existing routes. Executed additional commands use the existing validation, Undo and save behavior of that command; editing these preferences does not itself change a project or its history.

Conflict checks canonicalize modifier order and letter case, then refuse every existing default accelerator, duplicate additional assignment and the known OS/browser/text/window aliases in the shared reserved table. Bare tool keys count as reserved until their default is turned off. Contextual navigation, Space, function keys, digits, punctuation, Option without Command and Control-only chords cannot be assigned. Reserved combinations report a reason before saving. OS settings, third-party extensions and external accessibility tools can intercept other keys; this is not a global OS conflict detector. Mac AppKit menu accelerators remain fixed, including native file/window/destructive commands. There is no native IPC, menu rebuild or custom native primary mapping.

Shortcut help, web menus, document-title menu accessibility attributes, Actions and toolbar hints show default plus additional bindings. Shortcut-use highlights record the actual additional input under the named command, with the existing dispatch provenance and cancellation limitations. A displayed additional shortcut retains the context restrictions above; it is not advertised as available inside every editing mode.

The separate `oui-keyboard-preferences` local-storage record has a strict version-one envelope, only the declared layout, named-command map and optional `disabled` list, at most 128 additional assignments and a 32,000-character input limit. Parsing validates every binding and command before publication; unknown fields/versions, invalid identities, reserved keys and collisions activate safe defaults with a visible Preferences warning. Writes validate and persist before notifying subscribers. Blocked/quota-limited storage reports a failure without switching the active settings. Shared-origin windows observe actual storage events; no `.oui` field, clipboard payload, published library, Figma Bridge file or MCP document metadata contains these preferences.

Editor-source, saved-settings and synchronous local-candidate receipts prevent retained controls from publishing after document/page/selection/mode/modal/Motion, command/search/candidate or stored-settings changes. Away-and-back cycles invalidate old receipts permanently; fresh rendered controls retry normally. The initial receipt also handles React StrictMode effect replay. Keyboard matching reads the current preference once per global key dispatch; no typed-key history or arbitrary input text is retained by this feature.

Forma's tables cover four layouts and do not reproduce Figma's per-language remapped shortcuts.
