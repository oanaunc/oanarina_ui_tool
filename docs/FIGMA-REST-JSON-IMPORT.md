# Offline Figma REST JSON import

`File → Open project` in the browser recognizes a selected local GET-file response (`document.type = DOCUMENT`) or bare `DOCUMENT`. `File → Figma import / export → Import local REST JSON…` exposes the same file-input route in the shared editor, including the Mac shell without adding IPC or filesystem permissions. The existing native Open adapter is unchanged and is not verified for REST JSON. No token, API request, automatic download, image lookup or original-file modification occurs. UI-39-037 is **partial**; API retrieval and credentials remain separate absent workflows.

An explicit reduction review precedes outgoing recovery and incoming installation. Cancel, Escape, newer Open, stale entry callbacks, pre-chooser or review source/page/selection/mode/visibility changes permanently invalidate the candidate. Confirmation uses the existing abortable outgoing recovery and new-project installation policy: dirty projects require a retained local copy or explicit saved backup. Opening starts a new document with empty Undo history; editing then uses ordinary Undo, and `.oui` v1/v2 reading and v2 saving remain unchanged. Post-open notices use the existing ephemeral Figma import report; they are not persisted in `.oui` or sent to services. The original JSON remains the reference. Existing font loading runs only after the project opens; exact fonts, glyph positions and native rendering are not guaranteed.

Supported static conversion includes pages/backgrounds; frame/group/section hierarchy; rectangles/circular corners, ellipses/arcs, lines; baked SVG path geometry with one common winding rule per layer; solid paints and non-skewed linear gradients; circular radial gradients in normalized object space; uniform centered/inside/outside strokes with supported caps/joins/dashes; supported shadow/layer-blur effects; mask modes (explicit maskType, legacy isMaskOutline true → vector, otherwise alpha) and ordinary blend modes; plain fixed-box editable text. Local IDs are fresh. Local components stay mains and their instances stay live: REST instance layer ids carry the source path, so overrides are computed against the main. Instances of library components stay plain layers. Component sets become variant sets. Auto layout, constraints, independent stroke weights, mixed text ranges, text case, truncation, prototype interactions and flow starting points stay live. Styles are built from the first layer using them, since REST carries no style values, and later layers link when they agree. Booleans keep their operands when those recompute to `fillGeometry`; otherwise the baked path stays. The same settle pass as binary import drops any link that would move stored artwork. Mask-run/effect/text semantics still require source comparison.

`size` plus orthogonal, invertible `relativeTransform` preserves rotation, reflection and nonuniform scale through the shared affine model. Without that pair, absolute bounding boxes with zero/absent rotation beneath translation-only reconstructed ancestry become unrotated editable boxes. This fallback cannot prove absence of reflection or local scaling: a counted pre-open reduction notice explicitly warns that visual parity is not guaranteed. Known nonzero rotation, unsupported ancestry, missing or skewed geometry refuses the entire file; `geometry=paths` is useful when obtaining a response but does not make unsupported transforms or missing geometry valid. Vectors require `fillGeometry`; unsupported node types refuse, including hidden unsupported nodes. Curves keep supplied path coordinates and winding, not live vector networks or Boolean relationships.

Image references carry no image bytes: their paint slot becomes a visible neutral-gray solid with the same slot opacity, explicitly described in review. Unsupported paints, skewed/elliptical gradient geometries also use explicit gray placeholders. Unsupported effects are omitted with notice. Pass-through groups use normal compositing with an explicit reduction notice. Library/variable/component-property/export/annotation metadata, lists, per-region vector fills, variable strokes, advanced typography and unsupported paint/effect compositing are not retained; review describes these reductions. Source IDs, imageRef/URLs, plugin data and API response metadata are not stored in the converted project or diagnostics. Names and text are retained only as authored editable content. No external assets are embedded or fetched by this converter.

Bounds: 20 MB UTF-8 selected REST JSON, 100 pages, 20,000 converted layers and bounded total input-node traversal, 128 hierarchy levels, 100 paints/effects/stops per stack, 128 distinct text families, aggregate 2 MB / 100,000 path tokens and ±1,000,000 local/world geometry. Shared project validation and readable-file limits run before installation. Conversion runs in an owned worker with a 30-second limit, so Cancel stops it at once. The first JSON parse, which recognizes the format, stays on the main thread. Reads and recovery transactions remain abortable. No production/native build or Figma desktop reference round trip was performed for this source pass.

The mapper follows the official [REST node schema](https://developers.figma.com/docs/rest-api/file-node-types/) and [property schema](https://developers.figma.com/docs/rest-api/file-property-types/), particularly normalized gradient handles and `size`/`relativeTransform` versus absolute bounding boxes. Tests use self-authored synthetic responses, never private Figma files or IDs. Core tests cover no source mutation, affine refusal/preservation, paths/holes/Booleans, paint/stroke/effect/mask reductions, schema and work limits. Actual-browser tests cover review before mutation, editable Canvas/Undo/save/reopen, gray/hole export pixels, stale/canceled delivery, denied recovery, repeated/fresh UI receipts and short125% keyboard operation.
