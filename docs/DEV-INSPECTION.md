# Local Dev / Inspect workflows

Select one or more layers, then open the existing Inspect tab. The panel is read-only: its unit, root-size, color, search, source and selected-layer controls use temporary UI state. They do not edit `.oui`, create Undo entries, change inherited component values or assign styles/variables. Inspect now uses temporary export controls instead of the document export-profile editor. Empty Inspect asks for a selection rather than showing editing presets.

## Behaviors

- **UI-41-004 — CSS units selection:** pixels and root em units, with an explicit positive root font size (default 16 px). Converted dimensions, font sizes, spacing, strokes and measurements use that size. Rotation, line-height, opacity and other unitless values remain unitless. Percentages and element-relative em conversion are not offered because their containing-block/font reference is not established here.
- **UI-41-005 — CSS property list:** structured property/value rows, selectable code, row copy, complete CSS copy, search across row names/values/details and copy of the filtered inspection report. The report identifies the value source and layer. Multiple selected layers can be inspected individually through a local selector.
- **UI-41-008 — Color code format:** HEX (including alpha), modern RGB and HSL syntax are applied to supported CSS paints/strokes and inspection values. HSB is not a CSS color syntax and is not offered.
- **UI-41-014 — Applied style inspection:** existing paint/text/effect/stroke style links show their names and authored definition fields beside the materialized base property. Guide style names are included. Style-kind enumeration is generic, so additional validated kinds such as stroke appear when integrated. Missing links are labeled. The panel does not infer a style merely from equal colors.
- **UI-41-015 — Applied variable inspection:** each bound field shows its actual bound variable, resolved value, effective base field and optional Web code syntax. Saved literals are shown for missing references; no binding is invented. Resolved values can differ from effective values because the document solver clamps/derives fields.
- **UI-41-016 — Variable mode inspection:** each local collection shows its effective mode and whether it comes from this layer, a named ancestor, the document or the collection default. Each alias hop uses its own collection's effective mode; default fallback is explicit.
- **UI-41-017 — Alias chain inspection:** named variables, collections and modes are shown in traversal order. An iterative trace detects cycles/missing references and stops after 256 steps by default rather than overflowing the call stack. This inspection guard does not bypass normal document validation, which rejects invalid imported cycles.
- **UI-41-029 — Inspect variant properties:** the applicable main component/set and its variant property values/description appear for a variant, its children or linked instances, using the nearest nested instance context. Orphaned instances do not pretend to have a resolved main.
- **UI-41-030 — Inspect instance overrides:** explicit override keys show actual values and corresponding source values, including pinned values equal to defaults. Selecting a root includes descendant override rows; selecting a descendant limits those rows to that layer. Component property controls distinguish explicit values from inherited defaults. Reference-valued entries use names, and embedded asset bytes are omitted from summaries. Metadata generation stops at 2000 rows with a visible notice; the UI displays pages of 200 rows. Search covers that bounded subset. Names/values, nested summaries and long details are bounded and marked when truncated. Copy refuses reports larger than 1 MB of UTF-8 text and asks for a narrower search or individual row copy. Page-space position comparisons are explicitly labeled because instance offsets differ.

These nine behaviors have reachable local implementations and source/browser validation. Native Figma reference verification remains pending. This is not a cloud library inspector or iOS/Android code generator. See [the Dev Mode workspace](DEV-MODE-WORKSPACE.md) and [Code Connect and code generators](CODE-CONNECT.md).

## CSS and Motion limits

The new Inspect snippet is explicitly approximate CSS for one layer. It uses actual paint/stroke stacks and supported layout metadata instead of only legacy scalar colors. It represents simple solid/linear backgrounds, one solid border, text box styles, basic transforms, padding/gaps, flex/grid tracks and spans. Warnings identify unsupported image/nonlinear gradient fills, rich text ranges, multiple strokes, effects, geometry/masks, negative layout gaps, wrap/stretch/painting differences and video element requirements. Parent transforms, browser text shaping, fill/hug sizing and grid collision behavior can differ. SVG remains the route for vector appearance. No asset data URLs are copied. Imported names/font strings are escaped; selectors have a safe prefix.

Current canvas values follow a sampled Motion pose while Motion is open. The source selector can instead inspect the base document. CSS and measurements use that chosen source; applied styles, variable bindings, modes, variants and explicit override metadata always describe the current base document. Base does not mean a disk-saved checkpoint. The legacy standalone `cssFor` helper/Copy as CSS command is unchanged by this isolated inspector work.

## Validation

`tests/dev-inspection.test.ts` covers units, color/alpha formatting, actual paint/stroke values, safe CSS quoting, grid representations, alias/mode provenance, missing/cyclic/long aliases, variant/main/nested context, property defaults, explicit overrides, filtered reports, redaction, bounded summaries, a 4000-child/40000-override root and oversized copy refusal. `tests/e2e/dev-inspection.spec.ts` exercises real inspector controls, browser clipboard writes/readback, search/copy, unchanged saved documents and Undo, component properties, actual Motion keyframe/base selection, missing links, multi-selection, temporary export controls, a 1200-child root with pagination and an actual oversized-copy refusal.

No model migration, MCP protocol change, new package, native build, release archive, website change or feature-register regeneration is included. Native macOS clipboard and a real Figma reference round trip are not established by browser tests.
