# Font loading status and guarded font actions

Font loading is session state, not document metadata. The shared status store reports actual catalog checks, cache registration, bundled/Google downloads, embedded project fonts and imported-font registration. Each overlapping operation keeps an independent identity; newer registrations retain the existing generation ordering. Pending family downloads remain deduplicated. Active operations remain visible and the last 40 settled tasks are retained. The compact top-bar indicator counts distinct active family/task labels, opens the font library, and reports recent failures after active work finishes. The library shows source, phase, ready/failed/unavailable/superseded outcomes and actionable download/catalog retry controls. No byte percentage is invented.

An unavailable lookup means there is no downloadable catalog/cached family; an installed family can still be usable. This differs from a failed request or rejected FontFace registration. Installed-font discovery remains native-only; fallback detection retains its existing browser approximation. A successful retry reloads the actual catalog/cards or font specimens and clears the corresponding local action error. No files are newly bundled, no font permissions are broadened and no installed proprietary font files are copied.

Apply captures the exact document object, page, selection, mode and modal before the first await. Font-library Apply calls this guarded path directly, rather than preloading and then using the current selection. A temporary departure and return permanently invalidates the invocation. Motion, Home, hidden UI, another dialog, a document edit/reload or a new selection refuse the pending action with a review/retry message. Subscription cleanup runs on success and failure. Retained library handlers also validate their original render context before requesting a download. Only unlocked selected text and unlocked ancestors may be changed; ordinary component text overrides remain supported. Successful library Apply closes its own captured Fonts dialog synchronously with completion, and never closes a newer dialog.

Replace all uses keeps its existing explicit scope: every page, rich range, fallback stack and reusable text style in the captured document. It does not acquire a different document after downloading and does not introduce a selected-layer or new lock filter to this global replacement action. Its context and interruption proof is the same as Apply. Both paths use existing document transactions, Undo, validation and compatible .oui persistence; no schema migration or special MCP endpoint is needed.

Font downloads/registration are global resources and may finish even after an editing action is canceled. A font completion can also trigger ordinary project metric refresh. If that refresh changes the source document during the wait, the conservative context proof rejects applying the requested edit; retry after loading finishes. The font cache and status can still show successful loading. Automatic metric reflow retains its existing progressive-blur safety/refusal behavior. No cancellation or rollback of a font already installed in the current browser session is claimed.

Validation covers delayed successful Apply with Undo/save, inherited locks, managed text overrides, all-use replacement, exact source preservation after document/selection/mode/modal/Motion/Home/UI changes and away/back cycles, retained handlers, newer dialogs, real bundled FontFace loading, request failure/retry, catalog retry repopulation, overlapping status identities and bounded history. Existing font browser/import/fallback/progressive font-safety checks remain part of acceptance. Native WKWebView UI acceptance and Figma reference parity are separate; this source pass creates no app builds, archives, release packages, website or download updates.

Status recommendation: UI-53-006 Font loading status has a reachable shared implementation. This does not complete unrelated font acquisition, full OS discovery or Figma interchange requirements.
