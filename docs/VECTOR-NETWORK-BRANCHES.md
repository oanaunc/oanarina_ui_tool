# Stroke-network branches

This page describes the shared-vertex graph editor and version 1 forests. Cycles, faces, holes and crossings are in [VECTOR-NETWORK-FACES.md](VECTOR-NETWORK-FACES.md), which replaces the refusals and appearance limits stated below wherever they differ.

Select an independent open contour path, then use **Vector → Convert to stroke network**. Enter ordinary point editing first if the path has not yet been represented as contours. Conversion preserves the path coordinate box, transforms, active cubic controls and stroke appearance; each source anchor becomes an explicit vertex. Graph vertices and edge identities belong only to that layer. There is no inferred merging of coincident points.

**Edit network** opens dedicated canvas controls. Drag a vertex to move every incident edge. Select an edge to edit its two independent tangent handles on the canvas or with numeric offsets. **Draw network branch** lets you drag from an edge interior: exact de Casteljau subdivision creates a shared junction and a new straight branch. Dragging from an existing vertex adds an incident branch without subdividing. Vertex coordinates can also be entered numerically. Delete a selected edge with its inspector button or Delete/Backspace on the canvas; only newly orphaned vertices are removed. Delete/Backspace with a vertex or no edge selected reports how to choose an edge; it never falls through to layer deletion while this editor is active. The final edge is preserved until the user finishes network editing and explicitly deletes the whole layer.

**Flatten network to contours** creates one ordinary open contour per edge. Appearance remains a single compound stroke, but coincident endpoints become independent. Undo restores the graph. All graph edits commit once on release; transient geometry stays outside the document. Escape, Space during dragging, source/session changes, camera changes, Motion, modal changes, capture loss, matching pointer cancellation, blur, visibility interruption or resize cancel the draft. Secondary pointers cannot steal the gesture. Numeric controls, dropdowns and buttons have source and local-session receipts, including away/back transitions; fresh controls recover after a refusal.

## Supported geometry and appearance

- Graph-only geometry on a leaf `path`: 2–256 vertices, 1–256 edges, no cycles or orphan vertices, maximum junction degree 16. Distinct vertices cannot be coincident. Straight lines and cubic edges are supported. Self-crossing curves, collinear retracing, independent endpoint/interior touches, overlapping edges and crossings without an explicit shared vertex are rejected rather than automatically merged.
- Exactly one positive solid centered stroke, with round caps and round joins; no visible fill, dashes, independent edge widths, profiles, dynamic/calligraphic strokes or markers. The native renderer paints all edge subpaths in **one SVG path**. Stroke/layer opacity therefore composites once at shared junctions, including translucent paint.
- Independent Design layers under at most 64 total hierarchy layers. Cached affine matrices include reflections, signed scale and the existing path basis. Static movement, rotation and positive finite resize preserve graph metadata and use the same shared renderer; collapse or unsafe envelopes refuse atomically. The original coordinate/layout box stays fixed while graph vertices can extend beyond it; exported artwork bounds include the control hull plus stroke. Layout-box selection/fit is not a paint-tight graph fit.
- No component definitions/instances, managed ownership, affected Motion tracks, booleans, mask paint runs, clips, visible effects, auto-layout ancestors or Whiteboard/Slides graph authoring. Smart animate of affected subtrees is refused; static supported presentation remains available. Unsupported placement or style/controller changes refuse before publication.

Coordinates/control offsets are finite within ±995,000; local/world stroke envelopes stay within ±1,000,000. Document limits are 64 networks, 8,192 total vertices/edges and 100,000 edge-pair checks. A page containing a network supports at most 20,000 layers. These are joint limits: a file can reach its pair-test budget before reaching its vertex budget. Intersection tests use the existing Paper cubic kernel and bounded geometric tolerances, not an arbitrary-network exact-predicate engine. SVG presentation uses the same five-decimal convention as ordinary contour paths; saved graph coordinates retain doubles.

## File, export and interchange boundaries

`DesignNode.vectorNetwork` is optional and remains readable in `.oui` versions 1 and 2. Absent metadata leaves ordinary path behavior and default SVG bytes unchanged. A graph stores stable vertices, edges and relative per-edge controls; the ordinary `path` string is a deterministic, strictly validated appearance fallback, not a second editable geometry source. `points` stays empty and `contours` absent until flattening. Older readers that ignore graph metadata can therefore still render the saved stroke through the ordinary path route; editing it in an older reader is not a supported graph round trip. Any mismatch between saved graph and fallback refuses import or mutation. Imports validate structure/counts before intersection/ancestry work. Store edits, runtime variable derivation, canvas drafts and source MCP transactions check the graph before expensive derivation and again before publication where applicable.

SVG/PNG appearance exports use the shared graph path and conservative cubic control bounds. SVG reimport produces ordinary editable geometry; it does not reconstruct graph identity. Editable Figma Bridge import explicitly refuses graph metadata before creating a page and asks the user to flatten first. Binary `.fig` graph interchange is not claimed. Generic Boolean, offset, outline, normalization, cut/eraser and ordinary point-topology workflows require explicit flattening. Source MCP can read/full-replace a valid graph and perform valid ordinary pose/style updates; generic `update_node` does not accept the graph metadata field. Invalid mixed transactions leave the saved file unchanged. Clipboard/page copies retain local graph IDs inside separately remapped owner layers. Graph geometry is not a reusable style or component-library feature.

## Validation evidence

Kernel/model/action tests cover exact cubic and straight subdivision, shared vertices/independent handles, edge deletion/orphans, coincident/crossing/overlap/retracing refusal, no-ops/Undo, `.oui` 1/2, derived styles/variables, owned copy remapping, atomic Bridge rejection and cached 20,000-layer/256-anchor preflight. Actual browser checks cover gesture/preview/Undo/save/reopen, conversion/flatten raster equivalence, T-junction alpha, zero-delta legacy ordinary-path fallback raster equivalence, SVG reimport, numeric edits, cancellation, retained handlers, secondary pointers, native keyboard activation and repeated 125% reflected/nonuniform affine hit testing. Source MCP separately verifies safe pose updates, Undo and atomic unsupported edits. No app or download build is produced by this pass.
