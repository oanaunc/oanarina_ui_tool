# Conservative canvas viewport culling

Preferences → **Canvas performance → Cull distant canvas layers** enables a local rendering optimization for the Design/Whiteboard canvas. It is on by default, including migration of earlier version-one preference snapshots. It is saved in local preferences, outside `.oui` documents, and can be switched off without changing artwork or history.

The canvas omits a complete root layer and all its descendants only when their supported painted bounds lie entirely outside the visible SVG viewport plus a 128-logical-screen-pixel margin. A selected descendant keeps its whole ancestor root rendered. Point-editing and active text targets also keep their roots. Gesture draft scenes, sampled Motion, normal/mask outlines, mask-mode previews and non-Design views use the complete scene. The initial unmeasured viewport also uses the full scene; a ResizeObserver then tracks the SVG's logical client size as the window, panels and interface scale change.

The full original node array remains available to layer navigation, selection/marquee planning, guides, names, overview, creation/transforms, history, saved files and all exports. Culling changes only the node list passed into the existing canvas Artwork boundary. It removes the omitted subtree's draw groups and local definitions together, preserving the original flat ordering and parent relationships of everything retained. Shared Artwork, mask compositing, SVG generation and export defaults are unchanged. Source selection and ordinary exports do not become viewport-limited.

Supported bounds cover boxes, ellipses/arcs, polygons/stars, ordinary self-contained image/gradient/pattern fills and contour-based vector geometry. Cached parent affine matrices include rotations, reflection and nonuniform scale. Cubic control hulls conservatively include curve overflow; uniform/independent-edge strokes use an intentionally broad miter/cap envelope, including zero-axis lines. Descendant bounds are unioned without shrinking by parent clips, so overflow cannot be lost by a guessed clip box.

Uncertainty keeps a root rendered. Text/font ink, video, effects, live Booleans, nested masks, arrowheads, variable/dynamic widths, raw path strings without editable contours and nonfinite/extreme bounds retain their complete root subtree. Any root-level sibling mask keeps the entire scene, because removing a sibling could alter a mask run or its shared region. Ordinary SVG image fills are still self-contained image resources, not arbitrary cross-layer resource definitions. This pass does not attempt glyph-specific bounds, effect-envelope proofs, mask occlusion, child-level culling or hidden-resource scheduling. Future backdrop/shader or other cross-root sampling/resource features require a new culling safety review before use: retaining an effect owner alone is not a blanket guarantee for future cross-root dependencies.

Index preparation uses Maps and cached ancestry rather than a full-page search for every node. It supports 20,000 nodes, cumulative depth 256, 200,000 contour points and 100,000 stroke entries per page-index operation. World envelopes beyond ±1,000,000,000 are retained. Invalid identities/graphs, unavailable viewport data and exhausted work budgets fall back to the full scene. Disabled draft views skip index preparation entirely. A cached index belongs to its exact immutable source array. Private canvas attributes expose omitted node/root counts, retained-uncertain-root counts and a fixed fallback reason for diagnostics; no file bytes, paths, names or URLs are reported.

UI-53-003 remains **partial**. This is conservative root-subtree culling for the shared Design/Whiteboard canvas, not a general renderer replacement, progressive page loader or image decode queue. Complex and large single-root scenes can therefore see little or no reduction. Native WKWebView performance and exact Figma reference acceptance remain unverified. No app build, native binary, package, release archive, website or document schema change is produced.

Validation includes pure affine/control-hull/stroke/padding cases, cumulative hierarchy/work limits, 20,000-root linear work accounting, exact source preservation and stale-index fallback. Actual Chromium checks compare viewport PNG bytes with culling on/off for supported overflow and retained effects/masks/text; assert distant draw groups and definitions are actually absent; exercise pan/zoom/window resize/125% interface scale, selected-child navigation, draft Escape/commit/Undo, native Space on the preference, persistence and unchanged full-document SVG output. Existing selection, contrast and missing-image diagnostic workflows are checked alongside the new controls.
