# Deterministic dynamic strokes

This covers UI-16-015 (stroke wiggle) and UI-16-016 (frequency). It is an independent Forma width-wave implementation, not verification of Figma's unpublished dynamic-stroke geometry.

Waves run on open and closed contours, straight or curved. Samples are exact splits of the source curve, so generated geometry stays cubic, and an integer frequency keeps a closed wave periodic across its seam. Up to 128 source and 512 generated anchors. Effects, masks, instance copies, layer Motion and anchors outside the layer box no longer refuse; live Booleans still do. **Smoothen** averages the profile over a fraction of one cycle, and **Irregular bumps** swaps the sine for repeatable irregular cells that wrap at a closed seam. Older builds refuse a wave on a curved or closed contour. Any statement below that says otherwise is superseded.

Select one Design contour path and expand **Stroke → Dynamic stroke · Forma wave**. The existing stroke must be solid and centered, with bevel/round joins and butt/round/square caps. Enable **Vary stroke width**, edit **Wiggle (%)** or **Frequency**, or disable the option to return to a uniform stroke. Invalid settings give a local message. Unsupported source shapes show the reason before activation. Each successful change is one Undo; identical values do not create history. Numeric controls retain the existing arithmetic, keyboard and scrub interactions.

## Geometry and persistence

Optional `StrokeStyle.dynamic: {wiggle, frequency}` is saved in existing `.oui` version 1/2 documents. Wiggle is finite 0–1; frequency is an integer 1–16. The source contours are unchanged. For each open contour, local arc length determines the symmetric full-width ratio `1 + wiggle × sin(2π × frequency × distance / length)`. Sixteen samples per cycle and every original corner form a deterministic piecewise-linear width profile. Candidate distances closer than 0.000001 local units merge in favor of an original corner; original corners are never displaced. This is bounded polygonal geometry, not an exact smooth/noise algorithm. Maximum wiggle may reach zero width; degenerate fill pieces are omitted without NaN or overlapping alpha accumulation.

Shared Artwork renders the sampled profile through the existing nonzero compound filled-outline renderer. Caps and joins use the same tested geometry as point widths, so opacity applies once to the union. SVG/PNG/PDF and live surfaces use the same silhouette. SVG reimport retains editable filled geometry and appearance, not the original dynamic settings. The original fill and source pose remain separate. Maximum width `base × (1 + wiggle)` participates in shared visual/export bounds and stroke-in-layout; square-cap bounds use the existing conservative √2 envelope. These bounds are conservative rather than paint-tight.

Absent optional metadata follows the unchanged uniform-stroke path. Creating, editing, copying and reopening a supported profile keeps its centerline, settings and pose. Imports, source MCP updates and editor transactions validate the optional fields before publishing; malformed multi-operation MCP edits leave the saved file unchanged. Editable Figma Bridge transfer explicitly refuses dynamic strokes before any Figma mutation; use rendered SVG or PNG for appearance transfer. No direct binary `.fig` support is implied.

## Supported limits and refusal

- One positive-width saved solid stroke on a leaf path, 1–16 open straight contours, 2+ anchors per contour and at most 128 original anchors. Both authored coordinate dimensions must be positive. Anchors remain inside their authored box; near duplicates, reversing corners and live topology/normalization conversions refuse until dynamic strokes are disabled.
- At most 512 generated anchors per path. High frequency combined with many contours/corners can exceed this limit; reduce frequency or simplify the source. A uniform sampling interval below 0.00001 local units refuses rather than aliasing away frequency cycles; reduce frequency or enlarge the path. Validation allocates only the bounded candidate set.
- At most 20,000 layers and 16,384 conservative generated-anchor work units on a page containing dynamic strokes. The page work estimate includes original anchors plus sixteen samples per cycle per contour, including endpoints that may merge. It is an upfront work budget, not an exact output count. Ancestry is checked with one node map, a 256-layer depth cap and no per-sample page searches.
- Maximum full width is 10,000 local units, with the shared ±1,000,000 local cap envelope. Authored dimensions are limited to 995,000; an individual cap envelope can require a smaller size. Signed/rotated/nonuniform affine ancestry and path-basis scaling are supported.
- Dashes, independent edge widths, point-width profiles, arrowheads, curves, closed/branching networks, automatic layout on the path itself, visible effects, components/instances and live Booleans are outside this pass. Pages containing any masks refuse while dynamic profiles exist. Any nonempty Motion track on the path or an ancestor refuses, including hidden tracks. Motion must be closed to edit the settings. Prototype Smart animate refuses dynamic-stroke subtrees before a transition starts, including potential spring overshoot; instant/dissolve/move presentations remain available. Ordinary unanimated transform scales remain supported.
- Reusable stroke styles cannot capture or silently overwrite geometry-local dynamic settings. Explicitly disable the option first. Normal stroke color/width tokens may remain bound; final derived-state validation still enforces the maximum width and supported topology. Inspector edits detach competing stroke styles through the existing property-editing rules.

Retained inspector callbacks become permanently invalid after document/page/selection/mode/modal/Motion/tool/UI-scale or mask-inspection changes, including away-and-back cycles. Fresh controls recover. Inherited locks refuse edits. The common canvas draft publisher validates supported dynamic geometry before preview, so a drag outside the supported box cancels without publishing invalid geometry or crashing Artwork.

## Reference boundary

Figma's official [stroke properties documentation](https://help.figma.com/hc/en-us/articles/360049283914-Apply-and-adjust-stroke-properties) describes Frequency as bump count, Wiggle as bump size, Smoothen as jaggedness control, and centered-only dynamic strokes. [Introducing Figma Draw](https://www.figma.com/blog/introducing-figma-draw/) also describes a hand-drawn dynamic appearance. Forma implements real adjustable width waves for the bounded inputs above. Exact Figma noise, Smoothen, arbitrary cubic/closed networks, dynamic-stroke animation and calligraphic brushes remain unimplemented here.
