# Fine pointer adjustment and rotation feedback

After beginning a move, resize, rotation, vector-anchor or vector-handle drag, hold **Control** for ten-times-finer adjustment. Release Control to resume ordinary sensitivity. Movement integrates incoming world-coordinate deltas; toggling sensitivity does not rescale distance already travelled. Fine adjustment bypasses object/pixel/guide snapping and angular increments. Existing Shift axis/aspect constraints, Option-centered resizing, parent transforms and Motion editing still apply. Releasing precision can restore ordinary snapping at the pointer's effective position.

The canvas hint identifies Control precision. A transient readout identifies precision and disabled snapping. During rotation it shows the actual stored angle and signed change for a single selected layer, or the applied world-angle change for a multi-selection. Shift snapping is reflected in that displayed value. Angles can retain full accumulated turns. Readouts are canvas chrome, excluded from document data, history and exports; intermediate previews do not save as artwork.

Move/resize/rotation previews now use the same cancellation checks as vector/drawing previews. Escape, window blur/resize, hidden-document state, pointer cancellation/lost capture, changed camera, selection, page/document, modal, tool, mode, Motion time or source nodes discard an unfinished gesture. Successful edits continue through the existing validated store and Motion Auto-key pipeline with one Undo entry. Inherited locks and layout/component solving are retained; precision does not bypass those solvers. Drawing/freehand/marquee and pan gestures keep their existing sensitivity.

Use Control after pressing the pointer down to avoid macOS Control-click context-menu behavior. Browser interaction tests establish the shared editor behavior; native WKWebView/trackpad and exact Figma reference acceptance remain pending under the build freeze.

`tests/pointer-precision.test.ts` covers no-jump integration, reversals/fractional coordinates, finite-input guards, actual/delta rotation labels, transformed hierarchy motion and aspect/lock solving. Ten new browser cases exercise fractional move/save/Undo/Redo, unchanged documents during preview, sensitivity changes, fine resize, snapped/fine rotation readouts, cancellation, transformed vector points and actual Motion keyframe changes. The existing canvas-transform and Motion-vector cases also pass. No schema, MCP protocol, native permission or release artifact changes are required.
