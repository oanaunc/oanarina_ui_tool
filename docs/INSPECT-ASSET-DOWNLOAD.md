# Download the inspected asset

Inspect → **Download asset** offers read-only SVG, PNG and JPG downloads of the layer currently chosen in inspection, including its export subtree. Temporary format/1–4× controls do not change its saved profiles. A separate selector uses any existing profile with its format, sizing, suffix, bounds, visibility and conversion choices. Existing empty profile lists remain empty. Multiple selections use the inspected-layer chooser; locked artwork can be downloaded without unlocking or changing it.

The feature reuses Forma's existing layer export geometry, embedded-image validation, SVG generation and raster encoder. Hidden or broken assets and unsupported conversion profiles report the existing explicit refusal. It does not silently switch target or omit a failed image. The source walk is bounded before exporter preparation: 20,000 page layers, 50 MB of conservatively estimated page JSON, four million values and 64 nested data levels. Raster output retains the existing 16,384-pixel edge/80-million-pixel limit, and encoded output retains its 100 MB limit. Larger source pages can use the regular export workflow within that workflow's own limits.

No design metadata, profiles, selections or Undo history change. Source/selection/mode/dialog/Motion context, inspected target and local options have permanent receipts; stale callbacks cannot revive after an away-and-back cycle. The renderer task supports cancellation and a 30-second preparation timeout. A final optional callback in the existing download helper rechecks the source after asynchronous binary encoding and immediately before a browser download or native save handoff. It adds no native method or IPC permission. Once a native save panel opens, cancellation belongs to that panel; Forma cannot revoke a save the user subsequently completes there.

UI-41-018 is **partial**: this path requires Motion closed and exports base artwork through the supported local formats, without cloud permissions, a plugin asset environment or a complete Dev Mode workspace. It does not claim direct binary Figma export, paint-tight arbitrary-font equivalence or native save-panel acceptance from an API mock. Existing SVG/Bridge and font limitations still apply.

Validation covers real browser SVG/PNG/JPG downloads and raster pixels, saved-profile sizing/names, locked artwork, multi-selection target choice, no project/history changes, native Space activation, retained callbacks/fresh retry, late native-encoding refusal, cancellation, hidden/broken-image errors, Motion refusal and bounded source data. Native-adapter cases are browser mocks of the existing API, not native runtime tests. No app build, installer, signed package, release archive or website change is created.
