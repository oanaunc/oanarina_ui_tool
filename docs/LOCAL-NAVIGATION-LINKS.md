# Local file, page and prototype-flow links

**Status: partial local-only workflows for UI-03-019, UI-05-015 and UI-31-016. Reference verification remains pending.** The editor header and Home expose **Local links**, with Copy local file/page/flow link and an explicit paste → Review → Open workflow. These are not public URLs, remote sharing, an OS protocol registration or a request for access permissions.

## Identities and privacy

`forma-local:` encodes an exact version-1 array containing only its file/page/flow kind and scoped document/page/flow IDs. It carries no paths, names, private notes, comments, author/profile data, binary assets or document contents. Links are bounded to 4,096 characters and identifiers to 1–512 UTF-16 code units. Unknown versions/kinds, extra values, non-string or empty identifiers, malformed escapes and ambiguous/missing targets refuse before navigation. The `.oui` model is unchanged; links and transient presentation requests are not added to documents, clipboard artwork, library publication, exports, Bridge or MCP documents.

Review first uses the current unsaved document when its ID matches. Otherwise, the **browser** looks up only the exact ID in the existing local Forma repository. It does not enumerate other files or read paths/network resources. The target is validated, excludes Trash/deleted files, and shows its bounded display names/workspace/page/flow before the explicit Open action. On **Mac**, cross-file links instruct the user to open the matching `.oui` file first; current-file copy and navigation work without adding native IPC or changing native save associations. There is no automatic URL dispatch or clipboard read.

## Navigation and preservation

Current-file file/page navigation changes only editor selection/page/camera/focus; document identity, contents and document Undo history remain unchanged. A file link keeps the current page when already in that file; a cross-file link uses the saved file's first page. Page navigation fits visible authored layout boxes using cached world transforms, including rotation, reflection and nonuniform scale. It is a layout-box fit, not an estimate of clipped/effect paint bounds. The fit is applied after the normal saved-page viewport restoration. Slides retain their existing workspace presentation behavior.

Browser cross-file Open follows the existing file-import retention policy. Dirty current data, including zero-history RAM/imported documents, must be saved and byte-for-byte verified in local recovery before replacement. A final read/write transaction checks the exact reviewed target payload and its untrashed state, then updates only active/recent-file metadata. It never revives Trash or rewrites target artwork. Context loss aborts pending storage work and prevents delivery. Browser reload therefore points at the accepted saved target. Opening a different document resets that editor's Undo history as ordinary file opening does; the previous document is durably retained, not turned into an Undo entry.

The repository now records a constant-size private active-generation token alongside its existing active ID. All existing active writers route through one helper; ordinary active values and document/schema semantics stay unchanged, and a legacy absent token is valid. A reviewed-open receipt is one-use. If source context expires after metadata commit, rollback restores the prior active pointer only while the generation remains owned by that transaction; it never overwrites a newer writer. Its target recent-file record restores only while the same owned generation and exact record still match. A typed rollback failure surfaces a generic current-window toast even when its source receipt expired, so it cannot silently leave a wrong reload target. Once synchronous UI delivery begins the accepted pointer cannot roll back underneath partially published editor state.

## Exact flows and source lifetime

Flow links identify a saved flow ID independently from its starting frame. A transient exact-document/page/flow request initializes the existing shared prototype presenter, including multiple named flows sharing one frame. Dropdown selection and Restart retain that exact flow. Closing or leaving its source context clears the request. Authored flow order, description, duration, easing, reduced-motion settings and saved document remain unchanged. Ordinary presentation keeps its existing default route when there is no link request; existing rendering/interaction limitations of that presenter are unchanged.

Permanent source receipts, local draft/selection generations and independent asynchronous operation receipts prevent retained handlers from reviving after source, mode, modal, page, selection, draft or picker changes and away/back cycles. Invalidated reviews must be reviewed again; fresh controls recover. Clipboard completion messages also require the original current context. Copy uses the existing clipboard API; blocked clipboard access leaves selectable link text for Command-C. Dialog focus, native button Space/Enter, Escape, Home access and a short 125% viewport are covered by browser checks.

## Bounds and remaining limits

Local link operations support up to 1,000 pages; flow operations up to 1,000 flows and 20,000 layers on the target page. Geometry navigation supports 20,000 nodes, at most 256 acyclic ancestor levels, finite transforms/positions within its stated 1e12 navigation budget, and refuses empty layer/parent IDs rather than treating them as a different root. Large display names are elided to 200 characters. Existing documents remain readable; these limits constrain link workflows only. Saved cross-file payloads are capped at the existing 50 MB open boundary.

Public/team links, arbitrary filesystem resolution, cross-device matching, native cross-file dispatch and real Figma link parity remain unimplemented. Local IDs can coincide in independently copied `.oui` files; the current document is deliberately preferred, and cross-file IDB opening requires reviewing and accepting the saved local record. No new native permission, server, OS scheme, remote service, production build or release archive was added.
