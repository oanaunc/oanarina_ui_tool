# Text find and replacement

Text → **Find and replace text…**, Actions, or Command-F on Mac opens a literal base-text search. Search the page, the whole file, or the selected layer trees captured when the dialog opened. Case matching, Unicode word boundaries and hidden-layer inclusion are available. Results identify their page/layer, show a text preview and can reveal the corresponding layer, including another page or slide. Search and reveal leave document Undo and saved artwork unchanged.

Replace one match or all editable matches in one Undo transaction. Inherited locks remain read-only. Unaffected rich text is retained; inserted replacement text inherits the first matched character's formatting. Supported whiteboard author/connector metadata stays synchronized. Main component edits can update instances. Managed values that would overwrite a requested replacement are refused atomically; edit their property/workspace control instead. Changes persist in ordinary .oui saves without a version change.

Command-F commits a focused text draft before opening. Within the dialog it selects the query; Mac Control-F retains its normal editing behavior. The dialog keeps keyboard focus local, closes with Escape and returns focus to the canvas. The native Text menu uses the same command.

Limits: literal base strings rather than regular expressions, locale-specific collation or generated text at a motion keyframe. Close the motion timeline before replacing. Whole-word checks use Unicode letters, numbers, marks and connector punctuation, rather than a complete language-specific word-break engine. Replacement cannot split a surrogate pair. Query length is at most 512 UTF-16 units, replacement 100,000, results 10,000 and aggregate replacement growth one million units. Capped searches require refinement before Replace All. Results display 100 at a time. The existing 50 MB saved-file ceiling also applies. Component-derived values may be refused rather than silently lost. Reference verification against Figma remains pending.

Evidence: `tests/text-search.test.ts` covers literal/Unicode matching, scopes, inherited locks/visibility, bounded results/growth, rich-run splicing, Undo/redo, persistence, stale/invalid atomic refusal and managed values. The four production browser checks in `tests/e2e/text-search.spec.ts` cover replacement/save/reopen, scope controls and cross-page reveal, draft/keyboard/lock handling, and slide reveal. Native menu dispatch is checked in the isolated standard smoke path.
