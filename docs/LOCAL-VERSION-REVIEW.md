# Local saved-version review

File → Version history lists named snapshots on this device. Preview any saved version, choose its historical page, compare it with the current file, restore the complete project in one Undo step, or duplicate the reviewed version as a separate local file. A duplicate stays in All files; it does not replace or open over the current design. The existing named-save action still retains the latest 20 valid snapshots per file. Important versions need portable .oui backups.

The historical preview uses the shared bounded, isolated Artwork cover renderer with the saved base geometry and page background. It does not register historical fonts, play media or change the live editor. Preview pages support 500 layers/4 MB scene and embedded SVG/font data; missing/conflicting or restricted fonts and unsupported extents produce explicit diagnostics. Platform font metrics may differ. A file-cover choice is not mistaken for the full historical page preview. This is a structural review, not a pixel-perfect visual diff or Figma/native reference claim.

Comparison matches stable page/layer IDs, counts added/removed/changed/moved layers, records page changes and document metadata changes, and names changed layer fields. Reordering common layers produces a named layer-order change even when every layer property is identical. Object key insertion order and updated timestamps do not create changes. Arrays retain their authored order; derived geometry is compared literally. Reports contain layer/page names and field names, never property values, comment bodies, resource URLs, embedded image/font bytes or a made-up version author. Counts cover the complete comparison while the list shows at most 200 entries. Each validated document supports 50 MB/100,000 layers for comparison and two million property visits; over-budget comparisons refuse locally.

History browsing returns only validated lightweight headers and releases each cursor's document value. At most 200 stored entries are inspected; abnormal excess history is explicitly disclosed. Invalid name/date/identity headers are hidden with a diagnostic, without removing any stored data or crashing the editor. Full snapshots are read on demand and validated against the current document identity before use. Valid new saves trim only valid old snapshot records; malformed stored entries are preserved for recovery rather than silently purged. Existing version metadata without new fields remains compatible.

Restore replaces the complete validated project object rather than merging it over newer optional metadata. Covers, library provenance, resources and other optional fields absent from the older project disappear; exact saved library baselines and component override lists are preserved instead of treating restoration as a synthetic component edit. It preserves document identity, updates the modification time, clears transient selections/vector/Motion state and appends one ordinary history step. Undo returns the exact previous document. A semantically unchanged restore adds no Undo entry. Restore is unavailable with Motion open or on Home.

Async reads/writes stay attached to the original document/page/selection/mode/modal context. Same-event away/back changes permanently invalidate retained handlers; abortable IndexedDB writes stop on context changes, and completion never replaces a newer dialog. Named-save submission prevents duplicate in-flight requests and validates the full project/name before mutation. No schema version, native IPC permission, account/hosted sharing, collaboration attribution or external request is added.

Source acceptance in the isolated worktree passes 1,835 core checks across 156 files, editor/MCP TypeScript, 70 source MCP checks and 23 actual browser cases (ten new version checks plus recovery/repository/Home workflows). Tests include value-free change summaries, stacking-only changes, corrupt headers and document ownership, full optional-metadata restore, exact clean library baselines, one-step Undo, genuine save/reopen, independent duplication, actual aborted repository writes, newer-dialog preservation and keyboard containment at 125% UI scale. Independent review cleared the ordering and malformed-header corrections. A generated brush study was also checked through the real app: its saved historical artwork remained intact and a subsequent orb-color edit appeared as the sole changed layer in the comparison. Combined acceptance after integration is recorded separately. No app build, installer, release/archive refresh or website deployment is part of this source workflow.
