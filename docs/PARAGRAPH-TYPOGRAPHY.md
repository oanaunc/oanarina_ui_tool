# Paragraph formatting and nested lists

Forma now supports paragraph overrides in the Character formatting inspector. A caret targets its paragraph, and a selection targets every touched paragraph. Alignment, line-height multiplier, paragraph gap, paragraph indent, list type, number format, number suffix, composite numbering, custom bullet, nesting level, nesting indent, marker gap, item gap, hanging markers and a numbered-list restart are reachable controls. Indent/Outdent operate on each selected paragraph's own level. Clear paragraph overrides returns to the layer's defaults. These operations preserve source text, share Undo/Redo, save in `.oui`, and refuse inherited locks, Motion and stale editor contexts.

## Data and layout

`paragraphStyles` is an optional ordered array of paragraph-start offsets and validated style overrides. Entries must point to position zero or a position immediately after a newline, including an empty final paragraph. Up to 10,000 overrides and nesting levels 0–8 are supported. Empty paragraphs, surrogate pairs and trailing blank paragraphs remain ordinary source text. Text insertion splits a paragraph's formatting onto the resulting paragraphs; joins retain the surviving leading paragraph, while fully deleted paragraphs disappear. Deleting all text retains the first paragraph's override for the empty caret paragraph. Ordinary inspector edits, variable text updates and component materialization use the shared reconciliation path. Explicit metadata edits are validated before commit.

Paragraph overrides affect the same line-layout model consumed by canvas text, SVG and raster exports: width measurement, wrap gutters, baseline advance, item/paragraph gaps, text alignment, vertical alignment, auto dimensions and ellipsis. Superscript/subscript spans use relative numeric `dy` deltas so all styled runs remain in one SVG alignment chunk. This also fixes previously overlapping mixed-font runs in centered/right-aligned text.

Nested numbering counts independently at each level and restarts after a plain paragraph; explicit Restart number at resets a paragraph's counter. Number format is per paragraph: decimal, lower/upper alpha (z is followed by aa), lower/upper Roman (values above 3999 stay decimal, as CSS Roman counters do) or Outline, which cycles 1, a, i by level. Suffix is `.`, `)`, `:` or none. Composite numbering joins every enclosing numbered level with `.`, each in that level's own format, and skips bullet levels, so `1.A.i.` reads through mixed formats. Bullet glyphs cycle through filled disc, hollow circle and square unless a custom bullet of one to eight visible characters replaces the cycle. The new fields `listCounter`, `listComposite`, `listSuffix` and `listBullet` are optional paragraph overrides, absent from existing documents and from reusable text styles; the Figma Bridge validator accepts them and reports them with the other omitted list metadata. Hanging markers occupy a separate measured gutter, so continuation lines align with the item text. Paragraph indent offsets the first line of plain text and the complete hanging gutter of a list item. Item gap adds to paragraph gap after an item; it does not alter line spacing within a wrapped item. A hanging marker inherits the first character's face/color and shared layer paint behavior. Font subset requests retain marker glyphs for rich font runs.

Existing documents without new metadata retain their previous inline list rendering. Existing normal-text and list outline signatures remain compatible until a new setting changes appearance. Layer defaults `listIndent`, `markerGap`, `listItemSpacing` and `listHanging` are additive. New and updated local text styles record an explicit no-list default when their source is plain, while legacy styles with an omitted list type retain their old semantics. Local text styles can carry these defaults and list type; paragraph offsets are content-specific and are deliberately excluded from reusable text styles. Instance overrides and bounded MCP operations support paragraph metadata and the new defaults. No document format-version change is required.

## Checklists

List offers **Checklist** beside bulleted and numbered lists. A checklist line is a bullet with a state, stored as the optional `listChecked` paragraph field, so indent, spacing and hanging markers work as they do on any list. **Checked** sets the state of the selected lines. A line split from a checked line starts unchecked. Choosing another list type clears the state. The box is a text character, so it takes the layer's color and any export that keeps list markers keeps it.

## Keyboard list editing

The rich text inspector editor and the canvas text editor share `src/list-editing.ts`. Enter on a non-empty item creates the next item through the ordinary paragraph split, which inherits the item's formatting; an explicit restart stays only on the first part, so splitting a `5.` item produces `5.`, `6.` rather than two fives. Enter on an empty item moves it up one level, then out of the list. Tab and Shift+Tab change the level of every touched list paragraph, bounded to 0–8 and consumed at the bounds. Backspace with a caret at an item's start removes its marker and keeps the text. Shift+Enter, modified keys, IME composition, selections for Enter/Backspace and plain paragraphs keep native behavior, so Tab still moves focus outside lists. In the inspector editor, Escape releases the next Tab so keyboard focus can leave a list. List key edits commit immediately and form one Undo step each; the field's own Command+Z remains the browser's text undo, so document Undo applies after leaving the field.

## Clipboard and interchange limits

Forma's rich clipboard JSON and its HTML with validated Forma paragraph metadata preserve effective paragraph settings. Pasting into the middle of an existing paragraph keeps that leading paragraph's formatting; newly inserted paragraphs receive the copied settings. A terminal newline does not borrow the next unselected paragraph’s style or overwrite a surviving destination suffix paragraph. Numbering is recomputed within the destination sequence. Original Unicode characters and trailing blank paragraphs are preserved. External HTML follows the supported character-format importer plus semantic lists: `ol`/`ul`/`li` nesting becomes paragraph list metadata with hanging markers, and `start`, `type`, `value` and inline `list-style-type` map to Forma restarts and counter formats where a format exists. Levels below eight clamp to level eight, formatting whitespace between list tags is dropped, a list of more than 10,000 items keeps its text without list metadata, and Forma's own metadata wins when present. Other external paragraph CSS is not converted, and external applications may ignore Forma's metadata. Plain text copy contains source characters, without generated markers. Copying more than 10,000 paragraphs omits paragraph metadata while preserving source text and character ranges, so clipboard data remains bounded.

Editable Figma Bridge transfer validates the fields before creating pages and explicitly reports that per-paragraph formatting, nested lists and marker spacing are omitted. SVG preserves the rendered appearance. Mock API checks are not a real Figma desktop round trip.

## Remaining limits and status recommendations

- UI-21-034: implemented paragraph-level property overrides with reference verification pending; named reusable paragraph styles and paragraph-specific font/paint styles are not introduced here.
- UI-22-046 and UI-22-047: implemented hanging markers and list item spacing with reference verification pending.
- UI-22-011 to UI-22-014: numbered, bulleted and nested lists and list indentation have keyboard editing, per-level counter formats, composite numbering and semantic HTML import. Numbering is per text layer: a following layer continues only through an explicit Restart number at, and there is no automatic link between layers. Marker-specific decorations and exact Figma behavior remain absent.

Headless measurement retains the documented approximate font metrics. Extreme indents can leave insufficient space even for one glyph; text may overflow, with the layer's clipping setting controlling display. Generated markers do not receive a separate hyperlink. Exact font-dependent Figma measurement and native desktop reference verification remain pending.

Validation includes 14 new core cases, a source-only MCP transaction case, and eight new browser interactions with actual SVG pixel gutters and mixed-run bounding boxes. Existing rich-text and text-variant interactions are included. No native build, package, archive, release version, website change or central register update was produced by this task.
