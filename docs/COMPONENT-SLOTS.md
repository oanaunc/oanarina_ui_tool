# Editable component slots (bounded implementation)

This pass implements a local slot workflow for UI-28-031/032/033. Each remains partial against the complete Figma behavior. The inspector's **Component slots** disclosure is available for main components, their direct-child source frames, instance roots and generated slot frames.

A main defines up to 16 named slots targeting distinct direct-child frames. Their existing children are the defaults. Instances initially follow those defaults, including ordinary component overrides. **Customize** forks the actual current content in place with stable layer IDs. **Start empty** instead clears it and marks a local override. Custom areas accept ordinary text, shapes, groups and ordinary component instances through the inspector, supported copy/paste, drawing and layer moves. The inspector adds text/rectangles/components and selects, reorders or removes direct children. Source frame sizing, constraints, clipping, layout and styling still govern the area. Local children keep their own editable properties; ordinary nested instances retain their own managed-child boundary.

Main edits preserve custom islands; constrained instance size changes use the final slot frame as the local constraint baseline. Reset replaces only descendants still contained in the slot with current main defaults, in one Undo. Layers moved out stay independent and reset cannot delete them. Removing a source definition also restores default content in affected instances, with a visible loss warning and Undo. Locked custom content refuses removal/reset. Deleting, converting or reparenting a source frame requires removing its definition first; deleting a still-used slot-bearing main refuses with detach/reset guidance. Library updates that remove customized slots refuse until the consumer explicitly resets or detaches them.

The `.oui` v1/v2 optional fields are main `componentMetadata.slots`, instance-root `slotOverrides` and generated-frame `slotInstance`. Absent fields preserve old synchronization. Imported malformed references, duplicate targets, foreign ownership, escaped nested managed children, slot cycles and unsupported ancestry refuse before publication. Clipboard, page copies and local library installations remap frame targets/owners; individual copied slot frames/default children become ordinary artwork. Library copies retain local editable content in consumers without turning it into a main definition. Preview ID planning includes custom node counts/payload and never matches outer source IDs against local islands.

Source MCP `apply_operations` includes `component_slot` actions `customize`, `reset`, `clear`, `add_text`, `add_rectangle`, `add_component` (last requires `componentId`). These use the same model helpers and atomic revision/Undo pipeline. Editable Figma Bridge transfer explicitly refuses slot metadata before creating pages; use SVG/PNG for appearance. This pass does not claim native Figma slot interchange or a real desktop plugin round trip.

Limits: slot-bearing main components and instances stay outside other components/instances; ordinary frame/group ancestors are supported. Slot content cannot contain component definitions or slot-bearing nested instances. Maximum 32 direct roots/256 descendants per area, 1,024 custom nodes/page, 64 slot-bearing instances/page, 20,000 nodes/page, 100,000 nodes/document and 64 levels per slot hierarchy/ancestry inspection. Synchronization preflights projected page/document sizes, a 100 MB cumulative copied-node work budget and the 50 MB final project size. There are no preferred-content constraints, drag placeholder affordances or nested slot-bearing template inheritance yet. Generic edits outside a custom area retain normal behavior; insertion into managed defaults refuses or uses an ordinary outside container rather than being silently discarded. The component picker shows the first 200 ordinary mains; supported clipboard insertion remains available.

Controls capture exact document/page/selection/mode context and invalidate retained handlers permanently on interruptions. Local disclosure, candidate and draft changes use immutable receipts, including same-event away/back cycles. Keyboard buttons use native Enter/Space, with no new global shortcut.

Primary scope references: [Figma's slot workflow](https://help.figma.com/hc/en-us/articles/38231200344599-Create-and-use-slots-to-build-flexible-components-in-Figma-Design), [SlotSettings](https://developers.figma.com/docs/plugins/api/SlotSettings/), [SlotNode](https://developers.figma.com/docs/plugins/api/SlotNode/). These establish the concept; this implementation's ownership/schema and explicit limits are Forma-specific.
