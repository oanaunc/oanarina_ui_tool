# Selected character fill colors

The rich-text inspector displays **Selection fill colors** above its range summary. Selecting source characters reports their effective character fill styles, including shorthand and alpha colors, explicit no-fill overrides, and inheritance from the layer's paint stack. Equivalent literal hex spellings share one row. Inheritance uses the same exact saved-value comparison as Artwork, so a character inheriting a gradient or multiple paints is described as **Layer fills**, rather than presenting the fallback hex as its visible color.

The display is read-only, follows the current logical source range and its draft styles, and adds no document metadata or history entries. A collapsed caret asks the user to select characters; it does not guess the next insertion color. Safe UTF-16 range handling preserves surrogate pairs. At most 128 distinct styles are displayed, with the full distinct-style count and a keyboard-scrollable list for longer selections. Hidden and zero-opacity layer paints are excluded from the layer-fill description.

These are character styles and layer paints, not a composited screen-color estimate. Layer opacity, effects, masks, strokes and overlapping artwork can change the displayed result. If no layer fills are visible, the panel explains that its rows describe stored character styles. The existing native color picker shows the RGB channels of shorthand/alpha values and explicitly sets an opaque character override; the summary preserves and reports the actual alpha or no-fill value. Mixed source settings are labelled next to that picker.

The summary updates after ordinary range formatting, Undo and saved reopening; it does not introduce a separate editing transaction or protocol field. `.oui` versions 1 and 2 retain their existing rich text format. Inherited gradients, images and paint stacks remain editable through the existing Fill inspector. Exact Figma/native visual acceptance is separate.

Checks cover real logical ranges and rendered SVG color inheritance, alpha/none/shorthand normalization, mixed and inherited fill styles, surrogate-safe selection, bounded large selections, read-only complete saved JSON/history, actual range color editing/Undo/reopen, and short-window keyboard scrolling without app-header movement. No app build, bundle, native package, archive, website or version update is generated.
