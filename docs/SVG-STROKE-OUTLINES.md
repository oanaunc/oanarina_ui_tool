# SVG stroke outlines

Open Export, use a saved layer SVG profile or combined SVG export, and enable **Outline supported strokes**. Preview and download use the same conversion. The saved profile option is additive (`svg.outlineStrokes?: boolean`); absent/false preserves the existing SVG path byte for byte. Combined choices are temporary, while profile changes use normal Undo and `.oui` save/reopen. Export never replaces document layers or changes their appearance on canvas. Copy selection as SVG continues to use its independent appearance workflow rather than saved profiles.

The export planner reuses Forma's existing **Outline vector stroke** geometry. It converts visible, positive-width strokes on leaf paths, rectangles, ellipses, polygons, stars, lines and arrows, in solid, gradient or image paint, including stacks and arrowheads. A stack or an unlike fill exports as a group of filled paths in paint order. Caps, joins, positive dash patterns and offsets, and supported inside/center/outside alignment become filled editable SVG paths. An existing fill is supported only when the existing outline helper can combine it without changing compositing: one matching opaque solid color. Other fills and multiple saved strokes refuse explicitly instead of disappearing.

This is bounded, approximate outlining, not exact cubic offset geometry or full Figma parity. Curves are flattened to a maximum control-point deviation of 0.25 **local units**, subject to the existing 512-point flatten budget. Own and ancestor affine transforms are preserved in the geometry/ancestry; large transforms or large output scaling can magnify the local approximation. Caps, joins, self-touching contours and derived paths remain subject to the existing outline tool's safety refusals. The original export viewport is retained, including intentional frame/slice crops, rather than refitting the converted result.

The workflow checks original source ancestry before selection ghosts can remove ancestor effects, and refuses visible stroke effects (including effects on ancestors), clipped or live-Boolean candidate hierarchies, container/text strokes, independent edge widths, variable-width profiles, markers and vector-local layout guides. Any mask run in the exported snapshot refuses conversion. Sampled Motion must be closed for SVG stroke conversion. Direct headless `exportSvg` consumes the supplied static nodes; it does not invent animation semantics. Locked and component-managed artwork can be exported because only an unpublished snapshot is converted. No document ownership or override is changed. PNG/JPEG ignore this SVG-only setting and retain their existing renderer.

At most 20,000 exported layers, 256 cumulative ancestor levels, 64 converted vectors and 16,384 total output anchors are allowed. Existing per-vector outline limits still apply: 32 contours/512 input anchors, width at most 10,000 local units, at most 512 dash steps/128 dash runs, 2,048 construction pieces and 4,096 output anchors. Hierarchy classification is cached once with maps. All conversions finish before the export renderer is called; unsupported vectors never produce a partly outlined download. The export task retains its immutable source snapshot and existing abort-on-source/context-change behavior. SVG option controls permanently invalidate retained handlers across document/selection/mode/modal/Motion cycles. A synchronous local candidate receipt also prevents retained combined-option callbacks from overwriting a newer option before React renders it.

Shared import/profile validation, source MCP edits and Bridge preflight validate the optional boolean before document mutation. Source MCP retains the setting and normal Undo; no new capability or tool was added. Editable Figma Bridge explicitly omits export profiles, so this is not a new Figma stroke preference or a binary `.fig` interchange claim.

Source checks cover exact default bypass, straight outline area, affine/crop/ID/style preservation, malformed options, cumulative hierarchy limits in both orders, 20k-layer cached lookup, unsupported-input atomicity, profile Undo and `.oui` versions one/two, real editable SVG reimport, Bridge preflight and source MCP persistence/refusal. Browser checks compare actual original/outlined raster pixels, including dashed curved half-opacity strokes under signed nonuniform ancestry, verify imported filled geometry and rendering, exercise combined exports, genuine save/reopen, errors without downloads, retained controls and asynchronous source cancellation/retry.

UI-40-027 is **partial** with the stated subset and approximation. UI-40-026 **SVG simplify stroke** remains planned: this pass does not invent a second simplification behavior or rename outlining as simplification. No app build, native package, archive, website or release metadata is changed.
