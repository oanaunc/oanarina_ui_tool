# Higher-contrast canvas selection

Preferences → Canvas accessibility → **High-contrast selection outlines** adds a persistent local option for the Design/Whiteboard canvas. Layer selection, multi-selection member outlines, layer/parent hover, pointer marquee and keyboard box previews use a black surround with a white center. Stroke sizes are fixed in screen pixels as canvas zoom changes. Resize and rotation handles use white fill and a black border; vector anchors use black/white activity states. Selection geometry and pointer hit targets retain their existing behavior.

The black-and-white boundary helps distinguish the edge over light, dark and colored artwork without depending on a purple hue. It is an editor overlay, outside artwork rendering, saved `.oui` data and SVG/raster export. Turning the option on/off adds no document Undo entry. Existing version-one preference snapshots migrate with the option off while retaining other choices. Writes are validated and persisted before updating the live UI; denied storage keeps the prior value and reports failure. Reset preferences and cross-window storage changes use the existing preference lifecycle.

UI-44-020 remains **partial**. This is a manual local canvas option, not a system-wide increased-contrast theme or an accessibility conformance claim. Specialized gradient/crop/vector-handle/brush/width editing overlays, prototype connections, labels and dimension badges, Slides and presentation views retain their own appearance. The option does not change document colors, editor text contrast, font availability or export palettes. Exact Figma and native assistive-technology reference verification remain pending.

Validation covers native Space activation, denied writes, legacy preference migration, local persistence/cross-window reset, no document/history mutation, live resize and Undo, multi-selection/hover/box identity, vector anchor activity, a short viewport at 125% interface scale, screen-space SVG edge pixels at several canvas zooms, and unchanged ordinary SVG exports. No app build, native binary, installer, release archive or website change is produced.
