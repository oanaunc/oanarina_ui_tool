# Authored-backdrop blur (partial)

Background blur is a real shared SVG effect over the actual preceding artwork. In the Effects inspector, add an effect, choose **Background blur**, then set radius and strength. Visibility, removal, conversion to other effects, Undo, Redo and .oui persistence use ordinary effect transactions. A no-op field leaves bindings/history unchanged. Invalid geometry/compositing changes refuse before document publication.

The initial supported context is deliberately small:

- A Design page contains one independent root leaf rectangle or ellipse target, at 100% layer opacity and normal blending. Its only effect is background blur. The target must fit inside the underlay after its own rotation, reflection and static nonuniform scale. Rounded rectangles, supported smoothed corners and ellipse arcs use the same shape geometry as normal artwork.
- The first visible root is an authored opaque **#RRGGBB solid** rectangle with square corners, no stroke, children, effects or transforms. The app does not synthesize a white background or sample page CSS, the editor grid, checkerboards, or another application. Alpha/shorthand/functional legacy underlay colors refuse instead of treating the legacy black fallback as authored opacity.
- All preceding visible source artwork and its conservative stroke/control bounds must fit inside that underlay. Ordinary static primitive shapes, vector contours, images and plain containers are supported. Text, live Booleans/networks, component instances, media, markers, masks, profiled/dynamic/calligraphic strokes, source effects and non-normal blending refuse. Later artwork paints normally after the target.
- A target can also be a direct child of a frame. That frame needs one opaque solid fill, normal blending, no effects, no stroke and a square or clipping outline. Its fill is the known backdrop, so the filter floods it beneath the earlier siblings and blurs them together, in the frame's own coordinates, so a rotated frame works. Only the frame's own earlier children reach the blur: anything outside the frame is never read, and the target must sit inside the frame. Deeper targets, group parents and reversed stacking refuse.
- Sibling masks refuse. Target children, combined effect stacks, non-Design workspaces, Motion keyframes and prototype/Smart animate/scroll presentation are unsupported. This is not general Figma backdrop-root or native background-blur parity.

The real preceding SVG DOM prefix renders once into SourceGraphic; original source groups and hit handlers remain in the scene. A self-contained target-shaped SVG mask selects the blurred contribution. Original-outside-mask and Gaussian-blurred-inside-mask are added using premultiplied arithmetic composition. Strength is the mask amplitude, so 0 is the exact unfiltered backdrop, 1 uses the blurred backdrop inside the shape, and intermediate values mix both. Target paints/strokes render afterward. A transparent selection shape makes an active fill-less target selectable without changing exports. Hidden targets/effects and zero radius/strength bypass the prefix filter.

Radius is in page units, with Gaussian standard deviation radius/2, up to 128 units. The filter region is the outward integer-rounded authored underlay, avoiding fractional feImage resampling outside the target. Source containment is checked against the original, unrounded underlay. The rendered shape clips the blur without an effect outset. Region edge sampling uses the SVG `duplicate` edge mode; it does not imply content exists outside the authored box. The authored-underlay ownership proof depends on the current conservative source subset and must be reviewed before adding new cross-layer/resource effects.

Limits: 20,000 page nodes, 512 visible preceding source nodes, 64 hierarchy levels, 200,000 contour geometry units, 4,096 pixels per underlay edge, 16 million region pixels, 16 effect entries across layers/reusable style definitions and 64 million summed region pixels per file. Reusable effect definitions alone are valid; assigning one into an unsupported scene refuses atomically. Source paint/stroke metadata and mask geometry are validated before rendering. Frame/page authoring stays headless; no DOM is needed for validation.

Whole-page editor SVG/PNG/JPEG and source-MCP SVG use the shared compositor. A selection/profile export containing the effect must retain its exact original contributing prefix, including the authored underlay; removing or substituting backdrop layers refuses. Canvas root culling falls back to the full scene on affected pages. Figma Bridge refuses this unsupported native effect before creating a Figma page; use complete-artwork SVG/PNG for appearance, without a claim of native editable effect transfer. .oui versions 1 and 2 retain the additive effect type; existing absent/default data is unchanged.

Inspector callbacks are bound to source and disclosure receipts; source away/back, Motion, hidden UI, selection changes, closed/reopened controls and old numeric drafts cannot revive a previous write. Invalid Canvas drafts cannot publish to the shared renderer. Browser raster tests cover real shared Canvas/editor/headless output, opaque and translucent prefix compositing, strength endpoints/intermediate values, rounded and affine ellipse clips, unaffected exterior pixels, later painter order/hit selection, save/Open, Undo, style no-op/detachment and guarded callbacks. Native WKWebView/GPU and live Figma reference acceptance remain unverified.

Rendering references: [Filter Effects 1](https://www.w3.org/TR/filter-effects-1/) defines Gaussian blur, feImage and premultiplied filter compositing; [Filter Effects 2](https://drafts.csswg.org/filter-effects-2/) describes the broader draft backdrop model. Forma does not use deprecated `BackgroundImage`/`enable-background` or browser-only CSS backdrop-filter.

Status recommendation: **UI19-004 partial**, **UI19-036 partial** (actual supported target-shape clipping only). Other background/effect reference cases remain unimplemented or unverified.
