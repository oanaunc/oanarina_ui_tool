# Stroke width during authored scaling

In Design, select layers and open **Stroke → Stroke width during authored scaling**. Choose **Inherit container policy**, **Scale with geometry**, or **Keep stroke width when scaling**. An absent choice inherits its nearest ancestor; the fallback is the existing scale-with-geometry behavior. A container choice affects its descendants, with explicit child choices taking precedence. The setting persists in ordinary `.oui` versions one/two, page/layer copies and component defaults; an instance root can make and reset its own override.

The existing default follows the important distinction in Figma's documentation: ordinary single-object dimension resize retains stroke weight, while the Scale tool scales strokes along with geometry. See [Apply and adjust stroke properties](https://help.figma.com/hc/en-us/articles/360049283914-Apply-and-adjust-stroke-properties) and [Scale layers while maintaining proportions](https://help.figma.com/hc/en-us/articles/360040451453-Scale-layers-while-maintaining-proportions). This pass tests ordinary leaf resize versus **K** and preserves that default. Complete Figma Scale-tool parity, numeric multiplier/anchor-box UI, exact group regular-resize reference behavior and effect-scaling parity are not claimed.

Keep-width is an additional Forma preference for authored Scale-tool transforms, group resizing and transformed multiple selections. For supported proportional changes, the shared headless planner compares each affected layer's original and proposed world affine transforms. It compensates local stroke weights, independent edge widths, dash lengths and dash offsets by the inverse uniform world-scale factor. Zoom and translation do not affect saved strokes. Rendering, bounds, masks and SVG export then consume the same saved, compensated values through their existing paths; there is no SVG `vector-effect` flag or renderer-only approximation.

The policy is operation-scoped, not a general promise that stroke widths stay constant under all future transforms. Ordinary leaf width/height edits, Motion playback, direct scripted/MCP `motionScaleX/Y` writes and imported transforms keep their existing semantics. The setting does not change current artwork on its own. Arrowhead dimensions, paint patterns, corner geometry, shadows and other effects retain their existing scaling behavior; this setting preserves stroke thickness and dash geometry only.

Compensation requires a uniform relative world scale between 0.000001 and 1,000,000. Proportional local scaling remains supported under signed, rotated or nonuniform ancestors because the actual before/after world transforms are compared. Point-width profiles compensate through their base width and keep every anchor ratio. Nonuniform relative scaling, singular/nonfinite ancestry, locked hierarchies, managed instance-child strokes and live Boolean strokes refuse the whole operation before publishing a preview. Edit a main component, detach an instance, disable the profile, or choose Scale with geometry where appropriate. Instance-root stroke compensation follows normal stroke overrides; it does not change the main component or unrelated instances.

The optional enum is validated on file import, ordinary shared metadata validation, source MCP edits and Bridge transfer. Changing the policy and completing a scale each use normal document Undo/save. A zero-travel resize preserves geometry/style identity and creates no Undo entry. Planning scans at most 20,000 page layers, caches ancestry up to 256 levels and bounds compensated widths/dashes/offsets to ±1,000,000 local units. At most 100,000 numeric stroke values (weights, edges, dash entries and offsets) are compensated per operation; this count is checked before constructing each patch. All changes are planned before assignment. Competing stroke-width variable and stroke-style links detach when literal widths change; unrelated paint/color links remain. An exact post-derivation check rejects component/layout controllers that replace the accepted stroke values.

Canvas source/context cancellation uses the existing guarded gesture path. Draft compensation is not saved until release. Escape, blur, mode changes and source changes cancel normally. Errors from the final derivation check are shown as a local message and leave document/history unchanged. Policy controls have permanent original-context guards across same-event selection/mode/modal/Motion cycles, and require unlocked current Design targets with Motion closed.

Editable Figma Bridge validates the metadata and explicitly omits this preference while transferring current literal strokes. A metadata-only instance override preserves otherwise-supported component linkage. Source MCP can retain/edit the enum, but does not gain an implicit authored-scale operation or any additional filesystem/network permission. SVG continues to show actual saved geometry; the future editing preference itself is not exported.

Source checks cover legacy/default behavior, proportional/nonuniform transforms, exact source preservation, dashes/edges, ancestry inheritance, isolated selected subtrees, competing style/token detachment, no-op history, atomic failures, component/clipboard/page persistence, bounded 20k-layer lookup, source MCP Undo/refusal and Bridge validation/link preservation. Actual browser checks exercise the Scale tool, ordinary resize, exported stroke and reflected alpha-mask pixels, cancellation, context cycles, instance-root overrides and genuine save/reopen. UI18-028 remains partial: this is a tested authored-scaling workflow, not full Figma stroke/effect/transform parity. No package, build, native installer, archive, website or release metadata change is included.
