# Hanging quotation marks

The text inspector’s Paragraphs/All settings include **Hang quotation marks** for a layer and **Paragraph hanging quotes** for selected paragraphs. A caret formats its paragraph; range selection formats every paragraph it touches. Paragraph overrides inherit the layer setting until explicitly changed or cleared. The optional `hangingQuotes` boolean defaults to ordinary placement and works in supported `.oui` version 1/2 documents without a migration.

For supported paragraphs, shared layout measures the contextual advances of an opening quotation mark at the original paragraph start and a closing mark at its original paragraph end. Those advances lie outside the aligned text body. Word fitting and auto-width use the body width; the SVG text anchor places the original rich glyphs at the corresponding offset. Quote font size, family, features, tracking and baseline styles participate in existing shared measurement; no source characters or UTF-16 character/paragraph indices are replaced. Closing quotation marks followed by whitespace ignore that trailing whitespace in displayed layout while preserving it in the saved source.

Supported opening characters are ASCII double/single quotes, “, ‘, « and ‹; supported closing characters are ASCII double/single quotes, ”, ’, » and ›. This is literal edge-punctuation handling, not a language-aware quote-pair or apostrophe classifier. Only the original paragraph edges hang, not arbitrary internal soft-line edges.

## Deliberate limits

This is a **partial** hanging-quotation workflow. It supports LTR paragraphs with physical left or right alignment and no list markers. Centered/justified paragraphs, RTL or mixed RTL text, explicit bidi controls and interior tabs retain their ordinary geometry. Additional quotation conventions (including low quotes and CJK corner punctuation), language-specific optical fractions, interior quotation boundaries, arbitrary glyph bearings and exact Figma optical behavior are not claimed. A truncated ellipsis tail explicitly returns to ordinary quote placement before fitting its ellipsis; earlier retained lines can still hang. Headless measurement uses the existing approximate font metrics; the browser uses actual installed/loaded fonts, and unavailable glyphs/faces can fall back.

Shared SVG rendering covers canvas, static export and masks. Visual export bounds and mask regions include conservative quote ink room under rotation, reflection, scale and ancestor clipping. These bounds are not paint-tight; explicit frame/slice crops and clipping may deliberately crop overhanging quotes. Existing imported text outlines invalidate when the appearance setting changes. CSS inspection warns that one generated CSS rule does not reproduce these measured offsets. Editable Figma Bridge transfer validates the metadata but reports the omitted optical offsets; SVG preserves the rendered layout. This is not an actual Figma desktop round-trip verification.

Layer/paragraph edits use the existing Undo, save, component override/inheritance, local text style and logical rich-clipboard paths. Invalid layer/paragraph/style metadata is rejected before mutation; MCP edits use the same validation and atomic transactions. Inspector handlers refuse locked ancestors, Motion, changed page/document/selection, hidden UI, unsupported editor modes and retained actions whose context changes away and back. Paragraph range/source changes also invalidate retained quote actions.

## Checks

Core cases cover measured quote advances, boundary and unsupported fallbacks, rich sizes, trailing whitespace, wrapping/auto-width, ellipsis, transformed conservative bounds and clips, logical rich clipboard/rebasing, optional validation and versions, Undo, actual generated component copies, text styles and Bridge atomic refusal/omission reports. Browser cases inspect real character coordinates and exported quote pixels outside aligned margins, saved reopening/Undo, UTF-16 HTML clipboard, auto-width/wrapping, clipping/transforms, and stale/locked/Motion handlers. Source MCP checks exercise save/Undo and atomic refusal of malformed/non-text metadata.
