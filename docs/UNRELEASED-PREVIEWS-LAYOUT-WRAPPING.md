# Layer previews, layout suggestions, wrapping and stroke outlines

This continues the [responsive guides/slices/direction pass](UNRELEASED-GUIDES-SLICES-DIRECTION.md). Three more individually named requirements have working, tested local implementations, and one gains an explicitly partial implementation. The register records **1,244 implemented, 187 partial and 591 planned requirements**, out of 2,022. Reference acceptance is tracked separately. Forma is still in development toward parity.

Actual stroke pixel tests found and fixed a rectangle renderer issue: zero-radius SVG corner arcs interrupted dash progression. Omitting only those degenerate arcs preserves the intended shape and makes transformed closed-dash outlines match. The same portal-theme repair covers existing page thumbnails. Review also found and fixed stale typography select handlers after same-event Inspect/hidden-UI transitions. Tests exercise all six layer-wrap/paragraph-wrap/direction combinations while checking unchanged document identity and history. Responsive-guide controls now explicitly explain that a binding recomputes manual geometry until detached.

`textWrap` is optional, validated before mutation and compatible with existing `.oui` versions one and two. No native IPC/resource permissions, font redistribution, project upload or document format version changes are introduced.
