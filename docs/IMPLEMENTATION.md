# Implementation and limits

The register describes the target, not a completed clone. **Implemented** means the narrow named behavior has a reachable working path and validation evidence. **Partial** records material limits; **planned** records absent behavior. Reference verification is tracked separately. Complete Figma parity requires additional visual, accessibility, performance, platform and user acceptance testing.

## Current source versus public release

The source is **0.2.0-dev.9**, with 1,055 implemented, 167 partial and 800 planned requirements (2,022 total). The previous signed/notarized public Mac preview is **0.2.0-dev.8**; dev.9 release validation is underway. See [page and raster validation](VALIDATION-v0.2-pages-raster.md) for this source checkpoint, [native clipboard and canvas validation](VALIDATION-v0.2-native-clipboard.md) for the preceding preview, and [component-bridge validation](VALIDATION-v0.2-component-bridge.md) for the Figma acceptance boundary.

## Working development workflows

The editor draws frames, sections, slices, basic shapes, editable cubic curves and freehand paths. It supports selection, grouping, ordering, numeric transforms, live boolean operands, curve anchors/tangents, shape geometry, mixed-font character ranges, text wrapping/formatting, fill/stroke stacks, gradients, blend modes and effect stacks. Responsive stacks include fixed/hug/fill sizing, independent padding, gaps, alignment, wrapping, size limits and frame resize constraints. Project edits have history and versioned `.oui` serialization. Page canvas colors/opacity/visibility persist, inherit on new pages and support Undo. A separate explicit color-pair checker reports unrounded WCAG thresholds; automatic accessibility audits remain partial.

Pages support duplication, drag/keyboard reordering, contextual actions, safe deletion and fresh internal reference identities with shared local libraries; each change has Undo and persistence. A temporary name filter preserves the active canvas and uses canonical document ordering for page actions. Bounded device-local page pan/zoom and last-page choice restore on navigation/reopen; one hover/focus preview renders static artwork without changing the canvas. See [remembered views](PAGE-VIEWPORTS.md) and [previews](PAGE-THUMBNAILS.md). See [page organization](PAGES.md).

Live local components, variants, exposed text/boolean properties, typed variables with modes/aliases, linked local styles, database snapshots, local comments, interactive prototype presentation, basic CSS inspection and SVG/PNG/JPEG export are present. Motion supports sampled keyframe tracks, autokey, playback, editable easing, reusable animation styles, GIF export and codec-dependent video export. The font catalog includes 1,959 families, with 24 bundled offline and installed Mac font discovery. The Figma development plugin converts a subset of editable nodes and properties through `.oui`, with known-loss reports.

Local preferences including live system appearance, layer drag/reparent/type filters, previewed batch renaming and keyboard action categories/recents are implemented. See [preferences](PREFERENCES.md), [layers](LAYER-TREE.md) and [actions](ACTIONS.md).

## Material limits

- The shell does not match every observed Figma rail, toolbelt, submenu, shortcut or dialog. The shared command registry includes the keyboard palette and current drawing tools; shortcuts and reference coverage are still a subset. The motion workspace is a functional subset. Agents/Code, full Draw, Dev Mode and the wider suite remain largely planned.
- Positions are stored as absolute coordinates. World-matrix gestures, oriented handles, vector overlays, clipboard and ungroup preserve supported ancestor transforms. Genuine affine shear is rejected atomically; intrinsic scale normalization, tight group bounds and exact group resizing remain incomplete. Booleans with text, arbitrary groups and full vector networks are incomplete. Continuous handle rotation, centered/locked resizing and parent/world alignment work with documented affine limits. See [canvas scope](CANVAS-TRANSFORMS.md).
- Rich ranges, true italic files, styled clipboard and numeric OpenType/axis settings work. Paragraph-range styling, feature discovery/previews, automatic script fallback and complete native typography acceptance remain unfinished. Lists are simple prefixes. See [rich text](RICH-TEXT.md) and [fonts](FONTS.md).
- Angular/diamond gradients are raster patterns. Alpha/vector/luminance masks render with nested sources and preserved export dependencies. Mask outlines/tree indicators/hover previews and exact reference nested semantics remain incomplete; no background blur, variable-width strokes or advanced Draw brushes. See [masks](MASKS.md). Exports now preserve ancestor transforms/clipping and include transformed geometry, strokes and effect padding. Text glyph overflow and complex clipping/effect bounds still need work.
- The layout solver implements stacks, weighted fractional/fixed/hug grid tracks, spans, explicit cell placement and cell alignment, with minimum/maximum sizes and editable track edges. Direct text baselines work in horizontal stacks. Nested baseline extraction, exact track deletion/reordering/cell swapping, all aspect-ratio/auto-size interactions and adversarial cyclic sizing remain incomplete. See [grid scope](GRID-LAYOUT.md).
- Live component propagation, cross-page references, overrides, variant sets and exposed properties work locally. Divergent nested swaps, complex variant property migration and shared publishing remain incomplete. Variables support four types, modes, aliases, scopes and bindings; full token folder management and remote library workflows remain incomplete.
- Prototypes include transitions, nested overlays, variables, conditions, input triggers and root scrolling. Exact device shells, nested scrolling, complex animation matching and hosted sharing remain incomplete. See [prototype scope](PROTOTYPES.md).
- Whiteboard and Slides are local editable workspaces. Shared sessions, cloud presenting, complete FigJam/Slides parity, PowerPoint and embedded video/prototypes are unfinished. See [whiteboard](WHITEBOARD.md) and [Slides](SLIDES.md).
- The free stdio MCP server edits an explicitly selected saved file, including shared duplicate/reorder/delete page operations, typed references and atomic undo. No-net-change reorder preserves saved bytes/revision/history. Native/MCP writers now share a lock and disk-revision safeguards. Live editor state/selection/screenshots, raster export and persistent server undo remain unfinished. See [MCP](../mcp/README.md).
- Comments and snapshots are local. No cloud collaboration, accounts, permissions, notifications, branches or backend sync.
- Browser startup waits for recovery hydration before showing editable controls, accepting keyboard edits or scheduling/flushing autosave, preventing initial-sample writes from preempting recovery and avoiding lost input drafts. Unavailable browser storage permits in-memory editing with a warning. Native ready-handshake commands become eligible after model hydration and the document acknowledgment, including before the next React render.
- Recovery/recent files/snapshots use IndexedDB, with old localStorage backups preserved during migration. Browser eviction, abrupt termination before a pending write and persistent undo history remain incomplete. Explicit native saves are atomic `.oui` files. Use saved files for durable portable backups.
- SVG import supports reviewed editable layers and a separate sanitized visual route. Unsupported CSS, filters, complex clips/masks and text/paint semantics produce reductions; see [SVG import](SVG-IMPORT.md). No direct binary `.fig`, Sketch or PDF interchange. Bridge tests include API mocks and a synthetic connected Plugin API transfer. The bridge now preserves linked mains/instances, supported overrides, variant sets and single-target scalar/swap controls, with dependency closure and preflight/rollback. Nested structural swaps, root controls, unsupported overrides and ambiguous correspondence detach with reports; slots and multi-target controls remain unfinished. New component paths have strict API-contract mocks, not real component round-trip acceptance. Desktop plugin UI transfer remains unverified; vector contour bounds and rotation origins remain approximate. Read the [bridge guide](../figma-plugin/README.md) and inspect every transfer.
- The local Home browser supports folders, import copies, sorting/filtering, grid/list, rename/duplicate, star/pin/archive and guarded Trash/restore/removal. Organization is local; content edits in separate browser tabs still use last-writer behavior. See [local files](LOCAL-FILES.md).
- The Mac shell supports independent document windows, own-window save/export/menu routing, dirty close/save/cancel acknowledgments, recent files and session recovery. Native editable clipboard transfers validate/remap supported dependencies before one undoable edit; same-session copies can retain proven local links. Referenced-main Cut is refused, external SVG uses review, and 20 MB/20k-layer bounds apply. Explicit PNG/TIFF paste adds normalized embedded image layers with predecode size limits, Undo/save and active-slide containment. The source adds bounded transparent 2× Copy as PNG with stale-render cancellation, pending final native window acceptance. Browser-system and private Figma clipboard paths remain unfinished. See [PNG copy](COPY-AS-PNG.md). See [raster paste](RASTER-CLIPBOARD.md). See [native clipboard scope](NATIVE-CLIPBOARD.md). It does not provide native document tabs or a collaborative editor. See [Mac windows](MAC-WINDOWS.md).
- Native Mac builds are universal; runtime tests were on Apple silicon only. Windows/Electron is experimental. Complete VoiceOver, keyboard-only canvas, localization, large-document and performance acceptance work remains.

The [development validation report](VALIDATION-v0.2-pages-raster.md) lists checks and practical limits. Future work must keep the per-feature register honest and expand tests with real behaviors rather than marking entire categories complete.
