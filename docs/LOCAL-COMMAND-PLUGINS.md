# Free local command-plugin foundation

This is a **partial Forma-specific local extension workflow**, not Figma Plugin API compatibility or a remote catalog. Open Assets → **Local plugins**. Import a local JSON package, review its name/description/requested permissions, and install or explicitly replace its existing ID. Installing, reopening files, reloading the installed list and app startup never execute package code.

The manager lists/searches at most eight installed packages in a separate local IndexedDB database. **Add to favorites** and explicit runs fill the Favorites and Recently run rows, kept per device in local storage. Actions has a **Plugins** tab that searches installed packages, favorites first, and opens the manager on the chosen package without running it. These shortcuts are never saved in a project. Removal affects that catalog only. It does not delete artwork and is not part of document Undo. Reload reads the saved catalog. **Run again in fresh sandbox** creates a new worker; replacing code requires an explicit package import. Permission grants are transient and displayed for every explicit run; they are never saved with `.oui` files or treated as permanent authorization.

## Manifest and API

A package is one JSON file, at most 200 KB UTF-8, with these required fields, plus the optional `parameters`, `ui`, `network` and `codegen` declarations described below. Any other field refuses:

```json
{"format":"forma-local-plugin","version":1,"id":"my.example","name":"Example","description":"Creates a rectangle","permissions":["document:write"],"code":"await forma.propose({operations:[{op:'create',key:'box',type:'rectangle',properties:{x:40,y:40,width:120,height:80,fill:'#ff8800'}}],selection:{createdKeys:['box']}});"}
```

JavaScript is at most 100 KB UTF-8 and executes inside an async worker function. Dependencies/relative JavaScript files are not loaded. Supported requested permissions are `selection:read`, `page:read`, `document:write`, `ui:show`, `fonts:read`, `image:read`, `image:write`, `export:read`, `storage:local`, `network:fetch`, `codegen:run` and `assets:read`. Each is granted separately for one run, and unrequested or denied capabilities are refused again at each host request. `ui:show`, `network:fetch` and `codegen:run` must be declared together with their `ui`, `network` and `codegen` sections, in both directions.

- `await forma.readParameters()` returns an independent typed snapshot of explicit run inputs, with no document permission or document metadata added. Optional strict text/number/checkbox/choice declarations use trusted host controls; see [typed plugin parameters](LOCAL-PLUGIN-PARAMETERS.md).
- `await forma.readSelection()` returns bounded selected current-page IDs, names, type, parent, child IDs, base geometry, visibility/lock state, opacity, fills, corner radius, literal text and text styling. Image and shader fills report their type only, never their bytes.
- `await forma.readPage({offset:0,limit:100,parentId})` pages the same current-page fields, optionally only the children of one layer (`parentId:null` for the page root). Limit is 1–200. Text is capped at 10,000 UTF-16 units per layer with `textTruncated`; oversized responses refuse rather than silently discarding rows. No raw document, comments, annotations, profile/author metadata or embedded image/font data are exposed.
- `await forma.readAssets({kind,offset,limit})` needs `assets:read`. `kind` is `styles`, `variables`, `collections` or `components`, and limit is 1–200. It returns names, types and descriptions, variable values by mode, modes per collection, and component properties with their variant values. Style values are left out. With the same grant, layer reads add `styleIds`, `variableBindings` and `componentId`.
- `await forma.log(text)` adds a local console message. Console log/warn/error are also directed to this bounded console.
- `await forma.propose({operations:[...],selection:{nodeIds:[],createdKeys:[]}})` stages one proposal per run, reviewed when the run ends. It does not edit the document. The host displays actual operations and changed property values before a separate **Apply reviewed plugin proposal** action. A run that finishes without a proposal changes no artwork.
- `await forma.commit(proposal)` takes the same shape and asks for review now. The plugin waits, with its deadline paused, until the person applies or declines. It resolves with `{applied:true,created:{key:id},selection:[...]}` or `{applied:false}`. An applied commit is one Undo step and becomes the run's new source, so later reads see it and later proposals can use the returned IDs. A run may make 20 commits, then one final `propose`.

- `await forma.ui.show({width,height})`, `forma.ui.postMessage(value)`, `forma.ui.onMessage(fn)`, `forma.ui.resize({width,height})` and `forma.close()` run an interface. See below.
- `await forma.fonts.list({query,offset,limit})` and `await forma.fonts.load({family})` cover bundled families, fonts embedded in the file and faces already registered this session. Loading never downloads: any other family refuses and must be added through the font library first. `fontFamily` and `fontWeight` in a proposal require a family loaded in this run.
- `await forma.images.create({mimeType,base64})` takes PNG, JPEG, GIF or WebP bytes up to 2 MB. The host checks the signature, decodes them and returns a handle with real dimensions. `await forma.images.read({nodeId})` returns the embedded image bytes of one current-page layer, up to 4 MB, and refuses video.
- `await forma.exportNode({nodeId,format:'svg'|'png'|'jpg',scale})` renders a current-page layer through the ordinary export path, up to 4 MB. SVG arrives as text, and PNG, JPG and PDF as base64. `format:'pdf'` uses the design PDF writer on that layer alone, with a scale of 0.25–4. `await forma.exportNodes({nodeIds,format,scale})` takes 1–24 distinct layers and returns `{files:[{nodeId,...}]}`, up to 2.8 MB in total. A code layer exports as its captured preview.
- `await forma.storage.get(key)`, `set(key,value)`, `delete(key)` and `keys()` hold JSON values in a separate per-plugin IndexedDB record, limited to 200 keys and 256 KB. Values survive runs and reinstalling a new version. **Remove local package** clears them. They never enter a project, and one plugin cannot read another's.
- `await forma.fetch(url,{method,headers,body})` reaches the network only for a package that lists origins and a run that grants them. See below.

An operation is `{op:'create',key,type,parent?,properties}`, `{op:'create',key,type:'image',image:'handle',parent?,properties}`, `{op:'create',key,type:'instance',component,parent?,properties}`, `{op:'update',nodeId,properties}`, `{op:'delete',nodeId}` or `{op:'reparent',nodeId,parent}`. Creatable types are `rectangle`, `ellipse`, `text`, `image`, `frame`, `group`, `section`, `component`, `instance`, `vector`, `line`, `polygon` and `star`. IDs are generated. Keys are unique short aliases valid inside the proposal.

**Hierarchy.** `parent` is the key of a frame, group, section or component created earlier in the same proposal, or the ID of an unrotated frame, group or section on the page whose ownership allows edits. Inside a parent, `x` and `y` are relative to it. A group needs at least one child in the same proposal, and its bounds come from its children. A frame with `layout` lays its children out through the editor's own layout, and the review shows the final page result.

**Delete and reparent.** `delete` removes a layer and its subtree. `reparent` moves one into a parent, or to the page with `parent:null`, keeping its place on the page. Both need an unlocked subtree free of components, instances, masks, slices, video and Motion tracks, and children of an auto-layout frame may leave it, after which the editor lays it out again. A proposal cannot touch a layer twice this way, use a layer it also deletes, or delete a group's last child. The review lists each one.

**Components and vectors.** A `component` works like a frame, and its children come from the same proposal. An `instance` names `component`: the key of one created earlier in the proposal, or the ID of a main in this file. It takes `name,x,y,visible,opacity`, and its artwork follows the main. A `vector` needs `path`, which is SVG path data up to 100,000 characters in a box of the layer's `width` by `height`, plus optional `closed` and `fillRule`. `mask` (`alpha`, `vector` or `luminance`) makes a new layer mask the siblings after it. Paths and masks are set at creation only.

**Properties.** `name,x,y,width,height,rotation,fill,opacity,visible` apply to any layer. `effects` is up to 8 of `{type:'drop-shadow'|'inner-shadow'|'layer-blur'|'background-blur',color,opacity,x,y,radius,spread,visible}`, and replaces the layer's list. `fills` is 1–8 paints: `{type:'solid',color,opacity}`, `{type:'image',image:'handle',scaleMode,opacity}` with `image:write`, or `{type:'linear'|'radial'|'angular'|'diamond',angle,opacity,stops:[{position,color,opacity}]}` with 2–16 ascending stops; use `fill` or `fills`, not both. `stroke` (hex or null) and `strokeWidth`, `radius` on rectangles, frames and images, `pointCount` on polygons and stars, `innerRadius` on stars, and `layout` (`none`, `horizontal`, `vertical`), `gap`, `padding` and `clip` on frames.

**Text.** `text,fontSize,fontFamily,fontWeight,fontStyle,textAlign,verticalAlign,lineHeight,letterSpacing,decorations`, and `textRanges`: up to 200 sorted, non-overlapping `{start,end,fontFamily,fontSize,fontWeight,fontStyle,fill,letterSpacing,decorations}` in UTF-16 units that may not split a character. Replacing text clears its ranges unless the same operation sets them again. Fill requires opaque six-digit hex. Text allows TAB/LF/CR but refuses other C0/C1 controls. Families need `forma.fonts.load` in this run. Image layers refuse fills, and the review shows the actual image.

Component properties, variants, slots, code layers and shader or progressive effects are not offered.

**Updates.** Appearance-only updates (`name,fill,fills,opacity,stroke,strokeWidth,radius,visible,effects`) work on rectangles, ellipses, frames, polygons, stars and text, including layers with children, when the layer has no variable bindings. Any other update requires an independent leaf rectangle, ellipse or fixed text layer, because a move or resize must not leave children or controllers behind. Locked, component, instance, slot and masked hierarchies, affected Motion tracks, vector geometry and min/max/aspect/guide controllers refuse explicitly. Legacy falsy-root layers remain readable; writes refuse those unsupported identities and normalize sibling mask ownership before checking eligibility. The normal editor transaction and final full-page/outside-page proof can refuse automatic derivation that changes the reviewed candidate.

A document proposal applies through one ordinary editor edit with Undo and save/reopen. A selection-only proposal validates the same minted source/permissions receipt and updates ephemeral selection directly: no document edit, timestamp, dirty state or Undo entry. Plugin packages/code/grants are not embedded in projects, recovery, exports, clipboard payloads, library publication or the Figma Bridge. Resulting ordinary artwork follows its existing persistence/interchange paths.

## Plugin interface

A package with `"ui":{"html":"...","width":320,"height":200}` and `ui:show` can open its own interface inside the manager dialog. HTML is at most 100 KB; size stays within 120–800 by 80–640. The worker calls `forma.ui.show()`. The interface posts `parent.postMessage({pluginMessage:value},'*')` and receives `event.data.pluginMessage`. The host relays only that one-key shape, after validating it as bounded JSON. Anything else ends the run. Messages the worker posts before the interface finishes loading are queued. A run with an open interface stays alive after its main function returns, until `forma.close()`, Cancel, a source change or the 10-minute session limit. Its proposal then goes through the usual review and Apply.

The interface runs in the same opaque frame as code layers: `sandbox="allow-scripts"` only, with `connect-src`, `frame-src`, `object-src`, `form-action` and `base-uri` denied, and images, fonts and media limited to inline `data:` and `blob:`. It has no `forma` object, so every document capability goes through the worker and its grants. Runs that use an interface or byte transfers get larger published budgets of 1,000 requests, 1,000 interface messages, 8 MB per estimated message and 32 MB per run.

`console` output and uncaught errors from the interface appear in the plugin console, within its 50-message limit. Interface scripts run in their own terminable worker against a mirrored DOM, never on the editor's thread, so an infinite loop cannot freeze Forma. Cancel ends it at once, and a script that runs for more than 5 seconds without yielding ends the run with no proposal. See [guest script isolation](GUEST-SCRIPT-ISOLATION.md) for the evidence and for what the mirrored DOM cannot do.

## Networking

Plugins have no network by default. The worker's and interface's own CSPs deny all connections whatever the manifest says. A package must declare `"network":{"allowedOrigins":["https://api.example.com"]}` with `network:fetch`, the exact origins appear during review and beside the run grant, and the user must grant it for that run.

Origins are exact: `https://host[:port]`, or `http://127.0.0.1:port` and `http://localhost:port` for local development. Wildcards, paths, credentials and plain remote HTTP refuse. Each `forma.fetch` is checked in the host against the allowlist, then sent by a separate bundled opaque frame, `local-plugin-network.html`, which narrows its own `connect-src` to the granted list before it can issue a request. A host bug would therefore still meet a browser refusal. Requests allow GET, HEAD, POST, PUT, PATCH and DELETE, with only `accept`, `content-type` and `authorization` headers, no cookies or referrer, and redirects refused so a listed origin cannot forward the call elsewhere. Responses are text, up to 1 MB with a `truncated` flag. A run may make 25 requests with a 10-second timeout each, and every request appears in the plugin console.

The target must allow `Origin: null` through CORS, or the request fails. These calls are the only plugin network path, and they happen only after that per-run grant.

## Isolation and ownership

A trusted bundled `local-plugin-guardian.html` is loaded into an iframe with **only** `sandbox="allow-scripts"`; it never receives `allow-same-origin`, popups, forms, downloads or navigation permissions. The editor's existing CSP and native IPC/resource scopes remain unchanged. The guardian has its own CSP before its sole hash-pinned trusted script: default/connect/frame/object/base/form/style/image/font/media sources are denied, with only its pinned script and local Blob worker creation allowed. A separate resource is necessary because srcdoc inherits the editor CSP and cannot loosen its existing `script-src 'self'` restriction.

Guest code is never interpolated into srcdoc, an HTML script or the editor realm. It is delivered as message data after a one-time handshake, then becomes source only in a dedicated Blob worker governed by the guardian's inherited CSP. The worker has no parent window/DOM/native bridge and opaque-origin persistent storage fails. Bootstrap closures hide raw native postMessage and disable nesting/broadcast constructors across their exposed prototype chain. The trusted guardian terminates the worker and revokes its Blob URL on completion/error/cancel; host disposal removes the iframe/listeners/timer. The parent checks exact event.source, opaque event.origin, random per-run token, request IDs, strict JSON shapes, permissions and cumulative budgets independently.

Runs have a 15-second host deadline, at most 100 API requests/100 document operations, 50 console messages of 1,000 characters, per-message estimated inspection budget 200 KB and cumulative estimated bridge budget 1 MB. JSON budgets charge UTF-16-style inspection size, not exact UTF-8 transport bytes; package/code/catalog sizes use actual UTF-8 byte counts. Source inspection is bounded to 5,000 unique layers, 512-unit identities and a conservative 20 MB payload/work budget before cloning. Hierarchy-sensitive updates cap ancestry at 64. Installed catalog totals are at most eight packages/1 MB UTF-8. Invalid/blocked storage fails visibly and does not silently erase or overwrite stored packages. IndexedDB revision comparisons serialize catalog changes; cross-window notifications permanently cancel runs on package changes, including remove/restore cycles.

Each run permanently captures source document/page/selection, mode/modal/Motion/font revision, catalog epoch, package identity and local grant/choice receipt. Any relevant departure cancels old worker/proposal delivery, including away/back cycles. Every request and reviewed Apply rechecks ownership; no delayed publication is allowed after cancellation. Post-edit selection delivery also holds a temporary permanent receipt for the exact published document, so a synchronous subscriber replacing or leaving that context cannot receive old plugin selection/vector resets. Reviewed no-op document operations can still deliver their selection without an Undo entry. Old UI callbacks cannot apply a newer run or overwrite fresh permissions. Synchronous source/picker failures are shown only for their still-current action and release owned inputs/operations. Fresh controls can retry.

This browser boundary is **not an OS sandbox or a hard memory/RSS guarantee**. Browser structured cloning/allocation can occur before application inspection; request/deadline limits are best-effort resource controls. Native WKWebView behavior has not been smoke-tested under the user's build freeze. Unsupported sandbox initialization fails closed rather than weakening CSP. Remote discovery, dynamic or guest-rendered parameter forms, widgets, shaders, external dependencies and Figma API compatibility remain outside this pass.

## Validation

`tests/local-plugin-platform.test.ts` and `tests/e2e/local-plugin-platform.spec.ts` cover manifest pairing, origin and fetch refusal, per-grant refusal of every capability, interface messaging and malformed traffic, interface network denial against a counting server, font, image, export and storage paths, favorites, recents and Actions search. The network spec proves an unlisted origin receives zero requests through both the host check and the frame's own narrowed policy. That spec also passed once under Playwright's WebKit engine on macOS. A real Forma app build in WKWebView has not been exercised for any of this. Its native bridge refuses messages from subframes, and its navigation policy cancels external frame navigation, by source inspection only.

Pure API tests cover strict packages/permissions, redacted reads, typed operation refusals, source immutability, private plan grants/original bytes, lock/managed/mask/automatic ownership, valid legacy falsy-root mask refusal, late-controller atomic failure, one Undo/persistence and zero-edit selection delivery. Independent source checks recompute the exact guardian hash and assert the editor CSP remains strict.

Real Chromium interaction tests cover inert import/install/remove/reload, actual per-run permission denial, concrete proposal review/Apply/Undo/save with no code/grant leakage, selection-only document identity, native keyboard at 125%/short viewport, source/local/grant/catalog away/back cancellation and fresh retry, blocked storage, oversized valid source and picker failure recovery. Sandbox tests exercise opaque parent/native/storage denial, literal markup handling, fetch/XHR/WebSocket/EventSource/importScripts/dynamic-import/eval denial with zero tested localhost egress, copied-token foreign-source rejection, request flooding, infinite-loop cancellation and deadline cleanup.

Reference context: [CSP Level 3](https://www.w3.org/TR/CSP3/) and the [HTML iframe sandbox](https://html.spec.whatwg.org/multipage/iframe-embed-object.html) define the boundary. [MDN documents Blob-worker CSP inheritance](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy). These are security architecture references, not proof of Figma plugin parity.
