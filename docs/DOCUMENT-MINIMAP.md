# Document minimap navigation

Use **View → Show overview minimap** or search that action in Actions. The existing local preference survives reload and is separate from the project file. The overview names the current page, shows visible layer layout boxes and the current viewport, and labels base geometry or the current sampled Motion pose. Click outside the viewport indicator to recenter; drag the indicator or map to move the camera. **Fit** fits the schematic page bounds. While the map is focused, **F** fits, **Home** centers, arrows pan, Shift+arrows move farther and Page Up/Down move a viewport. There is no new global shortcut. Keyboard activation of navigator controls does not arm the canvas temporary Hand tool or finish a Pen path.

This is a current-page schematic, not a miniature artwork renderer or an all-pages atlas. It excludes hidden ancestry, slices, export ghosts, group boxes and generated Boolean children. It uses transformed layout rectangles, conservative axis-aligned ancestor clipping and the existing signed affine transform convention. Masks, precise clip shapes, text ink, path excursions, strokes and effect ink are not drawn. Those approximations are stated beside the map. Fit remains subject to the supported camera zoom/pan limits and does not promise that over-budget or skipped geometry is included.

The cached affine index scans at most the first 20,000 layers and emits at most 1,500 boxes. All inspected valid boxes contribute to bounds even if their outlines are omitted. Missing ancestors (including parents outside the input budget), duplicate/empty identities, cycles, nonfinite transforms and world corners beyond ±10 million units are skipped with a visible count; their children are never silently interpreted as page roots. Parent traversal is iterative and memoized. Core checks cover a 20,000-layer page with nested reflections/rotations and an operation-count bound, as well as the existing 20,000-level reverse hierarchy case.

Camera transactions preview live and commit one viewport-history destination. Escape, blur, hidden documents, resize, capture loss, matching pointer cancellation and source/context interruptions cancel through the shared camera-gesture API. Secondary/foreign pointers cannot replace, finish or cancel another pointer. Source proof includes the original document object, page, selection, tool, mode, modal, UI visibility, Motion time/play state, camera and UI scale; away-and-back transitions invalidate retained handlers permanently. Newer source or camera commands keep their own state rather than accepting obsolete rollback.

The minimap is available on the Design/Whiteboard editor canvas, including its prototype-editing and sampled Motion modes. It is absent from Slides and standalone prototype presentation, and hidden behind active modals/Home/hidden editor UI. It changes neither saved geometry nor selection, document Undo/Redo or native dirty state. Existing viewport history and per-page viewport recall remain separate from document history. Layout viewport dimensions are measured in logical SVG units, while pointer hit testing uses the actual physical control rectangle; checks include 125% UI scale and narrow containment.

Validation: focused core and actual browser checks cover transformed bounds/budgets, fit/click/drag/keyboard navigation, one-step viewport history, page recall, Undo/save identity, stale retained pointer/keyboard callbacks, source/mode/Motion/selection/scale cycles, Escape/blur/visibility/resize cancellation and foreign pointers. Existing overview/scrollbar interaction checks remain applicable. No schema change, project migration, native capability, package, generated archive, installer or website change is part of this source pass. Real native/Figma reference verification remains pending.
