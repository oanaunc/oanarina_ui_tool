# Independent edge strokes — supported boxes

**UI-18-011 remains partial for dashed edges and per-edge paints.** In the Stroke inspector, **Independent edge widths** exposes Top, Right, Bottom and Left for one selected unlocked rectangle, image, frame, main component, group or section in the Design workspace. Each existing stroke can have its own four widths, alignment, visibility and common paint. A zero width removes that side. Turning the option off restores that stroke's saved ordinary width. The summary identifies independent edges instead of displaying that inactive ordinary width.

The additive optional `StrokeStyle.edgeWidths` tuple uses `[top,right,bottom,left]`, each a finite number from 0 to 1,000,000. Ordinary strokes without this field retain their previous rendering path. Both `.oui` versions 1 and 2 remain supported. Existing nested stroke serialization preserves edge widths in saved projects, stroke styles, closed design clipboard data and component source/instance synchronization. Formatting detaches the competing stroke style and uniform-width token; binding a uniform-width variable to an independently sized first stroke is refused explicitly. A source edit propagates to its linked copies as one shared Undo transaction. Managed instance descendants and instance roots cannot edit the new controls directly; edit the main source or detach first. Other existing instance stroke overrides retain their existing behavior.

Canvas, SVG, raster export and source MCP SVG use one even-odd filled ring per stroke. The inner and outer rectangles derive from the four widths and Inside, Center or Outside alignment. Opposing inward widths that consume the box collapse the interior proportionally instead of inverting the hole. A single paint operation prevents translucent corners from receiving alpha twice. Gradient/image paint coordinates stay anchored to the original layer box, independent of the ring's changing bounds. SVG filter regions include asymmetric outside extents before applying effects. Shared export bounds and mask regions include asymmetric outward edges through the existing affine hierarchy; these bounds remain conservative with invisible paints and effects, rather than promising a tight pixel crop. Auto layout's existing scalar stroke-in-layout inset/outset uses the maximum edge width, so it can reserve extra space on narrower sides.

Rounded boxes keep one ring: every corner's outer radius grows by each side's outward width and its inner radius shrinks by each side's inward width, independently on each axis, so unequal sides meet in an elliptical taper and an inner radius consumed by a wide side becomes a sharp inner corner. The layer's four corner radii feed the same path, with the shared half-short-side clamp. Corner smoothing is refused with an instruction to remove it first. Non-box paths, ellipses, live booleans, arrowheads, dashed lines, non-miter joins and non-butt caps are outside this pass. Enabling is unavailable with an explanation; edits/imports/styles that would introduce an unsupported combination are refused atomically with instructions to disable independent edges first. The ordinary controls remain available after disabling, so the unsupported transition does not trap the inspector. Stroke outlining refuses independent edges explicitly. There is one paint for all four edges; separate per-edge colors, dashed edges, individual edge selection and tight stroke outlines remain unimplemented. The ring uses square box corners; the ordinary miter-limit value is retained for restoration and does not bevel those corners.

The read-only Dev/CSS output warns that independent edge geometry is omitted and does not emit a misleading uniform border. SVG preserves the appearance as editable filled ring geometry, rather than preserving an independent-stroke setting when reimported. Editable Figma Bridge transfer refuses independent-edge documents/styles before creating a page and recommends SVG/PNG; native Figma edge weights exported through the Bridge report their omission. Mock preflight checks are not a real Figma desktop round trip. Direct binary `.fig`, native reference acceptance and app/download rebuilds are not claimed.

New controls enforce inherited locks, current source/document/range-independent selection, workspace/mode and Motion restrictions. A subscription-invalidated context proof rejects a retained handler after an editor context changes away and back. Number edits use the existing arithmetic/scrub field and its draft cancellation; each accepted change uses shared Undo and persistence. No new native or protocol permissions are added.

Validation covers exact asymmetric rings, consumed/zero-size interiors, outside export/mask extents, original-box gradient coordinates, filter extents, alpha at unequal corners, signed ancestor transforms and alpha masks, linked component propagation, style/token detachment, both project versions, clipboard parsing, malformed import/style/MCP atomicity, source MCP save/Undo, explicit Bridge refusal and CSS/outline limitations. Actual browser checks exercise controls, color raster output, managed/inherited locks, Motion, same-event context cancellation, Undo/reopening and ordinary paint regressions. No app build, bundle, native package, archive, website or version change is generated.
