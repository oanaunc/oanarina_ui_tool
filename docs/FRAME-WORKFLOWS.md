# Frame presets and inspector actions

This implementation adds real editor paths in the Assets sidebar and single-frame Design inspector. It does not change the document format, native permissions, or Figma binary export.

## Presets

Assets → Frame presets groups existing desktop, phone/tablet and social sizes with three Watch sizes, six Paper sizes, and three Presentation aspect ratios. Asset search matches preset names, categories and dimensions. Selecting a preset creates an editable ordinary frame through the existing insertion transaction and fits the viewport; Undo removes that insertion.

Watch dimensions are logical interface pixels (184 × 224, 198 × 242, 205 × 251), not physical display resolution or a guarantee of device-specific safe areas. Paper presets round physical dimensions at 96 CSS pixels per inch: A5 559 × 794, A4 794 × 1123, A3 1123 × 1587, US Letter 816 × 1056, Legal 816 × 1344 and Tabloid 1056 × 1632. These are RGB canvas sizes; CMYK, bleed, physical print calibration and printer support are separate features. Presentation frames are 1920 × 1080 (16:9), 1024 × 768 (4:3), and 1920 × 1200 (16:10).

## Frame inspector

- **Swap orientation** exchanges authored width and height without rotating artwork. It keeps the frame center fixed, sets fixed sizing, and uses existing child constraints/layout behavior for the new size. Size limits, inherited locks, managed instance descendants, generated workspace frame ownership and auto-layout placement are guarded.
- **Select frame contents** selects visible unlocked **direct children**, in front-to-back layer order. It skips hidden and inherited-locked children and does not recursively select grandchildren. It changes selection only, with no document edit or Undo entry.
- **Fit frame to content** keeps **Direct children** as the default bounds choice and also offers **All descendants**. Both measure rectangular layer geometry in the selected frame's own axes, including hidden layers and child rotation/reflection/scale. All descendants includes nested overflow and geometry outside nested clipping boundaries. This is explicitly a geometry union, not visible-paint measurement: empty container rectangles and hidden/clipped geometry count, while stroke/effect padding is excluded. It rebases child transforms so every descendant retains its world transform and size. Original child constraint fields (including absent fields) are restored in the uncommitted candidate before full document validation. One successful transaction gives one Undo entry and ordinary .oui persistence.

**Painted bounds** is a third fit choice. It measures visible layers that actually paint, with outside strokes and effect padding, skips unpainted containers and hidden layers, and stops at nested clips because they hide their overflow. It uses the same refusals as All descendants, plus an empty result when nothing paints.

Fit remains **partial**: it supports ordinary free-layout frames, not auto-layout frames (use Hug contents), managed instances/main component subtrees, motion-controlled hierarchies, or generated slide/sticky/table frames. All-descendant fitting additionally refuses mask sources, live booleans and slices anywhere in the fitted subtree or its ancestor chain; direct-child mode retains its existing behavior. Collapsed transforms, nested scales whose composed world geometry overflows, incompatible size limits, and any downstream layout/component change that would alter child artwork are refused atomically. This is an intentional appearance-preservation limit, not a claim of full Figma fit behavior or reference verification.

## Nested geometry fitting follow-up

The single-frame Design inspector’s **Fit bounds** selector provides the reachable nested-content workflow. Choosing All descendants changes only local UI state until **Fit frame to content** is pressed. A successful fit keeps every descendant’s world matrix and authored size, restores direct-child constraint metadata, and validates the fitted frame’s own world matrix and size after the shared document derivation. A variable, guide, text or layout controller that changes those expected boxes causes an atomic refusal, with no selection/history/document replacement. The frame’s own background and clipping bounds intentionally follow its fitted size.

The action captures document identity, page, selection, editor mode, visibility, modal and Motion state. Immediate subscription invalidation prevents a retained handler from applying after a same-event mode/Motion away-and-back cycle; an actionable refusal asks the user to select/review the frame again. Inherited locks and existing managed/workspace/Motion ownership restrictions remain enforced. No document model, schema version, protocol field or native permission is added. Saved output remains ordinary `.oui` geometry; the local bounds choice is not project metadata.

Fitting is bounded to 20,000 page layers, 2,000 layers in the selected subtree including the frame, and 1,024 composed ancestor transforms. Parent matrices are cached, and subtree rebasing visits each descendant once. These conservative action limits do not prevent larger/deeper valid legacy projects from opening. Finite world corners, compatible size/coordinate limits and representable affine transforms are still required.

Source verification for this follow-up: 1,359 core tests in 116 files passed, including 10 new descendant-fit checks and the existing 14 frame-action checks. Twelve actual browser checks passed (eight new descendant-fit workflows plus four existing frame workflows), covering direct/default behavior, signed affine rendered corners, hidden/clipped geometry, one-step Undo/Redo, save/reopen, mask refusal, same-event context cancellation, live/same-event bounds-choice guards and a real variable-controlled size refusal. TypeScript and MCP source type checks passed. No app build, native build, package, archive, website or release artifact was generated. UI-09-025 remains partial; reference verification and paint-tight stroke/effect/boolean/mask fitting remain separate work.

## Scaled layers

Dragging a group handle or typing its W or H resizes the layers inside: positions and sizes change, while strokes, radii and type keep their values. The K Scale tool keeps one scale on the layer instead, so its fields show the size before scale. A group that already carries a scale, or holds contents that cannot resize (listed below), keeps the old behaviour on a drag and refuses a typed size with the reason. Rotated contents resize only with an even drag. A selected scaled layer now states its percent and on-canvas size and offers **Apply scale to values**. An even scale becomes real size, position, stroke, dash, radius, type, spacing, padding and effect values, and every layer stays exactly in place. An uneven scale changes position and size only, so strokes, radii and type keep their values, and it refuses rotated contents because they would skew. It also refuses mirrored scale, instances, main components, rich text, vector networks, Boolean results, masks, text on a path, guide-bound layers, nested scales and animated layers, each with its reason. Validation: `tests/scale-apply.test.ts`, `tests/e2e/scale-apply.spec.ts`.
