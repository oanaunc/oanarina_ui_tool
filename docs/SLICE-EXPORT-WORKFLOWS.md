# Slice exports and canvas outlines

The unreleased source adds **File → Slices and exports…**, also available in action search. It lists the current page's slices, searches name prefixes, and pages results in groups of 50. Arrow keys/Home/End move between slice options, including across result pages. The dialog contains a focus scope and Escape closes it. **Select slice on canvas** returns keyboard focus to the selected crop region; hidden/locked slices remain available for explicit inspection.

Each slice exposes its real saved export profiles through the shared export controls: SVG, PNG or JPG, scale 0.01×–64× or one constrained pixel dimension, suffix, supported format options, preview, individual download and multi-profile ZIP. Rename the slice to change the filename stem, and save it with Enter or **Save slice name**. Filenames are sanitized/bounded for Mac/Windows and duplicate batch names receive unique suffixes. Names, profile settings and layer visibility support document Undo and `.oui` save/reopen. The manager's name editor accepts 1–512 characters; longer legacy names remain intact until explicitly replaced.

**Export visible slices as ZIP** prepares each visible current-page slice independently using its saved profiles or its default profile. Empty saved profile lists intentionally omit that slice. Overlapping slices can include the same artwork at different local coordinates and scales. The ZIP contains assets and the existing SHA-256 manifest. Locked slices may be exported; editing requires unlocked Design artwork with Motion closed. Managed child renaming/visibility is refused; supported export-profile overrides still use the shared component validation. Slides use their own export workflow.

Slices crop all overlapping visible page artwork through the inverse of their complete parent/layer affine transform. Their own axes and fixed width/height determine the crop; sibling mask/clip structures remain in the shared rendering snapshot. Hidden layers are excluded unless a profile explicitly includes them. Slice regions never paint in exported SVG, PNG, JPG or ordinary artwork exports. Imported descendants under a slice also do not paint: crop preparation removes the entire slice subtree, avoiding orphaned export nodes. Crop rendering does not mutate the source file.

## Canvas visibility

**View → Show / hide slices**, Preferences, and the manager's **Show slices on canvas** toggle control an additive device-local preference (default on). Visible slices have dashed teal outlines and bounded name labels, following rotation/reflection/scale and Motion samples. Labels and border hit targets permit selection without intercepting clicks inside the crop. The saved layer's visibility toggle separately controls its outline and eligibility in visible-slice batches. Global outline visibility changes no artwork, saved project, export or document history. Preference migration preserves older custom values.

The slice polygon/visibility indexes cache inherited transforms and visibility iteratively, independent of node array order. A 20,000-layer reversed hierarchy is covered without recursive indexing. Nonfinite projected outlines from extreme legacy scale chains are omitted; export still validates its own finite geometry. Search examines at most the first 4,096 name characters, and on-canvas/list labels truncate for readability while preserving full saved names.

## Guards and limits

Delayed numeric/suffix fields in the shared export editor capture document, page, selection, mode, modal, Motion/time, home and UI context on focus. Changed contexts discard drafts even when a replacement uses the same IDs and displayed values. Immediate name/visibility actions also recheck the live context, including Home/UI visibility and selection changes that arrive before React rerenders. Motion and read-only modes disable profile changes; existing export settings remain usable for snapshots. Active exports use immutable prepared jobs and abort when the editor context changes or the task is cancelled.

The existing limits apply: at most 20 profiles per layer, 200 assets and 100 MB per export batch, raster edges up to 16,384 pixels and 80 million pixels, and at most 256 ancestor levels for export. SVG retains its supported editable/appearance options. A slice is a crop region; it does not isolate just one selected object, add file-system directories from slashes in names, or provide binary `.fig` output. Font/image/video/poster and SVG-fidelity limitations remain those of the shared renderer. Native save-panel/WKWebView and exact Figma behavior acceptance remain pending.

`tests/slices.test.ts`, preference migration tests and `tests/e2e/slices.spec.ts` cover transformed crop geometry, real overlap PNG pixels and scaled SVG downloads, selection/focus, name/profile/visibility persistence and Undo, large lists, stale drafts and unchanged saved artwork. Existing export-delivery interactions remain part of combined validation. No builds, packages, versions, downloads or website files are changed.
