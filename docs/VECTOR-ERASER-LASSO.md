# Vector eraser and lasso

## Filled shape eraser

When the path has a visible fill, the same tool removes area instead of centerline intervals, using `src/vector-eraser-fill.ts`. The sweep is built in canvas space, mapped through the inverse layer transform, and subtracted from the shape with Paper Booleans, so scale and skew erase what the pointer covered on screen. Round brushes use 32-sided capsules, so erased edges are short straight segments, not true arcs. The result can bite an edge, open a hole or split the shape into separate contours within the same layer. Identity, basis, pose and paints stay, and the layer box is not tightened. Untouched curves stay curves. A miss makes no history, erasing everything is refused, and the budgets are 128 contours and 2,048 anchors. Open filled paths, masks, live Booleans, visible effects and automatic layout refuse.

## Stroke eraser

In the point inspector, open **Vector eraser**, choose a **Round** or **Square** brush and diameter from 1 to 500 canvas units, then enable **Erase vector strokes**. Drag and release on the canvas. A translucent continuous brush sweep and an actual geometry preview show the operation before release; saved geometry remains unchanged until release. Round brushes sweep circular capsules; square brushes remain aligned to the canvas axes and sweep the convex hull between consecutive positions. Sparse pointer positions are connected continuously, with no unpainted sampling gaps. Brush sizes remain canvas sizes while zoom changes their displayed screen size.

The tool removes covered **centerline intervals** of this selected stroked contour path. Circle boundary roots use degree-six curve equations; the straight boundaries of swept squares/capsules use cubic equations. Derivative root isolation and bisection find interval boundaries, and union membership selects surviving intervals. Retained cubic pieces use de Casteljau subdivision, without flattening or fitting source geometry. Floating-point intersection tolerances still apply. Original layer ID, parent, dimensions, path coordinate basis, affine pose, stroke/paint settings and other metadata stay unchanged. Exposed stroke caps follow the original style and can extend into the brush area; this is not a pixel-exact outlined-stroke subtraction.

A release with an actual change creates one Undo transaction and survives `.oui` versions 1 and 2, save/reopen and the existing MCP contour schema. A miss creates no history. Fully covered contours may disappear if another interval survives. Erasing the entire layer is explicitly refused with an explanation: use the ordinary Delete action to remove it. Failed or interrupted operations never partially commit.

**UI-14-044 remains partial:** filled-region knife/eraser operations, general vector networks, automatic multi-layer erasing and outlined stroke-area subtraction are not implemented. **UI-14-045 has real round/square shape and size controls**, within these stated stroke-eraser limits. Reference verification remains pending.

Input shares segment scissors safeguards: a visible, effectively unlocked, unmanaged contour path in Design point editing, with Motion closed; visible solid centered undashed strokes; hidden fills; no live boolean, mask on the edited node, visible effect, child, automatic layout on the path or component definition. Up to 128 contours and 2,048 input anchors are supported, with an invertible affine hierarchy of at most 64 ancestors. Coordinates and visible controls must remain within ±1,000,000. A gesture permits at most 64 recorded positions and 16,384 broad-phase curve/sweep pairs; results permit 128 contours and 2,048 anchors. Collinear forward samples coalesce without changing their swept region. A live count shows the recorded positions. At 64 turning positions, the accepted preview visibly freezes at its last endpoint; Release applies only that visible prefix, and Escape cancels it. Later pointer movement is not shown or erased. Other computational or result-budget failures refuse the whole gesture. The same contour/anchor budget applies to input and output, so valid results remain eligible for another stroke. Cached matrices and node maps avoid repeated page/ancestor scans.

## Lasso vector points

In point editing, **Lasso vector points** selects anchors inside a drawn closed outline. Release closes the outline automatically. Shift at the start adds to the selection; Option subtracts; an unmodified lasso replaces it. Concave and self-crossing outlines use even-odd containment, including boundary anchors. A preview highlights included anchors. Tangent handles and whole layers are not lasso targets. Finish with Escape to return to normal anchor/handle dragging and the existing point operations.

Lasso selection is editor state, like ordinary point selection: it does not create document history or become part of saved files. Geometry changes made afterward use existing Undo/save behavior. It supports up to 10,000 anchors and 256 outline vertices, with one cached affine mapping. It works on filled and stroked contour paths, with Design/Motion/lock/visibility/instance/boolean ownership guards; clipped anchors remain selectable in point editing. Degenerate zero-area outlines select nothing. This completes the bounded anchor-lasso behavior **UI-16-022**; it does not imply general layer lasso or multi-vector editing.

## Sessions and verification

Both tools exclude Bend, segment scissors, gradient handles, image crop, mask inspection and one another. Escape, blur, document hiding, resize, document/page/source/selection/mode/camera/tool/UI-scale changes cancel pending operations. Lasso also invalidates if point selection changes externally. Pointer cancellation and lost capture cancel the gesture. Active-session identity and permanently invalidated context proofs refuse retained same-event handlers, including a mode changed away and back. Space/middle mouse may pan; camera movement disarms the tool. All geometry mutations preflight again and validate the complete resulting target after component/layout derivation.

Core tests cover exact retained intervals, round/square continuous sweeps, closed seams, tangent/miss/degenerate boundaries, affine/reflected basis, malformed/budget input, Undo/persistence, context invalidation, lasso containment and 10,000-anchor selection. Actual browser tests cover real pointer input, visible preview/exported gap pixels, one Undo/save/reopen, size/shape, affine ancestors at 125% UI scale, all cancellation paths, retained handlers, unsupported input and lasso selection followed by real anchor editing. Existing validated MCP contour updates persist eraser results; no model schema, new MCP operation, native IPC, build, package or website change is needed.
