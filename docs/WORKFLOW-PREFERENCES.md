# Local workflow preferences

These settings live in the validated `oui-preferences` local storage envelope, outside .oui documents. Existing version-one envelopes acquire only the new field defaults; existing values remain intact. Unsupported fields, invalid enum values, nonfinite/range violations and fractional interval/file-limit values are rejected. Reset affects preference keys, not saved projects, named versions or exported files.

- **Interface scale:** 85%, 100%, 110%, 125%, 135% and 150% presets; validated values between 85% and 150% can also be read, and a saved value above that clamps to 150%. At 135% and 150% the menu bar, top bar, toolbar, sidebars, title menu and root dialogs were checked at 1440×900, 1280×720 and 1024×640 (tests/e2e/ui-scale-large.spec.ts); Main and title menus now cap their height to the window at every scale. Not every specialized dialog was opened at 150%. Native WKWebView has not been checked above 125%. Panels, toolbar, top/menu bars and root dialogs scale independently from the SVG canvas and playback. Sidebar pointer deltas and physical fixed-menu anchors compensate for scale. Compact layout uses the physical breakpoint to stay synchronized with responsive styles. Changing scale cancels active canvas artwork gestures and sidebar resizing. Native macOS menu/title-bar sizes remain system controlled.
- **Font previews:** show or hide specimens in the Font library. Typeface names, explicit loading and Apply remain available. This does not alter document typography or automatically download the font catalog.
- **Local recovery interval:** a 100–60,000 ms quiet interval after edits, with the previous 600 ms default. Hiding/closing the page still attempts immediate recovery. Native close-state recovery and explicit project saves retain their existing paths. This is local recovery, not automatic overwriting of exported .oui files.
- **Recent file limit:** 0 (all/default) or 1–1,000 visible matches in Home's Recent files view. All files and stored projects are retained. The native Open Recent and Dock menus keep their existing separate macOS behavior.
- **Default export format:** SVG (default), PNG or JPG for fresh generic export dialogs, the generic inspector, and frames without saved profiles/new export-profile entries. Existing .oui frame settings retain their authored formats.
- **Color picker format:** HEX (default), RGB, HSL or HSB, consumed by newly mounted color pickers after integration with the color workflow changes. A picker’s explicit format change remains local to that mounted picker.
- **Duplicate names:** preserve names (default), reserve unique `copy` suffixes, or increment trailing numbers on duplicated artwork roots. Children and ordinary Paste retain their names. Design/Whiteboard Duplicate and slide artwork Duplicate consume this setting; Home's separate Duplicate file behavior is unchanged. Naming joins the existing duplication transaction, so one Undo removes the complete duplicate.
- **Keyboard zoom around selection:** keep selected visible artwork's center stationary on screen during Command +/−. The native command adapter also applies this to native menu zoom because AppKit forwards the same existing command ID for keyboard accelerators and menu clicks. Web toolbar/menu and wheel zoom retain their current behavior. The default remains off.
- **Control-click context menu:** controls Control context-menu events on the canvas; plain right-click retains its existing behavior, including the separate right-button-pan preference. The default remains on.
- **Number-key opacity:** enable keys 1–9 for 10%–90%, and 0 for 100%, outside editable inputs. Locked selected layers are skipped. The default remains on.

Validation in the isolated source checkout: TypeScript compilation; nine focused workflow core tests plus existing preferences/panel tests; complete 784-test core suite; twelve new browser scenarios, with the existing preferences, sidebar, document title and page suites also checked. Browser coverage includes exact 120×80 drawing at 125% interface scale, sidebar resize distance, compact overlay/window fit, physical menu anchors, cross-window gesture cancellation, duplicate/Undo, locked opacity, export bytes/defaults/profile preservation, preview visibility, real IndexedDB recovery timing/pagehide flush, view-only recent limits, and the existing native command forwarding callback. This is not a native WKWebView smoke or reference verification against Figma.
