# Offline Sketch document import

Forma can open a supported local `.sketch` ZIP through **File → Import Sketch document…**, or browser **Open project…**. Conversion runs in an owned worker and the user reviews counted reductions before opening a new editable project. The current project remains unchanged during reading, conversion and review. Existing reviewed-import repository delivery retains dirty source recovery and rolls back an unaccepted candidate with ownership checks. Opening starts a new project with empty Undo history; subsequent edits have normal Undo/Redo and `.oui` save/reopen. No document-version change was needed.

This is a **partial UI-39-033 implementation**, not complete Sketch compatibility. The Mac shared HTML picker is reachable without expanding native IPC. Native shell Open/associations and a real native Sketch comparison have not been verified.

## Editable supported subset

- Referenced pages, artboards and groups, with rotation and reflection through the same matrix Sketch draws with.
- Symbol masters stay main components and instances stay live, with string, swap, hide, image and shared-style overrides applied by path through nested masters. Library symbols embedded in the file are added to an **Imported components** page when used. Expansion is charged before any copying.
- Shape groups keep live Boolean operands, folding sequential operations into nested results. A rotated group carries its transform on a wrapper. Unjoined compound shapes become one path with their winding rule.
- Clipping masks keep their mode, and a layer that breaks the mask chain ends it in a mask group. Layer blend modes, resizing constraints, shared layer and text styles, color variables, prototype flows, hotspots and start points map to native data.
- Rectangles with per-corner radii, ovals, stars, polygons, triangles, edited primitives and straight/cubic open/closed path contours. Rounded anchors between straight edges become true circular fillets; next to a curve they stay sharp, with a notice. Incoming `curveFrom` and outgoing `curveTo` normalized controls become actual editable anchor-relative handles; closing segments retain both endpoints’ controls. Rectangle corner points must traverse adjacent corners. Standard fixed rectangle radii and SVG ellipse geometry have counted rasterization notices.
- Stacked fills and borders with solid, gradient and image-pattern paints; shadows, inner shadows and Gaussian blur. Disabled definitions are omitted and counted. Native border-option enable-state, dash phase and rasterization are disclosed reductions requiring comparison.
- Text keeps editable ranges for font, size, color, spacing and decoration, with the family, weight and italic read from the PostScript name. Alignment, line height, paragraph spacing and vertical alignment are kept. Text boxes stay at their saved bounds, and native glyph shaping is not reproduced. Installed/fallback font availability affects layout; imported files do not trigger a new font service.
- Embedded local PNG/JPEG bitmap layers, stretched to their saved frames. Headers and actual browser decoding must agree before review. Missing/nonlocal/unsupported references become visible editable gray rectangles with a notice, never network requests.

Every import has a reduction summary. Smart layout rules, comments, user data and export settings are not transferred. Noise fills use a gray placeholder. Notices are shown before opening and retained in the new document description. Original source IDs become fresh local IDs. The original `.sketch` is never overwritten.

Unknown layer classes become visible gray placeholders with their saved size, and instances of a symbol missing from the file do the same. Unknown or inconsistent curve data, explicit transform objects, unedited open primitives, circular symbols, empty shape groups and unsafe geometry refuse the **whole** import before replacement. Nothing is silently deleted. Raster-only preview files are not used as a substitute for editable conversion.

## Boundaries and cancellation

The archive reader validates central/local headers, sizes, flags, exact ranges, CRCs and duplicate names before publication. Only stored/deflate ZIP entries are supported; encrypted, multipart, ZIP64, link/special-file, traversal or unaccounted-data archives refuse. No path is extracted. Only `document.json` and referenced page JSON are interpreted; ignored previews and user records never execute. Asset references are local archive keys only.

Bounds are 50 MB input, 128 MB expanded bytes, 2,048 entries, 32 MB per JSON entry, 16 MB other entries, 256-byte ASCII ZIP names, 50 pages, 20,000 layers per page after symbol expansion, 60,000 expanded symbol layers, 64 layer levels, 100,000 points, two million scheduled JSON values and one million text characters. Repeated embedded image strings count each serialized node occurrence—including both legacy image and paint image fields—toward a 40 MB output preflight; a final 50 MB project guard remains before document parsing. Page titles and text are bounded too. Unique referenced images are limited to 256, 8,192 pixels per edge, 16 million pixels each and 64 million aggregate pixels.

FileReader exposes actual byte progress and abort; archive entry progress is actual worker completion. The worker is terminated after 30 seconds, cancellation or source invalidation. Bitmap validation has a 30-second aggregate abortable deadline and the existing 15-second per-decode bound. Browser codecs may finish internal work after cancellation, but owned callbacks are cleared and cannot publish. Synchronous parsing, bounded inflation and JSON/model validation are not cooperatively interruptible; worker termination bounds their wall-clock lifetime, not instantaneous JS allocation/total browser RSS. Output accounting prevents repeated-asset amplification before full-document serialization, but ordinary parser/intermediate strings still consume memory.

Picker, entry and review receipts are invalidated permanently on source/page/mode/modal changes, including synchronous away/back cycles. Old callbacks cannot open a replacement context or confirm a newer review. Reports use fixed local error codes and do not echo raw source errors, URLs or private payloads. Ordinary `.oui`, direct `.fig`, SVG, REST JSON and PDF defaults retain their existing paths.

## Source reference and verification

The independent converter follows the official [Sketch file format introduction](https://developer.sketch.com/file-format/) and [JavaScript API geometry reference](https://developer.sketch.com/reference/api/). The archived MIT [official schema repository](https://github.com/sketch-hq/sketch-document), inspected at commit `4493900abbfa49ae82fbcb8ad85cccf2cc2256b0`, establishes the referenced-page structure and closed enum/object fields. Its archived status does not establish full current/native-format parity. No schema implementation was vendored and no dependency was added.

Synthetic fixtures exercise real ZIP/worker conversion, editable geometry and exported colors, local PNG decoding/damaged-image refusal, multipage conversion, progress/cancel/deadline cleanup, stale picker/review callbacks, dirty recovery denial and reviewed repository rollback. Core tests cover archive corruption/traversal/encryption, malformed/unsupported atomic refusal, adjacent corner ordering, scheduled-value bounds and repeated-image serialized-output amplification. User Sketch files or private artifacts are not test fixtures.

## Cubic path extension

The archived `curveMode` enum is checked as 0 None, 1 Straight, 2 Mirrored, 3 Asymmetric and 4 Disconnected. Absent mode remains accepted for legacy straight points only. Active handles require a known curved mode and an actual coordinate; mirrored/aligned modes must have both handles and satisfy their opposite-vector symmetry/collinearity checks at a relative tolerance of `1e-8` (with a local absolute floor for symmetry). These checks authorize the later editing constraint; **they do not regenerate or snap imported control geometry**, and do not prove native raster parity. Disconnected handles retain their independently saved coordinates. Anchors remain within the normalized unit box; controls may overhang it, but every scaled anchor/control, world point and resulting handle vector must be finite within ±1,000,000 units before publication. This conservative bound can refuse extreme saved paths. The existing 100,000-point, serialized-output and worker limits apply unchanged.

Only documented winding rules 0 (nonzero) and 1 (even-odd) are accepted; unknown values refuse before opening. A single closed contour can retain retraced bridge segments and an even-odd curved hole. Synthetic kernel/browser checks distinguish asymmetric controls, nonzero parent origins, closing-edge curvature and actual hole pixels, then edit/save/reopen the real contours; reference/native Sketch acceptance is still unverified.

The normal existing Vector point-edit entry may re-tighten the saved path box and create its own undoable normalization. Imported handles remain ordinary editable contour data; actual fixed-viewport raster checks verify the entry preserves artwork. A subsequent handle gesture has one additional Undo, Escape cancels its draft, and `.oui` reopening retains the edited controls.
