# Local layer annotations

The Inspect sidebar exposes **Layer annotations** for one selected layer. Add and edit plain note text, developer notes, stored numeric property references, authored box measurements, or a distance to another layer. Existing notes can be searched, edited and deleted. A local category manager creates, renames, recolors and deletes categories; deleting one preserves its notes as uncategorized. Each layer keeps its own copy of a category, and **Manage annotation categories across this file** treats every copy with one name and color as one category.

Notes and category edits are staged until Save. Each successful edit is one Undo transaction and persists in .oui versions 1 and 2. Context-invalidated drafts refuse application instead of moving into another selection. Cancel discards the draft. Hidden/locked/managed annotations remain readable in Inspect; changing them requires an editable unlocked source. Component roots inherit one atomic annotation set and can override it; generated children are read-only. Resetting the existing component annotation override restores current source data. Main edits update linked copies on normal component derivation.

## Actual reference semantics

Property annotations read a closed list: the stored numeric fields `x`, `y`, `width`, `height`, `rotation`, `opacity`, `fontSize` and `strokeWidth`, plus `fill`, `stroke`, `cornerRadius`, `fontFamily`, `fontWeight`, `lineHeight`, `letterSpacing`, `textAlign`, `blendMode`, `gap`, `padding`, `layout` and `prototypeTarget`. They show current values rather than a copied string. A text property on a non-text layer, or a layout value on a layer without layout, reads as unavailable. A stored stroke or text field is not a guarantee about a multi-stroke stack’s visible ink or a loaded font’s glyph metrics.

Measurement annotations calculate the length of the authored local width edge, height edge, or box diagonal after the complete affine transform, including signed/nonuniform ancestor scales and rotation. Those three are box vectors. **Between two points** measures any two points of the box, and **Painted width** and **Painted height** read the page-axis painted bounds of the layer and its children, including strokes, effects and text overhang. Distance annotations default to the two box centers in page coordinates; they can also read the nearest box edges (the page-axis gap or overlap from Spacing inspection), or two chosen points on the two layers. Point readings can be limited to the horizontal or vertical page axis. Values update as referenced geometry changes. Center distances become explicitly unavailable when absolute-coordinate floating-point precision cannot support the displayed hundredth of a pixel. Box-vector lengths avoid translation subtraction. Deleted, missing or unavailable targets show an explicit unavailable result; the note survives, and Undo restoring the target restores the live value.

Internal distance references follow page copies, ordinary copied subtrees and component materialization. Cross-file clipboard targets outside the copied graph are explicitly made unavailable, with one notice; a coincident destination ID cannot silently retarget them. Copied ancestor ghost groups omit unrelated annotation metadata. Source and instance internal references map through their respective graph IDs. External targets of inherited component annotations are unavailable in generated copies rather than being guessed across ownership/page boundaries.

## Visibility and handoff

A saved per-layer checkbox controls its markers. **Show annotation markers on canvas** is an ephemeral editor preference and does not alter document history or exports. Markers are HTML siblings of the SVG, carry only counts, and use the authored transformed top-right box point. **Show annotation text and measurements on canvas** adds each note and live value beside its layer, and a line for each measurement, in a detached overlay outside the exported artwork tree. Both views appear in Inspect while Motion and modal editing are closed; hidden or zero-opacity ancestry and the per-layer checkbox hide them too.

**Annotate on canvas** and **Measure on canvas** (Inspect sidebar, or View and Actions) are pointer tools. A note click selects the layer and opens the editor with the clicked point saved. A measure takes two clicks: on one layer it saves a point measurement, on two layers a distance owned by the first. Points snap to box corners, edge midpoints and the center within 8 screen pixels. Escape cancels. The sidebar's percentage fields reach the same points by keyboard. A locked or managed owner refuses in the status line and writes nothing.

The expandable **Handoff annotations across pages** searches notes, layer/page names, kinds and category names; filter developer notes or other kinds, page through 50 rows, and navigate an actual annotated layer without changing content/history/visibility. Live referenced values are shown when inspecting their owner. This is local file handoff information, separate from comment threads, assignments, developer resources and cloud collaboration.

## Validation, persistence and privacy

The optional node `annotations` object contains local `categories`, `items` and optional `visible`. Unknown fields, invalid kinds, malformed scalar/reference values, duplicate local IDs and missing local categories are refused before document publication. Bounds are 32 categories and 32 notes per layer, 2,000 plain-text characters per note, 512 annotation items in the complete derived document, 20,000 page layers/256 ancestors for geometry, and 100,000 document layers for the handoff scan. A distance target may deliberately be unavailable; a category reference must resolve inside its own annotation set. Legacy files without annotations retain absent metadata without migration/version changes.

Ordinary `.oui` saves, whole-file duplication and authorized source MCP project reads/replacements retain private annotations. No annotation text is automatically included in project summaries, error messages, logs or public artwork. Shared Artwork/SVG/PNG/PDF rendering does not draw annotation metadata. Canvas count markers are HTML and never enter the SVG export tree.

**Export for Figma** removes annotations and related override keys from a clone, also dropping opaque library ownership/publication data whose baseline strings might retain private annotation metadata. The source document remains unchanged. Standalone editable Figma Bridge import validates annotations before creating pages and emits only a generic omission notice. An annotation-only override does not detach an otherwise supported linked instance. No native Figma annotation API or desktop round trip is claimed.

Reusable library publication removes private annotations/related override keys before computing source fingerprints and emits one generic warning. Incoming reusable snapshots with annotations are refused. Installed consumer-library policies and normal whole-project saves remain intact. This stage adds no network service, filesystem permission, paid requirement, global category sharing or code-completion verification.

## Limits

Categories exist while a layer uses them; there is no empty file-level category. File-wide edits skip locked layers, managed children and instances that inherit their annotations, and report the count. Instances keep whole-set inheritance, so edit the main component to change those. Paint references summarize a stack (`2 paints`) rather than listing it. Edge gaps use transformed boxes, not nearest painted contours, and clipping or occlusion does not change them. Painted bounds use the same conservative rules as `visualBounds`. Overlapping canvas labels are not rearranged. Native and reference-app acceptance remain unverified.

Optional fields `fromPoint`, `toPoint`, `at`, `axis` and `gap`, and the new measurement and property values, appear only on annotations that use them. Older Forma builds refuse a file that uses them, because their closed validation rejects unknown annotation fields. Files that do not use them save exactly as before.

Combined delivery also strips file-local comment threads before serializing Export for Figma. The ordinary editable .oui keeps both comments and annotations; the source document and Undo history are unchanged by delivery preparation.
