# Local sections and layer status filters

Sections have a dedicated Design inspector with a title, a local Ready for development checkbox, direct-child selection, a parent-section selector, and a local link. Mutations use document transactions, support Undo/Redo, and survive .oui save/reopen. `readyForDevelopment` is optional on section nodes in version 2 documents; version 1 imports retain the optional field. Both file parsing and editor transactions reject invalid values or readiness on other layer kinds.

Titles accept 1–512 characters without control characters. Inherited locks and managed instance sections block metadata and structure edits. Nesting uses the existing world-transform-preserving hierarchy planner, rejects cycles and invalid destinations, and refuses animated hierarchies or participating auto-layout sections. Whiteboard/Slides structure changes remain in their workspace controls. Contents selection chooses visible, unlocked direct children, rather than flattening nested content.

A `forma-section:` token contains only the current document/page/section identifiers. Copy local section link displays the token even if clipboard permission fails. Open local section link, below Layers, validates the currently open file and destination, clears filters, selects the section/page, and finds it on the canvas. It creates no public URL, hosting, sharing permission or external protocol handler. Missing/deleted sections and links for a different open file are refused without editing the document.

The layer status selector combines with type and name filters and preserves ancestor paths. It supports saved export settings or slices, explicitly ready sections, configured prototype reactions/legacy destinations/flow starting layers, layers carrying a durable anchored comment, and geometric intersections with local comment pins. The comment filter includes resolved pins and accounts for rotated/scaled geometry; an anchored comment matches its layer by identity wherever its pin lands, and a missing anchor falls back to the saved position. Pins remain canvas coordinates, so this is not a durable layer comment attachment. Hidden/locked layers remain inspectable in layer filters, as in the existing layer tree. Status filters are workspace UI state and do not dirty the project.

Ordinary groups expose an explicit Fit group bounds to children action. It reuses guarded frame fitting, preserving child world geometry and restoring source constraint metadata before final validation. It includes hidden direct children, excludes stroke/effect padding, rejects empty, locked, managed, boolean and auto-layout groups, and refuses cases where layout would move the artwork. This remains partial relative to automatic group bounds recomputation. Existing group blend mode controls support the renderer's 16 blend modes and isolation, but a separate Figma pass-through blend mode is not added by this work.

Validation: `tests/section-workflows.test.ts` (13 core tests), `tests/e2e/section-workflows.spec.ts` (6 browser interaction tests), TypeScript compilation, and the complete 720-test core suite passed in the isolated source checkout. The browser tests cover save/reopen, Undo, nested transforms, cycle refusal, direct contents, local cross-page links, filters, inherited locks, malformed imports, group fitting and the existing rendered multiply blend mode. The pin classifier also checks 20,000 layers against 10,000 pins. These checks do not establish reference verification against Figma desktop.
