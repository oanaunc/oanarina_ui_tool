# Sampled vector and scatter brushes

This is a bounded Forma brush workflow, not complete Figma Draw brush-format compatibility. UI-16-038 and UI-16-039 remain **partial** pending broader source, editing and reference coverage.

Select one eligible vector in Design, open **Reusable vector brush → Sample vector as brush**, name it, review the actual silhouette, then choose **Save sampled brush and draw**. This stores a local preset and opens the existing Brush tool. No document edit or Undo entry is created by saving a preset. Drawn strokes are ordinary groups of independently editable filled path stamps; the normal one-Undo brush transaction, `.oui` save/reopen, headless renderer, source MCP geometry editing and SVG export all work without new document metadata or a document version change.

The capsule contains only version, fill rule and closed editable contour coordinates/handles. It does not carry source IDs, names, annotations, links, styles, font files, images, controllers or external resources. Hole/winding semantics remain intact. The source's rotation, reflections, nonuniform scales and fixed ancestor affine transforms are baked into the silhouette; page translation is intentionally omitted. The brush color tints the whole silhouette. Size and aspect resize each stamp; stamps do not warp along a drawn stroke.

Supported sources are independent opaque solid-filled closed paths, unrounded rectangles, polygons and stars, with 3–128 anchors across 1–16 closed contours. A path must fit the 16 KB / 512-command inspection subset and contain no SVG arcs. Open contours, text, images, children, masks, clips, effects, blending, components/slots, automatic layout, affected Motion tracks, networks and visible strokes refuse before saving. A visible six-digit solid fill is required. Existing source artwork is unchanged. Source pages support 20,000 layers, 64 hierarchy levels, and documents up to 1,000 pages / 100,000 layers. A cached node map prevents per-point ancestry scans.

Normalized geometry uses a 100×100 basis, 6-decimal capsule coordinates and the existing 5-decimal contour renderer. Collapsed or ill-conditioned matrices/bases, degenerate silhouettes, unsupported aspect ratios (outside 0.1–4), oversized coordinates and excessive serialization amplification refuse. The conservative serialization gate reserves normalized-coordinate rounding and tests the maximum stamp size/aspect/scatter envelope against 0.01 design units. This bounds the known serialization stages, not Paper's parser/bounds algorithm or arbitrary font/raster behavior. Source-to-stamp antialiasing may vary at transformed edges.

Enable **Deterministic scatter** in Brush controls for a primitive or sampled vector. The unsigned 32-bit seed and stamp ordinal/channel determine repeatable along/across displacement, angle and size jitter. Changing global random state does not affect the result. Straight pointer-event segmentation does not change the sequence; arc-length spacing still follows the authored centerline. Displacement is measured in base brush sizes, along/across the local tangent; size jitter is symmetric up to ±90% and angle jitter up to ±180°. Pressure behavior stays in the existing brush pipeline. This is not a pressure/tilt nib or a stretch brush.

Before drawing, controls show the effective stamp cap. The existing 1,024 pointer-sample and 512-stamp limits remain, with sampled vector strokes additionally bounded to 8,192 total anchors and 1 MB of path data. Previews use at most 32 stamps and respect the same cap. Exceeding a stroke budget cancels the whole uncommitted draft; no prefix is silently saved. Source/settings/camera/mode changes and gesture interruptions invalidate the existing draft proof.

Local libraries remain `forma-brush-presets` version 1 with additive optional `vectorStamp` and `scatter` fields and a new `vector` shape. Existing presets and primitive drawing output are unchanged when those fields are absent. Unknown/malformed fields and oversized capsules or cumulative libraries refuse before settings publication. The complete serialized library remains limited to 64 KB / 32 built-in-plus-custom presets. Older preset readers can refuse the new fields; old `.oui` readers still see the ordinary drawn vector paths. Brush JSON import/export shares the reusable settings separately from a design. Local storage failure is reported by sampled-brush creation; the brush remains available for the current session.

The sampling review uses permanent source/context invalidation and immutable local name/disclosure receipts. Retained handlers cannot save a source after selection/document/mode/modal/Motion changes, even after an immediate return. A fresh Review restores usability. Preset changes never rewrite already-drawn strokes.

Validation includes closed-hole Canvas/SVG pixels, source preservation, atomic local settings budgets, deterministic event segmentation, reflected/nonuniform ancestry, unsupported source refusal, one-Undo drawing, genuine save/reopen, local preset export/reload, stale retained review handlers, scatter draft cancellation, keyboard Space activation, compact 125% containment, and source MCP persistence of ordinary vector stamps. No new native or network capability is added.
