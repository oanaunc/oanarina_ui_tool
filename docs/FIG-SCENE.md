# Decoded Figma scene mapping

`mapFigScene({message, images}, name, onProgress?)` converts the bounded decoder snapshot into a new, validated v2 `DesignDocument`. It runs in the same owned worker as decoding (`src/fig-import.worker.ts`), so cancelling stops conversion too. `summary` counts what stayed live. It does not read project paths, fetch remote images, touch editor state or mutate the decoded input. The workflow must call `validateFigSceneRasters(document, signal)` before installing the result: that browser gate decodes each distinct admitted fill/stroke raster and checks its intrinsic dimensions. `complete` means no reductions were reported by this mapper, not complete `.fig` format parity.

## Preserved current appearance

- Public design pages retain source ordering and canvas backgrounds. Internal style/dependency canvases are used for resolution without becoming visible pages.
- Local affine transforms retain hierarchy using the editor's existing rotation/reflection/scale representation. Nonuniform parent scale with a rotated child is allowed; unsupported local skew fails before mutation.
- Frames, rectangles, corner radii, ellipses/arcs, lines and available vector geometry become editable layers. Stroke outlines can become editable filled paths. Baked boolean geometry is imported without also painting its operands.
- Embedded PNG, JPEG, GIF and WebP images retain pixels and alpha. Fill, fit and tile use existing paint behavior. A stored crop transform becomes a Forma crop when its scale is uniform; a stretched or rotated crop is fitted and reported. Gradient handles come from the inverse paint transform, so linear gradients are exact; a radial, angular or diamond gradient that is not a circle in the layer's unit box is placed at its nearest circle and reported.
- Referenced local styles resolve their current values. `styleType` records become Forma paint, text and effect styles, and a layer links to one only when its values agree. Text styles are `typographyOnly`, so applying one leaves the layer's box and vertical alignment alone. Stroke styles stay plain. `VARIABLE_SET` and `VARIABLE` records become collections with every mode; aliases stay aliases, and a frame's explicit mode becomes `variableModes`. A value resolves in the mode that applies at that layer. A layer binds to a variable only when the resolved value equals its literal. Published library identities are not imported.
- Instances stay live. Each copy is addressed by its path of source ids inside the main (`figKey`), which also finds nested instances and swapped mains. Override keys are computed by comparing each copy with its source, ignoring per-copy paint ids and values that follow a shared variable binding. Overrides match by guid or stable `overrideKey`, at any nesting depth. Instances with custom slot content cannot follow their main, so they stay as exact plain layers and are counted. Only source-root appearance defaults are inherited; source position, visibility, deletion and ownership state are not copied into instances.
- Vector networks rebuild editable anchors. The reader accepts a blob only when every count and byte is accounted for, and the rebuilt outline must match the baked `fillGeometry` in bounds and area. Otherwise the baked outline stays and is reported. Junctions become separate contours sharing a point, with a notice. Rounded vertices keep the baked outline.
- Booleans keep live operands when they are upright, built only from shapes and recompute to the stored result. Otherwise the baked path stays.
- `fig-settle.ts` runs the edit pipeline on a clone before the document is returned. An instance that moves or changes is detached; an auto layout frame that moves children becomes positioned; a Boolean that recomputes differently keeps its outline; a style or variable link that changes the layer is dropped. Six rounds at most, then every remaining link is dropped together.
- Spec blocks become frames of editable text where any readable text exists, and keep their embedded raster preview as an image layer only where none does. See the spec block section of [FIG-IMPORT.md](FIG-IMPORT.md). The whole-file thumbnail is never used as the document or as a replacement for missing art.

## Editable text with original glyph appearance

When source glyph command data is available and styling can be represented as a whole-text outline, the text layer keeps its literal characters, font/style metadata and optional `textOutline` metadata. Untouched text renders the original glyph path, preserving source positioning even if the source font is unavailable. The path has an accessible text label; safe whole-text hyperlinks remain links in SVG output. Current fill, stroke and opacity still apply.

The outline is used only while its exact typography/layout signature matches. It includes characters, font family/size/weight/style, rich runs, axes, features, decorations, spacing, alignment, paragraph settings, truncation, width, height and clipping. Editing those properties falls back to normal editable text layout; Undo can restore the original outline. Moving, rotating or recoloring the whole text does not discard its shape. Font-refresh metrics leave a currently valid outline's original dimensions intact.

Mixed character styles, native decorations, unavailable glyphs and uncertain text layout report a reduction and use editable text instead. Source glyph outlines are local project geometry, not bundled font files. The outbound Figma plugin reports stretch fills as a FILL approximation and uses editable characters and available fonts; preserving this cached glyph metadata through a Figma round trip is not claimed.

## Validation and bounds

The mapper checks duplicate identities, missing parents, hierarchy/component/slot cycles, geometry/reference validity and the final saved document before returning it. Hierarchies are limited to 256 levels, reference chains to 64, and expanded output to 20,000 layers per page and 60,000 in total. Composed world matrices must remain finite, and padded artwork corners must remain within one million world units. A shared reference/property work budget also limits repeated traversal and inherited-map copying. Combined path data is bounded while appending; a separate geometry conversion budget prevents repeated shared blobs from amplifying processing without bound.

Only embedded hash references resolve images. Each admitted raster is bounded to 20 MB, 8192 pixels per side and 16 million pixels. Unreadable or missing images become marked placeholders rather than refusing the file. Before allocating any browser image, the open gate also limits all distinct fill/stroke image data to 64 million pixels in total (about 256 MB for one RGBA pixel buffer). Repeated uses of identical image data count once and must declare consistent dimensions. PNG chunk boundaries/checksums and static framing are checked; animated PNG, SVG and remote images are not admitted by this import route. GIF and WebP are admitted by their header dimensions and animation is not edited. JPEG headers are inspected and actual browser decoding remains mandatory. Images and raw blobs are memoized. Per-node/page serialized size, including pretty-print indentation, is accumulated before full-document serialization, with a conservative 48 MB scene budget inside the existing 50 MB saved-project limit.

`textOutline` accepts bounded numeric path commands only; markup, URLs, invalid coordinates and oversized paths fail the shared rich-text/document validator used by parse, store and MCP pipelines. Invalid or stale metadata is never interpreted as executable SVG.

## Remaining reductions

This is a bounded import subset. Grid auto layout stays positioned; a property driving several layers stays a property on the first and overrides on the others; property definitions on library mains, stroke styles, per-paint blend modes, background and progressive blur, per-region vector fills, key and variable prototype actions, cross-page prototype links, mixed line height inside one text layer and native document-block editing are reduced or omitted and reported. Field names are unverified against a real schema here; see the evidence limit in [FIG-IMPORT.md](FIG-IMPORT.md). Missing/unsupported records produce explicit notices, and invalid required references/bounds fail atomically. No binary `.fig` export is provided.

Synthetic tests in `tests/fig-scene-live.test.ts`, `tests/fig-import-worker.test.ts` and `tests/e2e/fig-live-import.spec.ts` cover live instances and main edits, nested overrides and swaps, variants, properties, auto layout, styles, variable modes, vector networks, Booleans, prototypes and the settle fallbacks, through the real decoder and worker. Synthetic core tests also cover hierarchy/world matrices, ordering, current local fills, instance/slot/text assignment closure, source-root defaults, editable outline save/open and edit fallback, boolean operands, malformed metadata, cycles and resource amplification. Browser tests measure real SVG image-alpha/mask/stretch pixels, recoloring, links/accessibility, actual text/font/width edits and Undo, and `.oui` save/open. Separate source-module tests use `playwright.fig-scene.config.ts` to test corrupt stroke-image rejection and cancellation without changing the active document; they are outside the production app test directory. Private reference files, decoded records, screenshots and converted documents stay in ignored local validation storage and are not committed.
