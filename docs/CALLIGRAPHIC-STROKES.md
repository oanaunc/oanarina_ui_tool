# Fixed-angle calligraphic nib

Nibs now sweep curved and closed contours as well. Curves are sampled with a turn limit of 6 degrees, each sample is a full ellipse, and consecutive samples are joined by exact tangent quads. The saved centerline keeps its handles. Effects, masks, instance copies and layer Motion no longer refuse; live Booleans and auto layout still do. Pressure and tilt are still absent. Older builds refuse a nib on a curved or closed contour. Any statement below that says otherwise is superseded.

Forma now has a bounded editable elliptical-nib stroke. Select a supported contour path, open **Calligraphic stroke · Elliptical nib** in its Stroke section, and enable the nib. Stroke weight is the major nib diameter. **Angle** fixes the nib direction in node-local coordinates; **Roundness** sets the minor/major diameter ratio. Different centerline directions therefore produce different broad/thin silhouettes. The nib follows the layer's actual affine pose, including reflection and nonuniform ancestors.

This is an independent Forma algorithm, not a claim of exact Figma brush parity. Figma's [illustration-tool guide](https://help.figma.com/hc/en-us/articles/31440438150935-Draw-with-illustration-tools) describes stretch/scatter brush workflows, and its [Figma Draw introduction](https://www.figma.com/blog/introducing-figma-draw/) describes calligraphy-inspired brushes. Neither specifies this ellipse-sweep algorithm. Pressure, tilt, random variation, custom brush artwork, curved contours and Figma's full brush controls remain outside this pass.

## Geometry and limits

For each straight segment, the outline is its exact Minkowski sum with a fixed ellipse: a quadrilateral connects the ellipse's two supporting tangent points at each endpoint, and full ellipses cover the ends and joins. Each quadrilateral and ellipse has the same positive winding. One compound nonzero filled path unions all overlaps and applies the stroke paint's alpha once, including self-crossings and multiple contours. The original centerline is saved unchanged; generated outline geometry is deterministic and is not hidden document state.

The optional `StrokeStyle.calligraphic` contains only `angle` (−180–180 degrees) and `roundness` (0.05–1). Absent metadata preserves existing stroke rendering and file behavior. Versions 1 and 2 remain readable without a required migration. Enabling explicitly saves round caps and joins; disabling removes the nib and retains those saved round settings. The nib's elliptical ends/joins are intrinsic to this stroke mode; ordinary line cap/join settings cannot silently change its geometry.

Supported input is one solid centered saved stroke, width 0.0001–10,000 local units, on a leaf path with 1–16 open straight contours and at most 512 anchors. Adjacent rendered anchors must be separated by at least 0.00001 local units. Positive box/basis dimensions and scaled centerline coordinates are bounded at 995,000; the full ellipse envelope stays within ±1,000,000. A page containing nib strokes supports up to 20,000 layers and 16,384 combined source anchors; ancestry is bounded at 256 and uses cached lookups.

Dashes, markers, independent edges, dynamic waves, per-anchor width profiles, curved/closed contours, live Booleans, masks, components/instances, visible effects, automatic layout and animated ancestry are explicitly refused. No pressure or tilt values are inferred. A page containing masks is refused conservatively. Shared ordinary stroke bounds use the major nib diameter as a conservative enclosing circle; exported geometry retains the actual elliptical silhouette. Authored proportional scale behavior continues through the shared stroke-scaling policy; Motion and unsupported geometry changes refuse before publication.

## Editing, persistence and interchange

Enable/disable, angle and roundness changes use normal Undo and `.oui` persistence. Numeric controls permanently invalidate retained source handlers across document, selection, mode, Motion, modal, inspection, tool and UI-scale changes. Equal settings and disabling absent metadata preserve source identity, bindings and history. New stroke edits detach competing stroke style/width bindings according to existing stroke-editing policy. Locked ancestry and managed ownership are refused before mutation. Clipboard copies own their saved nib metadata independently.

Headless document validation, source MCP operations, canvas drafts and transient prototype variable results validate the same geometry and budgets before publication. Invalid variable-driven nib widths refuse the complete action batch, including navigation. Static presentation works; Smart animate of affected subtrees refuses explicitly. Reusable stroke styles, geometry normalization/topology conversions, generic outline-stroke commands and editable Figma Bridge transfer refuse this mode rather than replacing it with a uniform stroke. SVG/PNG appearance exports use the same filled-outline renderer. Direct binary `.fig` interchange is not implemented.

## Validation

Core checks cover exact ellipse support/bounds, positive polygon winding, multiple contours, round nibs, deterministic output, model/Undo/persistence, no-op bindings, invalid geometry/style/ancestor input, clipboard and Bridge refusal, reusable-style refusal, transient prototype validation and bounded 512-anchor/20,000-layer ancestry work. Actual browser checks exercise direction-dependent broad/thin pixels, overlap alpha once, signed affine/nonuniform-basis export, reachable angle/roundness controls, keyboard enable/disable, save/reopen/Undo, retained context refusal, inherited locks, malformed imports, prototype recovery and unchanged bound controls.
