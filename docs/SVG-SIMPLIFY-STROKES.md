# SVG aligned-stroke simplification

**Export → SVG options → Simplify aligned strokes** is an optional export-only conversion. Saved layer profiles retain `svg.simplifyStrokes?: boolean` through normal profile Undo, `.oui` save/reopen and versions one/two; combined export choices are temporary. The document's artwork is never changed. With the option absent or false, the existing export bytes remain unchanged. PNG/JPEG ignore this SVG-only setting. Copy SVG remains independent of saved profiles.

## Meaning and reference

Figma's primary [ExportSettings API documentation](https://developers.figma.com/docs/plugins/api/ExportSettings/) describes `svgSimplifyStroke` as approximating inside/outside strokes to avoid a more complex masking representation. Its [static export settings guide](https://help.figma.com/hc/en-us/articles/13402894554519-Export-formats-and-settings-for-static-designs) explains the increased-weight-plus-mask alternative. This requirement concerns SVG stroke alignment representation, not general-purpose anchor reduction or curve simplification.

Forma's existing SVG renderer doubles inside/outside stroke width and clips/masks the unwanted half. This new option replaces that representation for a small proven subset with a centered stroke on an inset/outset centerline. The saved stroke width remains the exported width. The original fill path, paint order, colors/opacity, resource coordinates, layer transforms and crop are retained. It is distinct from **Outline supported strokes**, which converts strokes to filled paths. The two options are mutually exclusive: the UI switches off the other conversion, and malformed files or headless requests containing both refuse explicitly.

## Supported subset

A candidate must have one uniform, solid, undashed saved stroke on a leaf square-corner rectangle or complete circle. Rectangle joins must be miter with miter limit at least √2. Inside weight must be strictly less than half the smaller dimension; outside weight must be no greater than that dimension. These bounds avoid collapsed inner geometry and the current renderer's finite outside-mask white rectangle. Complete circles require equal width/height, full 360° sweep and no inner arc. No rounding, smoothing, independent edges or point-width profile is supported. No approximation of an ellipse or arbitrary contour is attempted.

For an inside stroke of weight `w`, the new rectangle/circle centerline is inset by `w/2`; for outside it is outset by `w/2`. The width `w` and existing affine groups remain unchanged. Only the matching stroke wrapper's alignment clip/mask is removed. Its now-unreferenced alignment resource is removed; unrelated resources remain. Original fills can differ from the stroke and can be gradients because their geometry is not converted. The output still contains an ordinary editable SVG stroke, including its original opacity.

Centered strokes remain unchanged. Lines, arrows and marker strokes already render centered in Forma regardless of saved alignment and are not simplification targets. Unsupported selected aligned strokes refuse the export rather than silently retaining only part of the result. Container/text/arbitrary-path aligned strokes, multiple saved strokes, partial circles, dashed/non-solid strokes, masks, clipped or live-Boolean hierarchies and visible effects refuse. Original source ancestry is checked before selected-export ghosts can remove ancestor effect metadata. Unrelated effects on non-target siblings do not disqualify a target. Sampled Motion must be closed for SVG conversion; direct headless `exportSvg` consumes the supplied static graph only.

## Bounds, state and verification

The planner supports at most 20,000 source/exported layers, 256 cumulative hierarchy levels and 128 aligned targets. Hierarchy and resource lookup are cached; no per-target ancestor or resource scans are required. Strict rendering and all conversion checks finish before the prepared export can download. Existing immutable snapshots and abort-on-source-change export tasks apply. The shared SVG controls retain permanent original editor-context proofs and synchronous local candidate receipts, so old callbacks cannot overwrite newer options. There is no document Undo entry for generating an export; saved profile edits use ordinary Undo.

Shared profile/import validation, direct source MCP edits and Bridge preflight validate the optional boolean and mutual exclusion before publication. Bridge explicitly omits Forma export profiles while transferring ordinary artwork. This adds no native, filesystem or network capability and makes no binary `.fig` interchange claim.

Source checks cover exact default bypass, rectangle/circle centerline math, fill/crop preservation and reduced markup, unsupported and ambiguous-input refusal, model versions one/two, original ancestry/Motion guards, bounded depth/target count, Bridge preflight and MCP persistence/atomicity. Actual browser tests compare whole-image pixels for inside/outside rectangle/circle edges and corners, gradient fills, half-opacity strokes and reflected/nonuniform nested transforms, verify genuine save/reopen and editable SVG reimport/render, centered mixed exports, mutual-exclusive controls, stale context guards and no download on unsupported input. Existing stroke-outline browser cases also pass.

UI-40-026 remains **partial**. The underlying requirement's alignment semantics are implemented for this explicit static subset, not arbitrary vector networks or exact Figma reference output. Figma's default enabling rules are not copied: Forma preserves its existing default bytes and makes this conversion opt-in. No app build, native package, release archive, website or central register metadata is changed.
