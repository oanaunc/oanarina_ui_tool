# Local templates and personal starter kits

Home → Start from a template and Resources/Actions → Templates and personal starter kits open the same keyboard-contained gallery. Search and category filters browse six original free Forma examples: Orbit studio landing page, Margin reader library, Tempo dashboard, a retrospective, a connected customer journey and a three-slide deck. Artwork, copy and shapes are original source assets; no third-party template or font files were added.

Select a template to preview its saved base artwork and individual pages. This uses the existing isolated cover renderer: 500 layers and 4 MB per preview, no Motion playback, historical font registration or borrowed conflicting font faces. An explicit diagnostic replaces unsupported previews. Previewing and filtering do not edit the current project.

Create new file makes an independent validated project identity, drops publisher identity, preserves document-scoped references and opens a new native window through existing `openDocument` IPC when available. Browser fallback retains the current project before replacement. Dirty ownership from the desktop tracker, including zero-history RAM-created/imported/recovered projects, prevents replacement if recovery cannot be written. A new recovery failure uses the existing in-memory warning. Native API mock checks exercise forwarding only; a shipping WKWebView acceptance pass remains pending under the build freeze.

Insert this page at current page root makes local editable copies through the existing validated clipboard transfer planner. IDs, supported component/style/variable/font dependencies and native Whiteboard sticky/connector records remap. It uses a 24 px offset and one Undo step, followed by real selection navigation. Design and Whiteboard workspaces must match. It reports the omission of page settings, comments, Motion and file-level review metadata; existing clipboard warnings cover unsupported prototype dependencies. Presentations create full new decks rather than inserting unregistered slide frames. Unsupported inputs and font conflicts refuse before document mutation.

Personal kits are full private local copies saved in the separate `forma-starter-kits` IndexedDB store. Kits include current private notes and supported embedded assets, with no community publishing or cloud synchronization. Saving does not modify the current document. Local entry selection is lazy; a kit can be exported as an independent `.oui` project, removed, or restored with Undo removal. Created files remain independent of kit deletion. Kit names, envelope and full document are validated before writes; imported/restricted fonts are not redistributed. Installed licensed fonts remain usable by name. Preserve `.oui` backups because browser/device storage can be cleared.

Limits: 50 kits, 100 MB total, 5 MB per complete envelope, 100 pages / 5,000 layers / 128 ancestors per kit. Unknown/corrupt entries remain stored with a hidden-entry diagnostic; writes never purge them to fit a new kit. Duplicate identities and total-size overflow refuse transactionally. Full copies retain valid cached external component-library references but no library publisher identity. Page insertion makes referenced definitions local editable copies.

Actions own permanent document/page/selection/mode/modal/Home/Motion proofs and abortable writes. Gallery-local name/page/candidate changes invalidate retained handlers and pending work. Fresh rendered controls can retry after a source interruption. Literal empty legacy page IDs remain selectable. Closing cancels pending storage actions and restores focus on the canvas or Home opener. No native IPC permission, document schema version or original sample was changed.
