# Smoothing, width profiles, progressive blur and Motion scrolling

This continues the [surfaces/vector/Motion source checkpoint](UNRELEASED-SURFACES-VECTORS-MOTION.md). The existing 2,022 requirements now record **1,263 implemented, 205 partial and 554 planned** items. No requirements were added. The new geometry workflows retain explicit partial coverage; Forma is not a completed Figma clone.

| Area | Reachable source behavior | Remaining limits |
| --- | --- | --- |
| [Corner smoothing](CORNER-SMOOTHING.md) | Rounded-box percent/reset control, one shared curve for artwork, clips, masks, SVG and supported vector baking; Undo, components, clipboard, `.oui` 1/2 and source MCP/Bridge metadata. | Independent MIT-licensed curve approximation with coordinate rounding; no general path, polygon or star smoothing or exact Figma geometry claim. |
| [Per-anchor widths and taper](VARIABLE-WIDTH-STROKES.md) | Anchor picker/numeric widths and canvas normal handles; true tapered straight bands with bevel/round joins and butt/round/square caps, zero tips and single-alpha winding; saved ratios, shared exports/masks/bounds, layout, Undo, component inheritance and validated source MCP. | One saved solid centered butt/round/square-cap and bevel/round-join stroke on bounded open straight contours. No curved/asymmetric width envelopes, independent inserted width positions, pressure or miter joins or arbitrary brush profiles. Unsupported conversions and editable Bridge transfer refuse. The taper requirement records this same workflow, not another implementation. |
| [Progressive blur](PROGRESSIVE-BLUR.md) | Spatially varying nine-level Gaussian blend with start/end radii, projected direction/extents, shared artwork/export/masks and conservative subtree overflow bounds. Geometry-affecting animation, unsafe derived previews and renderer limits are explicitly guarded. |
| [Motion frame scrolling](MOTION-FRAME-SCROLLING.md) | Native frame-local scrolling with negative origins, signed affine geometry, fixed/sticky positioning, scroll-to, remembered positions/Restart, isolated hotspot artwork and keyboard access. All schema additions are optional; current `.oui` versions one and two remain readable. Validation precedes document publication, with post-derivation checks. The new width/effect metadata does not expand native filesystem access, network binding or IPC. Proprietary fonts are not bundled. Corner geometry retains its upstream MIT license and third-party notice.

Independent review found and corrected unsupported smoothing input being discarded during Boolean derivation, width-profile conversion paths, retained mask-inspection handlers, fractional native scroll origins, excessive scene retention and keyboard focus, plus bounds interactions between width profiles, progressive subtrees and fixed/sticky scrolling. A source-valid filtered subtree cannot be stretched by positioned-scroll compensation beyond the filter budget; that combination refuses before the preview opens. Adjusted Motion scenes validate again before rendering. Canvas/overlay drafts validate before publication, geometry/text Motion under progressive subtrees refuses, prototype variable/variant actions preflight derived geometry and filtered Smart Animate refuses. Font loading preserves exact source/history if reflow exceeds a budget; live artwork pauses visibly and can recover through normal inspector edits, while exports remain strict. See [font safety](PROGRESSIVE-FONT-SAFETY.md).
