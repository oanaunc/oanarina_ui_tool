# Local saved-version links

Version history includes **Copy local version link** for the selected historical preview and a **Preview linked local version** input. Copy first re-reads and validates the actual snapshot belonging to the current document. Paste the opaque reference in Version history with the matching file open to review that saved base artwork. The existing comparison, explicit Restore with Undo and separate-copy actions remain available afterward; following the link itself does not restore or replace the current design.

This is partial version-link support. `forma-version:` references contain only a version tag, document ID and snapshot ID. They are local references, not public URLs, permissions, native OS launch handlers or cloud sharing. Snapshots remain in this device/browser's local repository, separately from ordinary `.oui` project files, and may disappear through existing retention or storage clearing. Copying a `.oui` to another device does not copy its saved history. Foreign document IDs, absent/corrupt/misowned snapshots and malformed or oversized references refuse before preview publication or clipboard dispatch. There is no cross-file automatic loading, snapshot import, network lookup or persistence-schema change.

The bounded format permits two nonempty control-free identifiers up to 500 characters and at most 4,096 encoded characters. It includes no title, author, file path, artwork, private comments, images or fonts. No credentials, network service, new IPC scope or filesystem access is required.

Actions reuse history's serialized source-owned runner. Source away/back transitions permanently invalidate old handlers and pending reads; fresh rendered controls recover with a new receipt. Input edits and historical target changes invalidate local requests even if the final text/target later matches. A queued real IndexedDB read cannot publish or dispatch clipboard content after invalidation. Clipboard dispatch, once accepted by the browser, cannot be revoked; late status publication is still refused. Read-only previews, copy and input changes do not edit document content, dirty state, Undo or saved files. Existing history preview limits and fonts/poster reductions remain in force.

Source validation: four pure format tests cover Unicode, ownership, size/control bounds and malformed data. Actual browser checks cover opaque copy, reopened linked preview, unchanged artwork/Undo/save, foreign/missing/corrupt data, retained source/local target handlers, queued real snapshot reads and 125% keyboard actions. Clipboard delivery is checked through the browser adapter; it is not native OS clipboard acceptance. The existing historical-review browser set is also included. An actual away/back regression identified memoized history proof reuse that blocked fresh recovery; each fresh context now gets a distinct ref-owned receipt while every prior receipt remains invalid.

UI-38-023 remains partial. Native AppKit and live Figma reference acceptance, public/version URLs and portable snapshot sharing remain unimplemented or unverified. No app, package, automation/source archive or website is rebuilt for this source continuation.
