# Selection, frame positioning, vector bending and text settings

This continues the [input/assets/mask source pass](UNRELEASED-INPUT-ASSETS-MASKS.md). Nine more individually named requirements now have reachable, validated local implementations. The register records **1,229 implemented, 184 partial and 609 planned requirements**, out of 2,022. Exact Figma reference verification remains separate and pending. Forma is not a finished clone.

The optional text-background field is additive; existing `.oui` versions one and two remain readable. Input validation rejects malformed metadata before document mutation. Local preference migrations retain old custom values while introducing disabled defaults. Ephemeral selection/tool/preview state stays outside saved documents and history. No native resource or IPC permissions change.

Independent review covered each implementation area and the combined selection geometry. Review caught a rapid-typing caret race, duplicate React keys in neighboring inspector controls, and three tests that accidentally matched source components instead of real instance copies. Corrected assertions now verify actual generated IDs, source propagation and independent Bridge overrides. These fixes are included in the final combined validation.

## Validation

On October 30, 2026, the frozen combined source passes **1,148 core tests in 104 files**, **590 browser interaction checks**, **50 saved-file MCP source/protocol tests**, and both editor/MCP TypeScript checks. The complete browser run uses a separate loopback origin and includes actual gestures, keyboard focus, modifiers, cancellation, transformed geometry, exported pixels, component propagation, Undo and saved-file reopening. The numerical dialog and text-settings tabs were also visually inspected in an isolated browser tab. The user's open design was backed up locally before applying the source update; private design files/screenshots are not repository artifacts.

No app build, installer, notarization, distribution archive, version change or website deployment is generated. Existing dev.12 downloads remain unchanged. Production/native/WKWebView checks, standalone bundled MCP acceptance, the downloadable Bridge/source archive comparison and real Figma desktop/reference acceptance remain deferred under the build/archive freeze; none is counted as passed. The one archive-comparison browser check is explicitly excluded from this source run.

Use `npm run dev` for these source changes. Installing the unchanged download does not install this implementation pass. The [feature register](FEATURE-REGISTER.md) retains all remaining partial/planned requirements.
