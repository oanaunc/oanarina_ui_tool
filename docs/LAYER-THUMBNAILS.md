# Layer artwork previews

Hover a layer row or focus its row with the keyboard to open one static artwork thumbnail after 200 ms. Escape closes it and leaves selection alone. Layer rows keep their existing arrow/range/toggle selection behavior. The preview is read-only: it writes neither project metadata nor history, and saved files contain only the original artwork.

The shared SVG export renderer supplies shapes, rich text, images, effects, parent transforms, ancestor clipping and relevant sibling masks. Selecting a child does not include unrelated ancestor fills or other sibling artwork. Frames fit their frame bounds; other layers fit the export artwork bounds. Slices show their actual page crop. Each preview is an isolated SVG image document, so its mask/gradient IDs cannot collide with the canvas. Previews reflect saved Design geometry, never Motion time or video playback.

Only one layer thumbnail renders at a time. The page gets a linear hierarchy/mask index; a preview collects a bounded subtree and ancestor/mask context before using the export renderer. Up to 500 context layers and 64 ancestor levels are supported; slice previews require at most 500 page layers. Smaller ordinary targets still preview on much larger pages. Hidden targets/ancestors, missing/cyclic hierarchies, oversized artwork and unsupported shared-export geometry display an explanation instead of a truncated picture. Thumbnails cap the generated SVG at 16 million characters; large exports remain available through the existing export workflow. External/nonembedded resources and unavailable fonts retain the ordinary export renderer's limitations.

Pointer departure, focus departure, Escape, scrolling, window resizing/blur, hidden document, filters, hierarchy expansion, menus, dragging, dialogs, Motion, hidden UI, project/page replacement and Assets cancel previews or their pending timer. A new hover/focus opens a fresh preview after a source edit or Undo. Pending keyboard focus can re-arm once its automatic tree scroll settles. Tooltips remain within the viewport; existing mask descriptions remain associated with their layer rows.

Validation: `tests/layer-thumbnail.test.ts` checks context collection, exact ancestor transforms, relevant mask subtrees, reversed hierarchy ordering on a 20,000-layer page, slice transforms and atomic limit reporting. `tests/e2e/layer-thumbnails.spec.ts` checks actual mask/crop pixels, read-only saved JSON and history, focus/Escape/ARIA, edits/Undo/reopen, filter/scroll/menu/drag/dialog cancellation, limits and compact placement. Exact Figma reference verification and native WKWebView visual acceptance remain pending under the build freeze.
