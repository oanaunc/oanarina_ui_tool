Shared image previews now refuse individual operands owned by live Booleans, mask-source/slice/media ancestry and unsupported nonrectangular ancestor clips. Whole Boolean results and supported sibling masks still render. This prevents blank or misleading isolated previews. **Layer thumbnails are reclassified partial** to make missing mask-source and imported-hierarchy coverage explicit; the preceding report's counts describe that earlier pass. Frame overflow inspection uses isolated images, avoiding duplicate live Canvas resource IDs, and remains partial because candidate bounds do not prove visible overflow through occlusion/masks/clips.

No schema migration or `.oui` format-version change is required. Source MCP keeps its existing shared document operations. No native IPC/resource permissions, proprietary font redistribution or project upload was added.
