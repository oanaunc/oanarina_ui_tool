# Persistent spacing inspection

Select a layer and switch to Inspect → **Spacing inspection**. A child initially compares with its parent; two selected layers initially compare with each other. Search the current page and choose another comparison target without changing the selection. A labeled solid/dashed diagram and persistent numerical rows report page-axis horizontal/vertical gaps or overlap, signed edge/center offsets, and four bounding-box insets when the selected box is contained by the comparison box. Offsets mean selected minus target.

The existing Value source selector switches between base geometry and the sampled Motion pose. This is read-only and creates no Undo history. Copy spacing reference includes the source, names, values and assumptions. It omits asset bytes, literal text bodies and raw private IDs. If clipboard writing is unavailable, displayed values remain selectable. Native Enter/Space activation works within the section without starting canvas panning.

The **Measure** selector offers three readings. **Layout boxes** are authored rectangles after ancestor affine transforms, enclosing rotated, reflected or nonuniformly scaled geometry in page axes. **Painted bounds** use the page-axis painted extent of each layer and its contents, with strokes, effects and text overhang, following clipping parents; hidden layers refuse. **Inside a rotated parent** compares a child with one of its ancestors along that ancestor's own axes, so padding reads correctly when the parent is rotated; other layers refuse. None of these are nearest contour distances or an automatic layout change. Stroke/effect/text overhang, path contours, clipping, masks, visibility and occlusion do not change this reference. The diagram illustrates the two boxes; it does not alter canvas artwork or enter exports. Existing Option-hover canvas measurements remain available separately. UI-41-010 gains a working partial implementation; broader native/visual-distance and exact Figma reference acceptance remain pending.

The pure solver indexes at most 20,000 page layers and follows at most 256 ancestors per compared target, independent of node order. Cycles, ambiguous page identities, unavailable ancestors, nonfinite output and coordinate precision loss refuse with an explicit diagnostic. Finite values use overflow-safe display formatting; no new model coordinate cap is imposed. Search lists at most 100 results per page and pins the current target separately. Numeric-looking identities do not collide with the chooser sentinel. The standalone layout helper can tolerate an empty string identity, but the application’s existing mask validator currently rejects an empty root layer ID; this feature does not change that document-validation policy.

Permanent source context, parent selection/source receipts, synchronous local candidate generations and reactive fresh-control renewal protect both choice handlers and copies. An old indexed select cannot resolve a newly filtered list against its previous candidate array. Retained callbacks and late clipboard completions cannot update a changed target; equal-value choices still renew usable controls. No document metadata, file format, native IPC, network permission or external service is added.

Validation: nine headless tests cover gap/overlap/insets, transformed shared boxes, numeric/precision failures, hierarchy bounds, zero-size boxes and immutable bounded reports. A clean actual-browser run passes 28 checks: nine new spacing workflows plus 19 existing platform/metadata inspection workflows. These cover real clipboard text, no-history/save invariance, target search/pagination, numeric-zero identity, sampled/base Motion, multi-selection, retained indexed choices, denied/late clipboard results and a short viewport at 125% scale. Independent source review found and corrected the retained indexed-choice seam and then cleared the final source. No new app/native build or release artifact is produced.
