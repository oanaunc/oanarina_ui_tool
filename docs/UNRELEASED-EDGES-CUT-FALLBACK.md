# Independent edge strokes, path cutting and ordered font fallbacks

This continues the [gradient, text and nested-name pass](UNRELEASED-GRADIENT-TEXT-NAMES.md). All three requirements in this pass retain **partial** status. The combined register records **1,246 implemented, 194 partial and 582 planned requirements**, out of 2,022. Implementation and Figma reference verification remain separate; Forma is still in development toward parity.

| Area | Working source behavior | Remaining limits |
| --- | --- | --- |
| [Independent edge strokes](INDEPENDENT-EDGE-STROKES.md) | Each eligible box stroke can use separate Top, Right, Bottom and Left widths, its existing paint, and Inside/Center/Outside alignment. A single filled ring avoids alpha overlap. Shared canvas/SVG/raster/MCP output, asymmetric bounds/masks/filter regions, Undo, styles, components and clipboard preserve the setting. | Square boxes and solid edges with one common paint. Rounded/dashed/non-box/per-edge paint and edge outlining are unsupported. Stroke-in-layout uses a conservative maximum. Editable Bridge explicitly refuses these strokes before page mutation. |
| [Vector cut](VECTOR-CUT.md) | A scissors workflow in point editing splits an open stroke contour or opens a closed contour at a chosen segment parameter. Exact cubic subdivision preserves local geometry and layer pose/style. Pointer and numeric paths, cancellation, Undo and saved reopening are included. | Contour strokes with bounded geometry and ownership; this does not cut filled regions or create vector networks. Endpoint caps may affect appearance. Source documentation lists the supported stroke and context restrictions. |
| [Multilingual font fallbacks](MULTILINGUAL-FONT-FALLBACK.md) | Ordered layer/range family lists share rendering, measurement, inline editing, masks, optical metrics, CSS and eligible embedded-font exports. User edits preserve Undo, style/instance semantics, rich clipboard and project persistence. Available fonts are requested through existing loaders. | Browser glyph selection, without automatic script assignment or glyph-coverage detection. Font availability, embedding permission and receiving renderer affect output. Headless metrics approximate; editable Bridge reports omitted policy. |

Edge widths and fallback lists are additive optional fields, compatible with `.oui` versions one and two and validated before accepted mutation. Imported user projects remain private. Fallback lists stay absent in legacy files until explicitly edited; the shared font stack intentionally corrects a previous missing-primary measurement/rich-tspan inconsistency, so unavailable fonts may reflow as documented.

On October 30, 2026, final combined source validation passes **1,513 core tests across 127 files**, **818 browser interaction checks**, **57 MCP source/protocol checks**, and editor/MCP TypeScript checks. The complete browser run passes on frozen source with the worktree-local cache, including synthetic `.fig` worker decoding/cancellation/recovery and the short-window preview regression. Evidence covers actual edge alpha/bounds/masks/filter pixels, mixed-script embedded-font measurement and export pixels, exact curve samples and affine/125% pointer picking, real controls, one-step Undo/save/reopen, linked sources/overrides and atomic malformed or stale-context refusals. Focused author runs and independent reviews supplement this final combined run; repeated, failed or interrupted runs are not added to its counts.

The preceding full browser run exposed a layer-thumbnail keyboard/hover/scroll race. The fix retains the focused request through late scrolling and prevents pointer exit from cancelling a focus preview. A dedicated short-window regression covers the sequence and Escape dismissal. Synthetic `.fig` worker checks passed in isolation after timeouts in a concurrent run; Vite caches now live inside each worktree because dependency directories can be shared. Interrupted/failed runs are not counted as complete acceptance.

Independent reviews include paint geometry and bounds, font validation/selection/embedding, exact cubic topology and context handling, and practical behavior at the cut tool's advertised page limits. A cached path/world mapping replaces repeated ancestry scans: the same synthetic 20,000-layer, 64-ancestor, 509-segment activation benchmark drops from 16,748 ms to 7.39 ms. This measures activation geometry, not browser DOM paint or all document operations. Generated artwork is imported for visual QA, including actual edge editing, fallback reorder/Undo and a canvas curve cut/Undo. The open user project is saved locally for a complete JSON comparison when updating the working source; no user project, private Figma ID or private screenshot is published.
