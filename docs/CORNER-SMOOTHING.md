# Rounded box corner smoothing

The Design inspector exposes a 0–100% corner smoothing field for a single unlocked rectangle, frame, component, instance, image or section. Set a positive shared or per-corner radius first. Large radii can consume the room available for smoothing. Reset removes the optional field and returns to the original circular corner path.

The same generated vector path drives artwork, box clips, masks, SVG/PNG exports and supported box-to-vector conversion to editable points. Image layers keep the existing image-conversion restrictions. Vector conversion bakes the curve and clears box-only metadata. Component inheritance, instance overrides/reset, reusable clipboard transfer, Undo, save/reopen and source MCP updates preserve the optional fraction. Existing version-one and version-two documents remain compatible; missing or zero smoothing takes the unchanged legacy path. Invalid fractions and unsupported shapes reject before mutation.

Geometry uses the MIT-licensed [figma-squircle implementation](https://github.com/phamfoo/figma-squircle), vendored from version 1.1.0 with its full license in source and third-party notices. It constructs independent cubic/arc approximations with four-decimal coordinate rounding. This is not a claim of exact Figma geometry or reference verification. Polygon, star and general vector corner smoothing are not implemented by this control.

The editable Bridge validates and transfers supported box-node `cornerSmoothing` in the plugin API, including component export and direct instance overrides. API mock checks are only protocol checks; a real Figma desktop round trip and native WKWebView acceptance remain pending. Unsupported Figma node types report omitted box-only smoothing metadata. The [Figma API property reference](https://developers.figma.com/docs/plugins/api/node-properties/) and [corner-radius/smoothing guide](https://help.figma.com/hc/en-us/articles/360050986854-Adjust-corner-radius-and-smoothing) describe the reference behavior; implementation and reference acceptance stay separate.

Source validation covers headless curves and bounds, legacy path identity, malformed imports, atomic updates, component overrides, clipboard, baked vector geometry, Bridge API transfer, actual browser controls/pixels, rounded frame clipping, alpha/vector/luminance masks, retained-handler invalidation, Undo/save/reopen, and source MCP export/persistence. No frozen application, installer, Bridge archive or MCP download is regenerated.
